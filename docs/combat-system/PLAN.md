# 戰鬥系統（首版：戰鬥核心與一種敵人）

## 目的

- 建立即時戰鬥的核心：生命與失能、武器普通攻擊、敵人攻擊預告、完整傷害結算、戰術暫停。
- 以一種普通敵人（舊令巡檢機）驗證手感。之後再加其他敵人與首領。

## 已決策（2026-11-03）

| 問題 | 決策 |
|---|---|
| 首版範圍 | 戰鬥核心＋一種普通敵人（舊令巡檢機） |
| 命中判定 | 出手時擲 D20 並顯示結果；成功才產生攻擊，之後是否命中由碰撞（攻擊範圍形狀）決定。碰撞命中後不再追加檢定 |
| 傷害結算 | 完整 26 步（`docs/dnd/規則/傷害.md`） |
| 戰術暫停方法（C3，2026-11-04） | 動作速度 0＋移動速度 0＋停用武器（`UNIT_WEAPON_BF_ATTACKS_ENABLED`），恢復時還原。`BlzPauseUnitEx` 與 `PauseUnit` 會中斷引導 |
| 近戰閃避參數（C3，2026-11-04） | 攻擊範圍緩衝使用預設 250，容許值 32。目標走開時引擎自己判定「未命中」，本系統的距離檢查是備援 |

## 範圍

### 包含

1. **傷害結算**：完整 26 步的純函式。傷害事件包含多個傷害部分；每個部分有標籤、輸出分類與防禦通道。
2. **戰鬥者數值**：一級屬性推導二級屬性（生命、攻擊力、防禦、暴擊、迴避、攻擊速度、施法穩定）。
3. **生命與失能**：本系統保存生命與護盾，WC3 單位的生命只用於顯示。玩家生命降至 0 時進入失能；敵人降至 0 時被擊倒並移除。
4. **普通攻擊**：玩家使用 WC3 原生攻擊（移動、攻擊動作、距離）。出手時以通用檢定擲 D20。傷害由本系統結算。
5. **敵人攻擊預告**：準備（約 0.8 秒，顯示形狀與聲音）→ 作用（擲 D20，成功時對形狀內的目標造成傷害）→ 收招。
6. **戰術暫停**：世界時鐘暫停時，戰鬥單位的移動、攻擊與動作也停止。恢復後繼續。
7. **技能系統改用新結算**：火球術、寒冰箭的傷害經新的傷害結算。數值與目前相同（其他層為中性值時）。
8. **範例地圖**：符文學者對舊令巡檢機。

### 不包含

- 其他兩種普通敵人、首領（下一版）。
- 偵測與警戒的四種狀態（未察覺、調查、追擊、失去目標）。屬於「潛入與追緝」模組。首版只用固定的察覺距離。
- 閃避動作、工具、補給、救難結算（屬於活動系統）。
- 倒地後的體質檢定與瀕死層數。首版一般活動不使用角色死亡（`遊戲框架.md`「結果剖面」）。
- 裝備、詞綴的資料來源。傷害結算支援這些欄位，但首版的值由範例直接提供。

### 2. 傷害事件

```
DamageEvent
  source、target、kind（direct | dot | reflect | thorns | crush | share）
  output（melee | ranged | spell）、canCrit、skill（技能所有權）
  parts: DamagePart[]
DamagePart
  amount、tags（physical、fire、frost…）、channel（physical | spell | none）
  history（base | added | gained | converted）
```

- 26 步依 `傷害.md`「完整結算順序」，每一步是一個可單獨測試的函式。輸入是攻擊者修正、目標修正與事件；輸出是每一步的中間結果與最終結果（生命損失、護盾消耗、分攤、偷取、反射、是否擊倒）。
- 修正來源（裝備、狀態、知識）以「修正清單」傳入。結算不讀取 WC3。
- 需要亂數的步驟（暴擊、格擋、壓碎）由呼叫者傳入擲骰函式，測試可以固定結果。
- 混合傷害的分攤（格擋值、固定減傷）依各部分占比；差額放在最後一個部分，使總和等於原值。
- 反射建立新事件，且不可連鎖。

### 3. 數值精度（32 位元）

- `傷害.md` 要求固定小數精度、途中不取整。WC3 Lua 是 32 位元浮點數，約 7 位有效數字。
- 首版直接使用浮點數，不取整。生命與門檻（死亡、破盾、斬殺）都用內部值比較。
- Node 測試用 `Math.fround` 模擬每一步的結果。烈焰斬完整範例的每一步，與文件數值的誤差必須小於 0.001。
- 生命值上限以 100000 為試玩上限。

### 4. 戰鬥者數值

依 `docs/dnd/屬性/二級/`：

| 二級屬性 | 公式 |
|---|---|
| 最大生命 | 40 + 體質 × 5 + 戰鬥等級 × 2 + 加成 |
| 近戰攻擊力 | 力量 × 2 + 精準 + 加成 |
| 遠程攻擊力 | 精準 × 2 + 力量 + 加成 |
| 物理防禦 | 體質 × 2 + 力量 + 護甲 |
| 法術防禦 | 精神 × 2 + 體質 + 裝備防護 |
| 暴擊率 | 5% + 精準修正 × 1% + 幸運修正 × 2%，上限 50% |
| 暴擊傷害 | 200% + 精準修正 × 2% + 幸運修正 × 3%，上限 300% |
| 迴避 | 身法修正 + 加成 |
| 攻擊速度 | （身法修正 + 精準修正）× 5%，上限 100% |
| 施法穩定 | 精準修正 + 精神修正 + 加成 |

### 5. 檢定

- 普通攻擊（不使用技能節點）使用通用檢定：`11 + 挑戰等級 + 不利修正（目標迴避）− 戰鬥等級 − 屬性修正（精準）− 有利加成`，範圍 2～19。
- 技能沿用技能檢定（已實作）。目標迴避作為不利修正。
- 檢定結果以浮動文字顯示（「命中檢定 成功／失敗，骰值，檢定值」）。失敗時不產生攻擊。

### 6. 生命與失能

- 本系統保存每名戰鬥者的生命與護盾。WC3 單位的最大生命與目前生命跟著更新，只用於血條顯示。
- 原生傷害事件（WC3 普通攻擊）在傷害前事件中被改為 0，再由本系統結算。
- 玩家生命降至 0：進入失能。單位停止行動、不能下命令、不是攻擊目標。範例提供 `-revive` 恢復，用於重複測試。活動系統之後處理救難結算。
- 敵人生命降至 0：被擊倒，播放死亡動作後移除。

### 7. 普通攻擊（玩家）

- 使用 WC3 原生攻擊：右鍵目標、自動接近、攻擊動作。攻擊時間依攻擊速度調整。
- 原生傷害事件發生時（近戰的出手時刻）擲 D20：
  - 失敗：顯示「未命中」，傷害為 0。
  - 成功：以武器基礎傷害建立傷害事件，經 26 步結算。
- 碰撞（使用者於 2026-11-03 要求玩家的攻擊也可以被閃避）：
  - 近戰：原生傷害事件發生時，本系統檢查攻擊者與目標的距離。距離大於「攻擊範圍 + 雙方碰撞半徑 + 容許值」時，判定為閃避，傷害為 0，顯示「閃避」。物件資料的「攻擊範圍緩衝」（Range Motion Buffer）設為小值，使目標在出手前離開時，攻擊動作被取消。先擲 D20 再檢查距離，不會在碰撞命中後追加失敗。
  - 遠程（下一版）：物件資料關閉「投射物追蹤」（Projectile Homing Enabled）。投射物飛向發射時的位置，目標移動即可閃避。命中目標時是否仍造成傷害，須在遊戲中確認。
  - 容許值與緩衝值為試玩值，在 C3 中調整。
- 首版武器是近戰單手武器（符文杖）。

### 8. 敵人：舊令巡檢機

行為（依 `01-灰潮泵站.md`：「沿固定區域巡查；攻擊前亮起定向燈」）：

```
巡邏 ──察覺──▶ 追擊 ──進入攻擊距離──▶ 準備（0.8 秒）──▶ 作用 ──▶ 收招（0.6 秒）──▶ 追擊
  ▲                │
  └──超出追擊距離───┘
```

- 巡邏：在兩點間往返。
- 察覺：玩家進入察覺距離（試玩值 600），且玩家不是失能。
- 準備：停止移動，面向目標。地面顯示直線形狀（定向燈），播放聲音。準備期間方向固定。
- 作用：擲 D20（通用檢定）。成功時，形狀內的玩家受到傷害；失敗時顯示「未命中」。
- 收招：不移動、不攻擊。玩家可以趁此時攻擊或離開。
- 敵人的原生攻擊關閉。移動以命令執行，由世界時鐘（`Phase.Combat`）驅動判斷。

### 9. 戰術暫停

- 世界時鐘暫停時：本系統的計時（敵人行為、技能、效果）已停止。另外須停止 WC3 單位本身的移動、攻擊與動作。
- 採用方法 2（C3 已在遊戲中驗證，見「已決策」）。候選與結果：

| 方法 | 已知問題 |
|---|---|
| `PauseUnit` | 會打斷引導施法（`docs/rxwc3/m5/PLAN.md`） |
| `BlzPauseUnitEx` | 會中斷引導（C3 實測） |
| 動作速度 0（`SetUnitTimeScale`）＋移動速度 0＋停用武器 | **採用**。引導不中斷 |

- 暫停期間玩家的命令：記錄最後一個命令，恢復時執行（`搜打撤規則.md`：暫停可下達下一個指令）。
- 施法中的單位：維持既有規則（暫停轉接不動施法中單位的技能）。

### 10. 預建數值（試玩值）

| 欄位 | 符文學者 | 舊令巡檢機 |
|---|---|---|
| 戰鬥等級／挑戰等級 | 1 | 1 |
| 力量、精準、身法、體質、精神、智力、幸運 | 2、4、4、0、9、16、0 | 4、2、0、4、2、0、0 |
| 最大生命 | 42 | 62 |
| 武器 | 符文杖：單手，4 + 近戰攻擊力 × 0.5 | 定向燈衝擊：雙手，6 + 近戰攻擊力 × 0.75 |
| 護甲 | 0 | 10 |
| 原始攻擊時間 | 1.5 秒 | 準備 0.8、收招 0.6 秒 |
| 攻擊範圍 | 原生近戰 | 直線，長 160、寬 80 |

- 符文學者的智力、精神、體質沿用技能系統的值；其他一級屬性為新的試玩值。
- 全部值都需要遊戲內調整。不得視為已平衡的資料。

## 驗證結果（2026-11-04）

C5 全部通過：預告可以閃避、檢定結果有顯示、失能與擊倒正確、暫停時全部停止（含引導不中斷、恢復後只執行最後命令）。記錄見 `implementation/PLAN.md`。

C5 期間加入原生生命防護（`life-guard/PLAN.md`）：無敵擋不住負數恢復與直接寫入，所以全部原生傷害歸零、關閉原生恢復，並每 50 毫秒修正血條。

## 已知限制

- 玩家普通攻擊的閃避依出手時的距離判定，不是投射物碰撞。目標在出手瞬間仍在範圍內就會命中。
- 浮點精度為 32 位元，不是真正的固定小數。
