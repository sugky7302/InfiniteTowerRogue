# C3 實驗地圖設計

## 範圍

建立戰術暫停與近戰閃避的遊戲內實驗。使用者填寫觀察表後，才決定正式整合方式。主設計保持未完成。

## 實作

1. 在 app 建立實驗入口，以 compiletime 建立四種 hfoo 衍生單位。預設緩衝從 hfoo 讀取，小緩衝使用 25。明確寫入緩衝、傷害點 0.5 秒及間隔 1.5 秒。
2. 暫停先取得一次世界時鐘暫停，再列舉全部存活單位。逐筆保存改變前的值，恢復時反向執行。重複暫停直接返回。暫停中換方法時先還原單位，再套用新方法，保留世界時鐘暫停。
3. 方法 2 停用兩個武器欄位。2b 清空兩個武器的目標遮罩。只改變原本非零或啟用的欄位，保存成功寫入的還原工作。
4. 原生介面沒有動作速度讀取函式。在模組載入時追蹤 SetUnitTimeScale。未曾寫入的單位使用引擎初始值 1。現有來源與地圖沒有其他動作速度寫入。
5. 在 entities/combat 新增純近戰距離判定，範圍包含雙方碰撞半徑與容許值。等於上限時命中。使用既有安全算術。
6. 僅統計 A、B 間的原生攻擊與傷害事件。走開指令使用世界時鐘幀來源，抵達後重新攻擊。重建單位會取消走開並清除統計，暫停中重建會先還原舊快照，再把目前方法套用到新單位。
7. 在實作記錄加入指令、操作步驟、空白觀察表及工具驗證結果。

## 驗證

執行單元測試、格式檢查、分層檢查、建置、全部指定 Lua 驗證及技能地圖產物測試。另新增最終 MPQ 檢查，逐一確認四種單位的原始物件欄位。依使用者要求，跳過會啟動遊戲的 npm run test。

此設計保持未完成，直到使用者完成遊戲觀察。實驗成果與工具結果記錄於 ../implementation/PLAN.md。
