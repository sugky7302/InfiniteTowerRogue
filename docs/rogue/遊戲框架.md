# 遊戲框架：沉冠遠征

本頁是[[故事/rogue/大綱|沉冠遠征]]的唯一根級框架。它只組裝本作玩法，不改寫共用資料庫。其他設計頁展開本頁規則。若兩頁衝突，必須先修正草案，不能把衝突交給實作者猜測。

## 核心承諾

- 已確認：單人 PvE 優先，後續加入合作。
- 建議：俯視即時戰鬥，可戰術暫停。暫停同時停止敵人、撤離及世界時間。
- 建議：以維蘭瑟沉冠帶為舞台，每次活動約12至18分鐘。
- 玩家反覆選擇目標、路線、戰鬥方法與撤離時機。
- 首版只驗證一張地圖、普通物品階級和少量合法技能配置。
- 首版不展開 PvP、玩家交易市場、賽季清檔或五至七階玩法。

本稿中的時間、容量、價格與目標比例都是試玩參數，並非已驗證平衡值。操作方式與損失程度仍待使用者確認。

### 世界規則

- [[知識體系]]、[[精通]]、[[技能]]、[[職業系統]]及[[資源]]。
- [[戰鬥規則]]、[[時間與距離]]、[[傷害]]及[[潛行與偵測]]。
- [[魔導武裝]]、[[詞綴]]及[[裝備體驗]]。
- 世界內容依[[故事/維蘭瑟/維蘭瑟世界契約|維蘭瑟世界契約]]。本作區域不提供跨世界交通。

### 遊戲模組

- 主導模組：探索。它管理路線、潮汐、可達區域、活動結束與撤離。
- 支援模組：戰鬥、潛入與追緝、研究、製作與交易、組織與據點。
- 調查與派系選擇先用通用行動解析及故事旗標處理。首版不另建完整社交或推理子系統。

### 掉落機制

- 選用方式：簡化。沿用來源完成時點、四層產出、批次、研究進度與唯一結算規則。
- 經濟節奏：戰役型。首版只測普通材料及固定劇情成果；精良以上內容在後續來源表驗證後加入。
- 研究進度範圍：玩家紀錄層。保底鍵維持「來源家族識別＋獎勵層級」。
- 活動契約接縫：完成來源即生成並保存來源結果。撤離只搬移既有實體，不能再次抽取。
- 獎勵剖面：物品先進活動背包；合格來源研究進度立即保存。任務報酬在帶回證物並交付後產生。
- 本作事前公開保存例外：救難撤出及敗北時，攜行實體物依救難契約被棄置或扣留；正常撤離則保留攜出物。此例外使用[[掉落機制]]容許的活動保存規則，不改變共用抽取算法。
- 首版來源草案見[[故事/rogue/關卡/01-灰潮泵站|灰潮泵站]]。它還不是正式來源 JSON，也尚未完成隨機掉落模擬。

### 內容套件

- 世界：[[故事/維蘭瑟/維蘭瑟|維蘭瑟]]的沉冠帶，以及本作新增的回燈港與灰潮泵站。
- 成長：選用既有低階知識、精通與職業入口；不自動納入全部500項職業。
- 戰鬥：[[故事/rogue/成長與裝備|成長與裝備]]列出的候選配置。正式可玩名單仍須逐項核對能力與負載。
- 不從[[翠谷星遊戲框架]]直接移植白環投影。維蘭瑟與翠谷星目前沒有已確認通道。

## 四層核心循環

### 操作循環

- 重複行動：觀察預告，選擇移動、掩護、攻擊、互動或撤離。
- 即時回饋：生命、戰鬥資源、聲響、敵人狀態、攜行物與潮汐改變。
- 成功、失敗與中斷：完成才產生對應成果。中斷會花掉已明列的時間或資源，不會重抽已生成的獎勵。

### 活動循環

- 開始：選擇一項委託與裝備，閱讀潮汐、出口和損失規則。
- 推進：探索、取得物品、修復捷徑，反覆判斷是否繼續深入。
- 結束：正常撤離、主動求援、敗北、超時或存檔暫停。
- 輸出：攜出物、觀測記錄、來源研究進度與已發生的世界變化。

### 成長循環

- 研究帶回的樣本，形成知識或提高既有知識等級。
- 用材料製作裝備與鑲嵌物，再檢查載體、刻印容量、調諧及技能負載。
- 新成長優先提供路線、工具與組合選擇。純傷害與防禦提升必須另行標示。

### 戰役循環

- 校驗三組證據，決定地方設施與知識的管理方式。
- 已修復設施、居民承諾及已公開資料跨遠征保留。
- 完成終局後保留角色與倉庫，開放收尾委託。新戰役另開紀錄，不強制刪除舊檔。

## 主要活動契約

| 欄位 | 定義 |
|---|---|
| 進入條件 | 角色可行動；有合法配置；已簽救難契約；地圖在觀測與救難涵蓋區內 |
| 活動目標 | 自選一項委託。玩家可先撤離再於下一次完成委託 |
| 重複選擇 | 搜索或趕路、消耗或保存材料、戰鬥或迂迴、深入或撤離 |
| 推進壓力 | 18分鐘潮汐期限、有限補給、攜行容量、聲響引起的局部追緝 |
| 退出條件 | 出口倒數完成；求援、失能或超時觸發救難結算；暫停退出則保存進行中活動 |
| 活動產出 | 帶回物品與證物、已形成知識、已登錄配方、來源研究進度、世界旗標 |

## 模組組合

| 模組 | 擁有的狀態 | 主要選擇與壓力 | 向其他模組輸出 |
|---|---|---|---|
| 探索 | 地圖連通、潮汐、出口、活動階段 | 路線與撤離；時間和容量有限 | 可達目標、活動結果 |
| 戰鬥 | 生命、戰鬥資源、技能事件、傷害與狀態 | 攻擊、防禦、撤步；補給與暴露風險 | 來源完成、受傷、聲響 |
| 潛入與追緝 | 每名觀察者的偵測、警戒與最後已知位置 | 隱蔽、引開、斷開視線；追兵持續接近 | 可接近的目標與追緝壓力 |
| 研究 | 待解析載體、前置、解析進度 | 樣本用於研究或另作他用；材料有限 | 完整知識與可用方法 |
| 製作與交易 | 實體庫存、材料消耗、裝備配置 | 整備或保留；本金與材料有限 | 合法裝備、工具及消耗品 |
| 組織與據點 | 工坊、研究台、航標工程狀態 | 優先投資哪項服務；工程材料有限 | 可用服務和額外入口 |

來源結算只擁有獎勵生成紀錄。庫存只擁有物品位置與占用。研究不能直接複製物品，戰鬥不能直接增加倉庫。

| 範圍 | 保留內容 | 重置時點 |
|---|---|---|

| 角色 | 已形成知識、精通、職業、天賦、生命與已綁定的個人狀態 | 治療或合法角色事件；一般敗北不刪除成長 |
| 世界 | 倉庫、地方設施、委託交付、居民承諾、知識公開結果 | 僅由相應事件改變；隨機配置不可覆蓋 |

## 驗證情境

### 正常循環

玩家取到記錄匣，選擇返回原碼頭。撤離後，銅線進倉庫，記錄匣交付委託。來源研究進度只加一次。玩家把銅線用於下一次出發的工具。

### 失敗或撤退

玩家完成一處來源後失能。該來源的研究進度保留，未攜出的樣本及自帶武器遺失。已讀懂並登錄的配方保留。玩家能借用普通裝備重試。

### 模組交互

玩家用唯一閥芯修好泵站，放棄把它帶回製作。修復打開第二出口，也停止一條噴流。玩家以較安全的返回路線帶走樣本，研究後取得新的機關處理方法。

驗收案例見[[測試/故事/沉冠遠征-搜打撤|搜打撤驗收規格]]。這些情境目前是設計推演，不是遊戲實測結果。
