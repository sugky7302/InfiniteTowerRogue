# 沉冠遠征：搜打撤規則

返回[[故事/rogue/大綱|大綱]]。本頁展開[[故事/rogue/遊戲框架|遊戲框架]]的單人活動，不自行更改持久狀態。

## 用語

| 用語 | 本作意思 |
|---|---|
| 遠征 | 從進場到正常撤離或救難結算的一次活動 |
| 正常撤離 | 在合法出口完成倒數，把實際攜帶物帶回港口 |
| 提前撤退 | 委託未完成前，仍以正常撤離方式離場 |
| 主動求援 | 放棄攜行物，由救難隊接回人物 |
| 失能 | 角色失去行動能力，但尚未死亡 |
| 來源 | 一個可完成的搜索物、採集點、敵群或事件 |
| 調校 | 由合法設備提供、只在本次遠征內維持的裝備運作設定 |
| 潮封 | 潮水與回流使本次一般作業窗口結束 |

## 出發

整備畫面依序顯示四項內容：

1. 本次目標，以及一個可選的次要目標。
2. 帶入的裝備、補給與「若救難撤出會失去什麼」。
3. 已知出口、潮封時間及本次可觀察異常。
4. 裝備是否合法，以及已知缺少的能力、資源或工具。

借用普通裝備沒有出發費。玩家不能因倉庫清空而無法開始下一次遠征。

選擇目標只在地圖標示來源線索，不提高該目標的隱藏掉落率。玩家進場後仍可改變路線或提前撤退。

## 時間與壓力

首版每次遠征有18分鐘活動時間。時間只在遊戲世界運行時前進。選單暫停、戰術暫停及離線時間都不推進潮汐，也不恢復資源。

| 活動時間 | 世界變化 | 玩家可見資訊 |
|---|---|---|
| 0至6分鐘 | 外圍穩定，主要通道開放 | 全程顯示潮封倒數及已知出口 |
| 6至12分鐘 | 部分低窪支路出現回流 | 提前30秒顯示聲音、方向標記與文字警告 |
| 12至18分鐘 | 低窪支路封閉，返程需走高架通道 | 地圖標示不可通行路段；主要出口仍可用 |
| 16分鐘、17分30秒 | 發出兩次撤離提醒 | 顯示最近已知出口及估計返回時間 |
| 18分鐘 | 結束一般作業窗口 | 未完成正常撤離者進入救難結算 |

潮汐固定改變已公告的地形與機關。它不依玩家背包價值偷偷加速，也不讓敵人無限增加生命值。

至少一個無消耗品門檻的出口，在潮封前始終可由主要活動區抵達。地圖可以要求繞路，不能隨機封死全部出口。

## 搜索與攜行

試玩背包有12格。穿戴中的主武器、副手、防具與工具另有位置，不占背包格。這些位置只是攜行配置，仍須通過既有穿戴及調諧條件。

- 同一物品且階級、完整性、污染、綁定與期限相同，才可堆疊。一般材料每格最多10單位。
- 大型標誌性材料占2格。不能用拆分堆疊把它變成1格。
- 補給和備用裝備占背包格。普通消耗品預設每格最多3份。
- 占用9至12格時，普通移動速度乘0.85。介面在拾取前顯示結果。放下物品後立即重算。
- 不允許超過12格後繼續硬塞。玩家須丟棄、替換或留在現場。
- 每次只接一項主要委託。它的必要證物使用獨立任務夾，不占12格；首版每份委託最多一件證物。

任務夾只解決容量問題。救難撤出時，未交付的實體證物仍會遺失。必要情報則已記錄，下一次可從確定來源重取證物。

搜索開始前顯示所需時間。完成後才結算來源。普通搜索以4秒作試玩值；危險機關另列時間。中斷不會產生半份獎勵，再開始也不能重抽已完成的來源。

背包不足的物品留在來源位置，期限為本次潮封。玩家可以返回取走。正常撤離只帶走背包與穿戴物，不把地圖上的所有物品一起送回港。

保底獎勵在回燈港領取。倉庫不足時保留未領取狀態，不扣進度。不可重複配方可在現場讀取並登錄，不會因背包滿而銷毀。

## 戰鬥與操作建議

建議採俯視即時操作：移動、瞄準、普通攻擊、閃避、兩個主動技能及工具。兩個技能是首版介面範圍，不代表角色只能掌握兩項知識。

敵人攻擊依序顯示準備、作用及收招。預告至少提供形狀與聲音，不能只靠顏色。普通敵人優先測試約0.8秒的明顯預告；首領大範圍攻擊優先測試約1.5秒預告。

戰術暫停可用來查看物品、敵情與下達下一個指令。暫停不執行搜索、治療、換裝、倒數、回魔或冷卻。解除暫停後，行動才依既有秒數執行。

底層保留[[戰鬥規則]]的連續時間，以及技能原有時間、距離、傷害與狀態。首版規則推演先保留技能明列的檢定。動作命中是否取代部分命中檢定仍是待決策事項，不能先刪掉D20或在碰撞命中後無提示追加第二次失敗。

技能投射物碰撞、角色閃避窗和鏡頭比例尚未實測。這些缺口不阻止紙上檢驗路線與撤離，但阻止宣稱戰鬥規格已可直接實作。

## 聲響與追緝

| 行為 | 對應訊號 | 可能後果 |
|---|---|---|
| 走過碎玻璃、拆開金屬箱 | 聲音由所在位置傳播 | 聽見的巡邏靠近調查 |
| 使用火焰或強光術式 | 可見閃光、聲音、熱與殘留 | 有對應感官的敵人取得線索 |
| 躲進陰影 | 降低視覺輪廓 | 不會同時消除腳步或氣味 |
| 擲出誘餌 | 另一位置出現聲響 | 敵人轉向調查；不保證所有敵人受騙 |

每名敵人各自記錄「未察覺、調查、追擊、失去目標」。進入調查只取得聲源位置，不立即取得玩家的即時位置。敵人必須重新取得合法訊號才能持續追擊。

首版每個區域最多啟用一組預先配置的增援。增援由入口實際進場。停止聲響不會刪除已到場敵人，也不會讓全地圖敵人自動知道玩家位置。

## 撤離

首版有兩種出口。兩者都可提前使用，不要求先擊敗首領。

| 出口 | 啟用條件 | 倒數 | 取捨 |
|---|---|---:|---|
| 原碼頭 | 一直可用；須返回入口區 | 12秒 | 不耗材料，但深入後回程較長 |
| 北側碼頭 | 完成泵站修復並抵達碼頭 | 18秒 | 路線較短，但需先花材料和修復時間 |

出口倒數期間，玩家可以移動、攻擊和防禦，但必須留在標記區內。受傷本身不重置倒數。離開區域或失能會取消倒數；重新啟動時從完整秒數開始。

第一版不以「附近仍有任何敵人」阻止撤離。玩家能藉控制與走位爭取離場，不必為了搜尋一隻卡牆敵人而失敗。

同一時間點按以下順序結算：先處理傷害及失能，再檢查撤離完成，最後處理潮封。因此，在18分00秒仍可行動且倒數剛好完成者正常撤離；同時失能者改為救難結算。

## 敗北與救難的原因

首版活動區只開放已完成測繪、設有救難通道的地方。港口提供一次使用的救難護具、定位標記與後備救難隊。護具在人物失能時隔離短期傷害並維持呼吸，等待船隊沿已知通道接回。

護具是本作待驗證的有限裝備設定。它不傳送角色，不複製記憶，也不能復活真正死亡的人。首版不配置會繞過護具而造成即死的無預警地形。超出救難條件的新區域，必須另訂規則後才能開放。

救難隊優先接回人物。為了移動傷者，隊伍會卸下武器、工具、背包及任務匣。後續回收財物歸救難基金，用來補充護具與維持基礎醫療。出發前公開此契約。

| 結果 | 正常撤離 | 失能、超時或主動求援 |
|---|---|---|
| 自帶武器、防具、工具 | 保留 | 遺失 |
| 未消耗補給與本次實體戰利品 | 保留 | 遺失 |
| 已形成知識與精通 | 保留 | 保留 |
| 已讀取並登錄的陣列、共振配方 | 保留 | 保留 |
| 未解析樣本及未讀取文件實體 | 入庫 | 遺失 |
| 合格來源研究進度 | 保留 | 保留 |
| 已完成的現場工程 | 保留 | 保留 |
| 只有接觸、尚未完成的來源 | 不結算 | 不結算 |

回港後恢復基本行動能力。首版不另疊加跨局能力減益、救援債務或強制現實等待。風險集中在攜行財物和錯失機會。

## 存檔、中止與重複結算

- 「暫停並退出」保存同一遠征，包含時間、位置、敵情、已消耗物、來源結果與臨時調校。
- 「放棄遠征並求援」明示物品損失，確認後採救難結算。
- 程式異常中止應恢復最近已完整保存的活動狀態。該狀態中的亂數與來源結果必須一起恢復。
- 同一活動不能既標記正常撤離，又再次執行救難或再次入庫。
- 來源完成與撤離入庫使用不同結算身分。重送只取得原結果。
- 關鍵狀態保存失敗時，先顯示尚未結算，不得一邊顯示成功一邊重抽或重發物品。

這些是資料行為契約，不指定資料庫、引擎或網路架構。具體保存頻率與異常恢復技術需在實作規劃時決定。

## 介面必須回答的問題

| 畫面 | 玩家應立即知道 |
|---|---|
| 整備 | 這次目標、帶入成本、敗北損失、免費替代配置 |
| 探索 | 生命與資源、潮封倒數、背包占用、最近已知出口 |
| 戰利品 | 可用於什麼、占幾格、是否關係到追蹤目標、是否改變移動速度 |
| 撤離 | 啟用條件、剩餘秒數、取消原因、目前將帶走什麼 |
| 結算 | 已入庫、已遺失、已保留進度，以及下一個可執行目標 |

不得把全部裝備價值壓成單一戰力分數。快速資訊先顯示用途與差異，進階結構遵循[[裝備體驗]]分層展開。
