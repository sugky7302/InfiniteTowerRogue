# 沉冠遠征：後續合作模式

返回[[故事/rogue/大綱|大綱]]。使用者已確認後續加入合作，但尚未決定人數。本稿建議先做雙人 PvE。

## 合作應增加什麼

雙人合作應增加「分工帶物、交替掩護、修復與守備、救人或撤離」的選擇。兩個人不應只是把同一套單人流程做得更快。

所有必要目標仍有單人解法。雙人機關可以縮短暴露時間，不能成為主線唯一入口。任何職業都不應被指定為必備治療位。

## 共同活動與個人狀態

| 內容 | 建議所有權 | 分配原則 |
|---|---|---|
| 地圖、潮汐、首領、現場機關 | 同一場活動 | 不因第二名玩家進場重建 |
| 攜行物與穿戴物 | 個人物品位置 | 轉交是同一實體移動，不能複製 |
| 戰利品實體 | 來源產生一次 | 按既有需求、收藏、放棄流程分配，或雙方事前同意指定 |
| 來源研究進度 | 每名合格玩家 | 結果確定前已加入，完成時仍是活動成員；已取得進度保留 |
| 知識形成與職業 | 每名角色 | 各自滿足前置與實踐，不由同伴自動授予 |
| 世界工程與委託 | 主持者的世界 | 訪客帶回自身物品與個人進度；不複製主持者的世界旗標 |

後續合作來源須另算兩人的每人收益。不能既複製共享掉落，又保留完整個人獎勵而讓產量翻倍。也不能只把敵人生命翻倍卻不評估每人材料成本。

## 倒地與撤離

- 合作版將單人的立即救難結算改為有限倒地等待。建議倒地窗口45秒，扶起需8秒連續操作。
- 扶起中斷時進度歸零。材料在成功扶起時消耗一份救護包。
- 首版合作測試每人每場最多被扶起一次。再次失能或等待逾時，該角色進入救難結算。
- 隊友可以救人、掩護或先撤離。已撤離角色不能返回同一活動。
- 撤離按個人結算。完成倒數者攜出自己的物品；未完成者繼續留在場內。
- 交給隊友的物品由實際攜出者入庫。原主人不能再領一份。歸港後若要返還，須再次轉交同一實體。
- 委託證物只存在一件。由誰攜出、是否能替主持者交付，必須在接任務時列明；初版建議由主持者攜出及交付。

救護包、倒地狀態與護具時間都是新增合作契約，需要另行驗證。不能在未啟用合作模式時改動單人的失能規則。

## 暫停、離線與異常

- 合作時只有雙方同意才能暫停整個世界。背包閱讀本身不暫停。
- 訪客斷線後，人物在原地保留最多60秒，不能由斷線取得無敵或自動撤離。
- 在期限內重連，接回同一角色與物品狀態。若期限內失能，仍按當下規則處理。
- 期限結束仍未重連，訪客進入救難結算。首輪合作測試不開放從斷線人物複製或取走其裝備。
- 主持者離線，保存並暫停整場活動。雙方回到同一活動續行。第一版不承諾主持權轉移。
- 已保存的來源獎勵不因重連重發。任一已結算撤離結果都不能回滾成可再取一次的背包。

這些是預期行為。連線架構、儲存權威、身分驗證與異常恢復方式尚未選定，需在合作實作前另建技術計畫。

## 何時開始合作驗證

先完成[[測試/故事/沉冠遠征-搜打撤|單人驗收]]中的正常循環、失敗復原、撤離競態與重複結算檢查，再做以下雙人案例：

1. 甲守住通道，乙完成修復，兩人各有明確決策。
2. 兩人同時拾取一件核心，最後只有一份實體。
3. 甲帶走乙轉交的樣本，乙失能；樣本只進甲的倉庫。
4. 撤離前一人斷線，重連後不重發獎勵、不重抽來源。
5. 任一配置可單獨完成主線，不因缺少指定職業而卡住。
