# M2 WC3 時間修正

- 依使用者提供的 WC3 實測修正數字模型。時間保存為整數毫秒。
- 秒數上限為 2147483 秒。整數毫秒上限為 2147483000。加法先檢查剩餘容量。
- 秒數先拆成整數秒與小數秒，再換算毫秒，避免大數乘法先成為低精度浮點數。
- 時鐘驅動器分開量時與任務喚醒。閒置仍量時，暫停才停止。量時計時器每 60 秒重設，並累加整數毫秒。
- interval 使用整數毫秒週期與絕對到期時間，不累加浮點秒。
- 保留原始碼既有註解。只移除 main.ts 的數字探測匯入與 hook。
- 加入 float32 原生計時器模擬、int32 範圍檢查與原始碼常數檢查。
- 執行單元測試、建置、獨立 TSTL 轉譯及 Fengari 驗證。遊戲內驗證由使用者執行。
