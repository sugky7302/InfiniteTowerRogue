## 類型、核心循環與地形空間

**腳本確認：**開始選單提供「聖靈守護戰（防守）」與「聖靈爭奪戰（PK）」。防守有難度選單；PK 另有分組與自由模式。本篇以防守及角色成長作主要參考，不推定所有模式同時啟用。[S2]

**設計推論：**防守模式形成兩條相互競爭的循環。第一條是「迎擊進攻 → 守住目標 → 準備下一波」。第二條是「離開防線 → 做任務或取得裝備 → 提升角色 → 返回防守」。程式會增加波次、建立進攻單位、下達攻擊指定區域的命令，並提示敵人名稱。難度分支對波次的判定不同，因此不能把本圖概括成固定相同的總波數。[S3]

**資料確認：**最終地形標頭是 256 × 192 格，含 16 種地表類型。格數不代表全圖可通行。[S10]

**文字資料：**任務串連幽州、南郡、西夏、北州、天晶洞及多處野外地點。送信要求從幽州到南郡。包包果任務要求採集後再送貨返回。中土蘑菇則分散到朱雀巢穴、魚妖谷、南郡東方與迷荒洞。空間用途包含城鎮交付、野外採集、洞穴門檻及救援撤離，並非只有一條進攻道路。[S5]

**設計推論：**多地點任務會讓離開防線成為時間選擇。這種張力可移到爬塔遊戲：主路推進下一層；支路提供成長資源，但消耗備戰時間。本輪未量測原圖路程、刷怪速度或安全回程時間。

## 三個武學案例

### 1. 背刺：朝向判定比名稱更具體

**文字資料：**`A00Q` 為匕首技能背刺。提示稱從背後發動有雙倍效果，威力受筋骨與身法影響。[S6]

**腳本確認：**程式以目標朝向，取其後方 200 距離的位置，再建立 220 × 220 的矩形。它檢查施術者是否在該區域。所查後方分支使用 `2.50 × 力量 + 3.20 × 敏捷`；一般分支使用 `1.25 × 力量 + 1.60 × 敏捷`，之後還乘其他角色係數。另有條件分支可使用較高係數，所以不能宣稱只有背後一種增傷來源。[S7]

**限制：**提示說筋骨影響較大，但此式的敏捷係數較高。本輪未完整追查三項屬性的所有換算。改作前應用測試角色逐項增加屬性，量測最終傷害。

**改作提案：**爬塔首領轉身前先給明確預告。玩家可用繞背換取增傷。首版使用角度或區域其中一種判定，並把有效範圍畫在測試模式中。

### 2. 鬼道二式・挑：技能是一張接續關係圖

**文字資料：**`A00I` 對前方直線敵人造成傷害。提示列出可接在一式、三式、五式之後，並可接三式或四式。`A00J` 一式則標示沒有前式，可接二式或三式。這是明確的連招關係資料，不是泛稱「有連擊」。本輪未核對所有接續條件及時間窗。[S6]

**改作提案：**每招保存「可用前式」「可接後式」「有效時間」。成功命中才寫入連招狀態。介面只高亮當前合法招式。第一版保留三招與兩條分支，先測中斷、死亡與換層是否清除狀態。

### 3. 同歸刀法：用自身生命換取百分比壓力

**文字資料：**`A00C` 提示每次攻擊扣除目標當時生命的六分之一，同時扣除自身生命的五分之一。這是提示值。尚未確認實際扣血的基準、致死限制、首領抗性與連續觸發條件。[S6]

**設計推論：**若依當前生命計算，初段削血強，尾段收尾弱。自身代價又使高頻攻擊不必然是安全策略。

**改作提案：**先限定為主動的一次攻擊。明確選擇當前生命或最大生命。首領設單次上限。面板預告自身代價，驗收時同時記錄兩個單位的前後生命值。

## 裝備構築與回饋

**文字資料：**蓬萊冰甲的一組物件提示列防禦 320、生命上限 12,000、身法 45，並列出蓬萊頭盔、護腿與護手。仙羽戰衣的一組提示則列生命上限 4,000、法術係數 10%、內力 60，並列仙羽披風、圓盾與飛靴。它們提供不同成長方向。但只看列名，不能宣稱完整套裝加成已驗證；同名物件也可能有不同階段。[S8]

**設計推論：**武器係數、屬性權重、裝備強化與套裝收集，會同時影響選擇。深度來自相互配合，但也增加比較負擔。原圖的 `+link` 能列出係數，是把隱藏成長資料交回玩家的重要做法。[S9]

**文字資料：**常用指令還有狩獵情報、鏡頭鎖定、天氣與物品清理開關。[S4] **改作提案：**自製遊戲先做一頁角色摘要。每項數值顯示來源與受影響技能。環境特效開關與戰鬥效果分開，避免關掉天氣時也失去必要警示。

強化系統的取捨最明顯。成功率降低與失敗退級會消耗資源，也可能讓玩家停止嘗試。**改作提案：**首版先做保證成功的三階強化。若要加入機率，再加入失敗保底或退級保護，並顯示期望成本。這是改作選擇，不是對原圖平衡的實測評價。

## 爬塔最小原型與驗收

以下皆為**改作提案**。做五層與一個防守據點。每次防守後，玩家選擇直接上樓，或進一個支路任務。只保留劍、匕首、法杖三種武器方向。先做背刺、三招連段與一次捨身攻擊。裝備只設三階確定強化及一種回收材料。

| 驗收項目 | 明確通過條件 |
|---|---|
| 防守節奏 | 五次進攻均有波次、方向及準備時間提示。最後一隻敵人不會使流程停住。 |
| 支路成本 | 玩家外出時能看見距下次進攻的時間。回程入口不被任務永久封鎖。 |
| 背刺判定 | 正面、背面、邊界各測一次。目標轉身時判定與畫面方向一致。 |
| 連招 | 合法前式可以接續。逾時、換層及死亡後不能沿用舊狀態。 |
| 捨身代價 | 目標及自身的前後生命符合資料表。低生命與首領上限另測。 |
| 任務組合 | 兩個任務的四種接受組合都有明確結果。救援人物只建立一次。 |
| 裝備回收 | 提煉消耗原裝備且只給一次材料。取消操作不改資料。 |
| 數值回饋 | 技能提示、角色摘要與實際運算來自同一份設定。屬性各加一點的結果可查。 |

原型先驗證「外出成長是否值得承擔回防成本」。若這個選擇不成立，增加任務、裝備與武學數量只會增加內容量，不能補足核心決策。
