# i18n：多語言文字

## 目的

- 玩家輸入 `-lang <語言代碼>`，切換自己看到的文字。
- 物件編輯器中能在執行時修改的文字（技能、物品、單位名稱等），一次全部切換。
- 程式中的顯示文字也一起切換。
- 程式位置：`src/shared/i18n/`。

## 已決策（2026-10-26）

| 問題 | 決策 |
|---|---|
| 第一版語言 | `zh-TW`、`zh-CN`、`en-US`。 |
| 預設語言 | 依用戶端語言（`BlzGetLocale()`）。 |
| 物件文字的來源 | 在世界編輯器（WE）中以 `zh-TW` 撰寫。建置腳本讀出文字，產生其他語言的翻譯檔範本。 |
| 執行時無法修改的文字 | 接受。這些文字只依用戶端語言自動切換。 |
| RxWC3 與 logger 的錯誤訊息 | 不翻譯。固定使用正體中文。 |

## 用語

| 用語 | 意思 |
|---|---|
| 基準語言 | `zh-TW`。其他語言的鍵以它為準。 |
| 翻譯鍵 | 一段文字的識別碼，例如 `extract.countdown`。 |
| 物件文字鍵 | 物件編輯器文字的識別碼：`<類別>:<代碼>:<欄位>[:<等級>]`，例如 `ability:A000:tip:1`。 |

## 設計

### 1. 語言是本地狀態

- 每名玩家的語言只影響自己的畫面，所以語言使用 RxWC3 的本地 Signal：`localSignal<Locale>`。
- 套用文字的程式使用 `localEffect`。
- 翻譯後的文字只能用於顯示。遊戲邏輯不得讀取或比較翻譯文字，否則多人時會不同步（desync）。
- RxWC3 的執行時檢查（`config.checkSignalSync`）會回報「同步計算讀取本地語言」的錯誤。

### 2. 切換流程

1. 地圖啟動時，讀取 `BlzGetLocale()`，對應到三種語言之一。不屬於三種語言時，使用 `zh-TW`。
2. 如果本地偏好檔存在，改用偏好檔的語言（見第 5 節）。
3. 玩家輸入 `-lang zh-TW`、`-lang zh-CN` 或 `-lang en-US`：
   - `onPlayerChat`（RxWC3 M3）收到同步的聊天事件。
   - `forLocalPlayer`（RxWC3 M4）只讓輸入者的用戶端繼續。
   - 寫入本地的語言 Signal。
4. 語言 Signal 改變時，`localEffect` 一次套用全部文字。
5. 語言代碼不正確時，只對輸入者顯示可用的語言清單。

### 3. 兩層切換

| 層 | 方式 | 涵蓋 |
|---|---|---|
| 自動層 | 地圖內的各語言字串檔（Reforged `_Locales`）。遊戲依用戶端語言選擇。 | 載入畫面、地圖說明等執行時不能修改的文字 |
| 執行時層 | 原生函式覆蓋文字 | 下表的文字 |

執行時層的原生函式（每一項都要在遊戲中驗證）：

| 文字 | 原生函式 | 套用時機 |
|---|---|---|
| 技能名稱、說明 | `BlzSetAbilityTooltip`、`BlzSetAbilityExtendedTooltip` 等，每個等級分別設定 | 切換語言時套用全部技能 |
| 物品名稱、說明 | `BlzSetItemName`、`BlzSetItemTooltip`、`BlzSetItemExtendedTooltip` 等 | 只能設定單一物品實例。切換語言時套用現有物品；物品建立時套用目前語言 |
| 單位名稱、英雄名 | `BlzSetUnitName`、`BlzSetHeroProperName` | 只能設定單一單位實例。時機同物品 |
| 自訂介面 | `BlzFrameSetText` | 由 `localComputed` 與 `localEffect` 更新 |

### 4. 翻譯資料

物件文字：

1. 你在 WE 中用 `zh-TW` 撰寫物件文字。
2. 建置腳本使用 `war3-objectdata-th` 讀出全部可翻譯欄位，產生 `i18n/<語言>/objects.json`。
   - 新的鍵加入範本，並標記為未翻譯。
   - 已刪除的鍵在建置時列出。
   - 缺少翻譯時，建置輸出警告，執行時使用 `zh-TW`。
3. 建置時把翻譯表寫入 Lua 產物。

程式文字：

- `src/shared/i18n/locales/zh-TW.ts` 定義全部翻譯鍵，它是型別的來源。
- `zh-CN.ts` 與 `en-US.ts` 必須有相同的鍵。缺少鍵時，TypeScript 編譯失敗。
- API：`t("extract.countdown", { sec: 12 })` 傳回目前語言的文字。介面使用 `localComputed(() => t(...))`。

### 5. 語言偏好

- 語言偏好存在本地檔案（`CustomMapData` 下）。
- 語言是本地狀態，所以讀取偏好不需要 `sync`，也不放入存檔碼。

## 相依

| 相依 | 用途 |
|---|---|
| RxWC3 M1.5 | `localSignal`、`localComputed`、`localEffect` |
| RxWC3 M3 | `onPlayerChat` |
| RxWC3 M4 | `forLocalPlayer` |

所以執行時切換在 RxWC3 M4 之後完成。翻譯資料與建置腳本可以先做。
