# 裂牙巢母

裂牙巢母是牙根被青熒礦粉刺激的成年母狼。牠不受邪惡意志控制，而是因持續疼痛、領域壓力與護幼本能變得攻擊性極強。

## 可辨識預告

- 風車木柱留下同一高度的磨牙痕，越靠近巢穴越密集。
- 攻擊前會低頭、後腿踩地，接著沿直線衝刺。
- 強光照到星紋牙時會反射青白光，牠會立刻轉向掩體。

## 戰鬥行為

- 裂牙衝刺：沿直線接敵。撞上障礙時自身失衡。
- 護幼狂暴：幼狼受到傷害後立即提高攻擊壓力。
- 低吼呼群：召回場外狼群。救過羊群或保全狼群的玩家可用行為線索打斷。

## 非戰鬥解法

玩家可誘離巢穴、清除礦粉、治療牙根或把幼狼移到沒有青熒沉積的舊洞。這些方案需要實際工具、樣本或觀測，不由一次安撫檢定直接完成。

## 素材與知識

- 裂牙：可用於工具、箭頭或年齡研究。拔取健康牙齒會永久傷害巢母。
- 星紋牙垢：受損且潔淨的研究樣本，可追查青熒礦來源。
- 行為觀察：連接[[追跡]]、[[感知之方向]]與[[反應]]。
