# 失衡調律核心

失衡調律核心是觀星文明留下的自動環境裝置。它沒有完整人格，只能依舊有目標掃描威脅、重分配星脈能量並修復調律網。回流道錯接使它把所有外洩都誤判成需要提高輸出的能量不足。

## 可辨識預告

- 掃描前，三環燈帶依序照過玩家裝備與最近使用的技能痕跡。
- 空間連接改變前，門框和地面星紋會先出現相同顏色。
- 核心片即將斷開時，所有輸出短暫靜止，隨後朝沒有接地出口的方向集中。

## 戰鬥階段

1. 掃描：記錄玩家重複使用的路徑，生成具有明確來源的對應防護或模擬效果。
2. 逆流：改變能量安全區與空間連接，要求一人操作回流閥、一人處理守衛。
3. 斷片：外殼破裂並露出三枚核心片。繼續攻擊只會增加失控，必須執行封印、修復或拆分方案。

## 限制

- 核心不能創造沒有來源的能量，只能輸送、儲存與轉換星脈輸入。
- 它只能模擬已觀測到且裝置具備合法節點的效果，不能複製天賦、人格或完整知識。
- 切斷輸入會停止大部分攻擊，也會讓照明、門鎖與安全出口失效。

## 素材與知識

- 星紋晶片：保存局部符文狀態。
- 調律核心片：多頻能量重分配載體，只能在終局安全取得。
