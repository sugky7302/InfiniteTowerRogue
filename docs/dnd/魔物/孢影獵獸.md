# 孢影獵獸

孢影獵獸是與大型菌群共生的伏擊獸。菌絲網把地面振動與氣味傳回獵獸，使牠在濃霧中仍能追蹤獵物。牠並不能直接讀取思想。

## 可辨識預告

- 孢霧在牠移動前先沿地面形成細長渦流。
- 菌絲節點受到踩踏時，遠處會傳來一次低沉回聲。
- 獵獸準備孢爆時背部孢囊先膨脹，附近火光變成暗紅。

## 戰鬥行為

- 孢影隔離：在兩名玩家之間升起高濃度孢霧，切斷喊話與視線。
- 菌網伏擊：從未破壞的感知節點旁接敵。
- 孢塵爆：向近距區域釋放孢塵。遇明火可能提早爆燃並傷及所有附近目標。

## 非戰鬥解法

玩家可切斷菌絲節點、改變水流、以受控煙霧驅離，或修復孢泉的低濕區讓菌群退回原棲地。單純燒毀森林能趕走獵獸，但會產生永久焦地。

## 素材與知識

- 孢囊膜：用作濾材與樣本包。
- 菌絲節點：研究[[感知網]]與[[傳感]]，受損節點只能提供部分碎片。
- 孢毒觀察：連接[[化感]]、[[流動之擴散]]與[[代謝]]。
