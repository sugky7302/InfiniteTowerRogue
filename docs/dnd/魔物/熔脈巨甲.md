# 熔脈巨甲

熔脈巨甲是以高溫礦物築殼的群居生物。成年巨甲會把過熱回流道當作孵化場，背甲能儲存熱與衝擊，再從腹部裂隙洩放。

## 可辨識預告

- 背甲縫隙由暗紅逐步變白，表示儲能接近上限。
- 洩能前會抬高身體，腹部發出規律三次震動。
- 同類攻擊連續命中時，對應殼片會越來越亮。

## 戰鬥行為

- 背甲承載：正面與背面受到的衝擊大多轉為過載計量。
- 熔浪洩放：過載滿時向近距與接敵區放出熱浪。
- 護卵推進：把角色推離孵化區。卵群受傷時優先攻擊來源。

## 非戰鬥解法

玩家可關閉回流、建立替代熱源、搬移卵群或逐次接地洩能。移巢需要先理解幼體溫度與巨甲護幼行為，不能只用馴服檢定取代條件。

## 素材與知識

- 巨甲殼片：隔熱、耐衝擊，可用於盾面與爐板。
- 熔脈晶砂：高溫儲能材料，處理不當會因震動放熱。
- 洩能觀察：連接[[能量之儲存]]、[[熱流]]與[[動能]]。
