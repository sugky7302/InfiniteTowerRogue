# 多工手感

## 原型概述

讓核心的兩個低強度操作共享一套手眼節律。它只決定混成方式，不是角色可以直接持有或施展的能力。

## 唯一轉化

只整合相容且可同時執行的操作，不增加額外肢體或免費並行完整技能。

## 相容核心

本原型可與感知、生理、機動、防護、反應、投射、互動及隱匿核心混成。生成時仍須把抽象轉化改寫成符合血脈器官、訊號或規則入口的具體內容。無法保留血脈核心時視為不相容並重抽。

## 五層生成骨架

| 深度 | 成品必須具體化的內容 |
|---:|---|
| 1 顯現 | 以「讓核心的兩個低強度操作共享一套手眼節律」重寫血脈核心的弱被動許可，或授予1級血脈核心知識。不得生成主動技能。 |
| 2 掌握 | 授予一項能穩定「只整合相容且可同時執行的操作，不增加額外肢體或免費並行完整技能」的支援知識，明列輸入、限制與失效條件。 |
| 3 分化 | 從「雙點控制／交替控制／主從控制」選一條，授予造成第一次質變的知識或精通。 |
| 4 融合 | 生成所選流派的天賦精通。展開知識必須全部存在，並照常計入技能構築成本。 |
| 5 成就 | 生成所選流派的標誌性知識、精通或被動例外。保留成本、限制與反制。 |

## 流派生成方向

### 雙點控制

把血脈核心朝「雙點控制」具體化。深度3建立質變知識，深度4形成可重用精通，深度5取得仍有反制的標誌性規則。

### 交替控制

把血脈核心朝「交替控制」具體化。不得與其他方向共用深度3以上成果。

### 主從控制

把血脈核心朝「主從控制」具體化。若成品只需要兩條流派，可以在候選生成時刪除此方向並說明理由。

## 實踐與考驗種子

- 深度2實踐：完成三次不互相干擾的雙操作練習。
- 深度3突破：在一項操作失敗時維持另一項並交代中斷順序。
- 深度4實踐：使用所選流派授予的知識，完成三次結構不同且具有失敗代價的自創技能實踐。
- 深度5突破：以所選流派的自創技能解決一個普通構築無法處理的重大問題，同時承擔並保留其成本或反制。

## 混成限制

成品必須保留血脈核心，不得只增加精準、通用傷害或防禦。任何需要主動啟動、選擇目標或時機、指定方向或支付成本的效果，都必須生成具名知識或精通，再由玩家自行構築技能。
