# 制裁之錘

制裁之錘把凝聚光明投向近距離敵人，命中後使其昏迷6秒。

## 技能根節點

- 基準有效距離：10碼。
- 目標：一名可見敵人。
- 持續時間：6秒。
- 結果：禁止目標主動移動、攻擊、施法、使用技能與主動反應。
- 解除：到期、合法驅散或明載的免疫／解除方式。

## 構築方案

> [[光明]]→[[投射]]→[[昏迷]]

未使用精通時，技能複雜度與迴路負載都為3。

## 行為

1. 檢查目標與距離後投射光明。
2. 命中時建立6秒昏迷。
3. 昏迷不造成傷害，也不等同死亡或定身。
