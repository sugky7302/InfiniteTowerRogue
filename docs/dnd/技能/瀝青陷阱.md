# 瀝青陷阱

瀝青陷阱把感應裝置投向指定地點。第一名敵人靠近後，裝置展開黏滯場域，拖慢區域內的敵人。參考原型為 [Wowhead 技能 187698](https://www.wowhead.com/tw/spell=187698)。

## 技能根節點

- 檢定屬性：精準。
- 消耗：無。
- 原始施法時間：0秒。
- 冷卻時間：30秒。
- 基準有效距離：40碼。
- 投射速度：20碼／秒。
- 感應半徑：8碼。陷阱最多存在60秒。
- 啟動資格：第一名由感應區外進入的敵人。
- 瀝青池：以陷阱為中心半徑8碼，持續30秒。
- 減速：區域內敵人的移動速度乘以0.5。
- 同時上限：每名施放者1個瀝青陷阱。新陷阱成立時舊陷阱失效。

## 行為

1. 檢查落點，投射陷阱並建立8碼感應區。
2. 第一名合格敵人由區域外進入時，消耗陷阱並停止感應。
3. 在陷阱位置建立30秒瀝青場域。
4. 敵人進入瀝青池時取得50%減速，離開時立即失去。再次進入可重新承受。
5. 60秒內未啟動、被破壞或由同一施放者建立新陷阱時，舊陷阱失效。
