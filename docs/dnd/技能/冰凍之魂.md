# 冰凍之魂

冰凍之魂記錄冷酷凜冬期間由施放者命中的敵人，並在合格結束原因發生時命令冰劫與霜奪各自爆炸。

## 技能根節點

- 監聽效果：由同一施放者建立的[[冷酷凜冬]]實例。
- 觸發結束原因：自然到期、敵對驅散。
- 不觸發：主動取消、來源死亡、條件失效、替換刷新。
- 外部來源：[[冰劫]]與[[霜奪]]，各自建立半徑8碼爆炸。
- 每次爆炸傷害：12＋結束時近戰攻擊力×0.4，冰霜傷害。
- 致傷機制：急速降溫、冰晶切割與凍結介質衝擊。
- 記錄目標倍率：2.0，冰凍之魂記錄群組。每個爆炸事件各套用一次。
- 目標：爆炸時區域內仍存活且敵對的個體。兩區重疊可各承受一次。

## 構築方案

生命週期主幹：

> [[凜魂爆發]]→並行：[[期間命中記錄]]／[[效果結束時]]

結束分支再以並行控制節點建立兩條完整路徑：

> ├─[[外部施放來源]]（冰劫）→[[區域]]→[[記錄目標增幅]]
> └─[[外部施放來源]]（霜奪）→[[區域]]→[[記錄目標增幅]]

兩個並行控制節點、重複的來源、區域與修飾皆分別計數，技能複雜度與迴路負載都為11。

## 行為

1. 冷酷凜冬開始時建立本次實例專屬的空集合。
2. 持續期間由施放者命中敵人時，以目標實例去重寫入。
3. 結束時先檢查原因。不在白名單便清除集合且不爆炸。
4. 在同一時點讀取一次[[近戰攻擊力]]，再並行檢查兩個外部來源。
5. 合法來源各自建立半徑8碼區域、篩選目前敵人並結算獨立冰霜傷害。
6. 目標存在於集合時，該次爆炸傷害乘2；離開區域者即使有記錄也不受傷。
7. 兩條分支完成後清除集合。來源失效只取消其自身爆炸。
