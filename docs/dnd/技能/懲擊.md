# 懲擊

懲擊把光明集中投向單一敵人，命中時造成一次神聖傷害。

## 技能根節點

- 法力消耗：法力容量的3%。
- 原始施法時間：1.25秒。
- 基準有效距離：40碼。
- 目標：一名可被投射鎖定的敵人。
- 傷害：8點＋法術強度×0.8，神聖類型。
- 檢定：依[[檢定值]]進行一次技能檢定。

## 構築方案

> [[光明]]→[[投射]]→[[光明之裁擊]]

技能複雜度與迴路負載都為3。

## 行為

1. 檢查目標、距離、投射路徑及法力。
2. 完成施法後投射集中光能。
3. 命中時由[[光明之裁擊]]建立一次神聖傷害事件。
4. 神聖分類本身不附帶相剋、淨化、顯形或控制。
