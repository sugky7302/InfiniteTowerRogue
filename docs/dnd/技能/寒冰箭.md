# 寒冰箭

寒冰箭向遠方敵人投射低溫冰晶，命中時造成冰霜傷害並降低移動速度。

## 技能根節點

- 基準有效距離：40碼。投射速度20碼／秒。
- 傷害：10＋法術強度×0.8點冰霜傷害，由低溫組織損傷與冰晶衝擊支持。
- 移動減速：速度倍率0.5，持續8秒，寒冰箭減速群組。
- 目標：一名可見敵人。

## 構築方案

> [[冰霜]]→[[投射]]→[[移動減速]]

冰霜傷害是核心明載的內稟結果，不另計傷害節點。未使用精通時，技能複雜度與迴路負載都為3。

## 行為

1. 投射物等待命中、攔截或失效。
2. 命中時先結算冰霜傷害，再建立8秒移動減速。
3. 傷害免疫不自動免疫減速，狀態免疫亦不自動免疫傷害。
