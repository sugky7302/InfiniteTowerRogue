# 英勇躍擊

英勇躍擊讓使用者跳向指定區域，落地時把衝擊傳向周圍敵人。

## 技能根節點

- 原始施法時間：0秒。冷卻45秒。
- 落點距離：8至40碼。
- 移動時間：依軌跡長度與起跳速度計算，最短0.5秒。
- 作用區域：落點周圍半徑8碼。
- 目標：落地時區域內的所有敵人。
- 傷害：6點＋[[近戰攻擊力]]×0.3，鈍擊物理傷害。
- 檢定：起跳時進行一次技能檢定。失敗不離地。

## 構築方案

> [[機動戰技]]→[[軌跡]]→[[躍擊]]→[[區域]]→[[落地衝擊]]

技能複雜度與迴路負載都為5。

## 行為

1. 檢查落點距離、拋物路徑、通過容積與可站立地面。
2. 沿固定軌跡移動。障礙或失去主動移動能力時依當下位置提前落地。
3. 只有成功抵達合法落點才建立半徑8碼區域。
4. 對區域內每名敵人各結算一次落地衝擊。非敵對目標不在候選中。
5. 落點無法傳力時不產生區域傷害。
