# 盾牌猛擊

盾牌猛擊以裝備並持握的盾牌撞擊近戰目標，造成衝擊傷害並產生怒氣。

## 技能根節點

- 檢定屬性：力量。
- 前置：盾牌由[[裝備中]]與[[持握中]]確認，且明載衝擊致傷資料。
- 目標：接觸距離內一名敵人。
- 傷害：盾牌基礎傷害×1.0＋近戰攻擊力×0.5，類型為物理衝擊。
- 成功資源：命中並造成實際傷害後，由[[怒氣生成]]增加15點怒氣。

## 構築方案

> [[裝備中]]→[[持握中]]→[[武器技藝]]→[[接觸]]→[[命中時]]→[[怒氣生成]]

未使用精通時，技能複雜度與迴路負載都為6。

## 行為

1. 檢查盾牌、持握狀態與接觸距離。
2. 命中時依盾牌資料與近戰攻擊力係數結算物理衝擊傷害。
3. 造成實際傷害後產生15點怒氣。
