# 獵豹形態

獵豹形態把施放者切換為四足獵豹身體，解除可驅散移動限制並維持速度、變形免疫與墜落防護。

## 技能根節點

- 原始施法時間：0秒。
- 目標：施放者自身。
- 持續時間：主動離開形態前持續。
- 形態資料：採[[獵豹化身]]。裝備收納停用，生命值比例、身分、意識、記憶與已支付資源保留。
- 移動速度：1.3倍率，獵豹形態移動群組。同群組只取最高值。
- 變形免疫：只拒絕形態建立後的新「變形」狀態，不解除既有變形。
- 墜落傷害倍率：0.5。

## 構築方案

主路徑：

> [[獵豹化身]]→[[化身]]→[[形態切換]]→[[進入形態時]]→[[移動限制解除]]

形態維持分支由並行控制節點分出[[增益]]、[[狀態免疫]]與[[墜落減傷]]。完整技能複雜度與迴路負載都為9。

## 行為

1. 支付成本並確認目前位置能容納獵豹碰撞範圍。
2. 建立獵豹形態資料。成功後觸發一次[[進入形態時]]。
3. [[移動限制解除]]依驅散門檻處理定身、移動減速與合法束縛。
4. 並行維持速度倍率、變形免疫與墜落傷害倍率。
5. 離開形態時先移除三項形態限定效果，再恢復原形資料。
