# 背刺

背刺消耗能量，以穿刺戰具攻擊近戰目標。命中時若位於目標背後，該次傷害提高，並產生連擊點。

## 技能根節點

- 檢定屬性：精準。
- 能量消耗：40點。
- 前置：由[[持握中]]確認一件可用的穿刺戰具。
- 目標：接觸距離內一名敵人。
- 基礎傷害：武器傷害×1.0。
- 背後傷害：[[背後時]]成立時，由[[背襲增幅]]使本次傷害乘以1.2。
- 成功資源：命中後由[[連擊點生成]]對本次目標增加1點。

## 構築方案

> [[持握中]]→[[武器技藝]]→[[接觸]]
> 條件分支：[[背後時]]→[[背襲增幅]]
> 成功分支：[[命中時]]→[[連擊點生成]]

未使用精通時，技能複雜度與迴路負載都為7。

## 行為

1. 檢查戰具、目標與能量，開始時支付40點能量。
2. 命中時結算基礎武器傷害。
3. 同時檢查背後條件。成立時只將本次傷害乘以1.2。
4. 命中成功後對本次目標增加1點連擊點。
