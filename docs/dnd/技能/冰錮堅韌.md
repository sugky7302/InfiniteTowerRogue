# 冰錮堅韌

冰錮堅韌以受控低溫作用強化自身防禦，短時間降低所有承受傷害並免疫新昏迷。

## 技能根節點

- 目標：自身。
- 持續時間：8秒。
- 傷害承受倍率：0.7，對所有傷害事件套用一次。
- 狀態免疫：只拒絕新施加的昏迷，不移除既有控制。
- 安全機制：核心保持血液流動與組織溫度下限。失敗時技能不成立。

## 構築方案

> [[冰霜]]→[[覆體]]→並行
> ├─[[增益]]→[[傷害減免]]
> └─[[狀態免疫]]（昏迷）

未使用精通時，技能複雜度與迴路負載都為6。

## 行為

1. 技能成功後同時建立8秒傷害減免與昏迷免疫。
2. 每個承受傷害事件只套用一次0.7倍率。
3. 新昏迷失敗，但其他控制正常處理。
4. 到期或效果被移除時，兩項結果同時終止。
