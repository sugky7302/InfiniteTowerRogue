# 振奮咆哮

振奮咆哮以受控聲音鼓舞附近隊伍成員，暫時提高其目前與最大生命值。參考原型為 [Wowhead 正式服技能 97462](https://www.wowhead.com/tw/spell=97462)。

## 技能根節點

- 原始施法時間：0秒。
- 冷卻時間：180秒，技能成功開始時起算。
- 作用區域：以使用者為中心，半徑40碼。
- 合法目標：區域內聲音可抵達、能聽見且屬使用者隊伍或團隊的成員。
- 目前生命值倍率：1.1。
- 最大生命值倍率：1.1。
- 持續時間：10秒。
- 疊加群組：振奮生命增益。同群組只取最高倍率。
- 效果分類：非魔法士氣增益。

純知識版：

> [[戰吼技藝]]→[[區域]]→[[可聽見]]→[[增益]]

精通版：

> [[振奮咆哮構築]]

純知識版技能複雜度與迴路負載都為4。精通版都為1。精通不改變距離、目標關係、倍率、持續時間或冷卻。

## 行為

1. 建立40碼聲音區域，逐一檢查隊伍或團隊關係、聲音傳播與聽覺。
2. 每名合格目標各自取得同一來源的兩項1.1倍率，並保存10秒持續時間。
3. 目前生命不得超過當下最大生命；本效果不是治療，也不觸發治療事件。
4. 自然到期、驅散、來源失效或較強同群組效果替換時，依[[增益與目標選取]]移除本效果提供的倍率。
