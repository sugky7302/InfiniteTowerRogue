# 糾纏根鬚

糾纏根鬚讓既有植物組織在指定位置快速生長，形成可承力根系並定身目標。技能可以選配週期性物理傷害。

## 技能根節點

- 檢定屬性：智力。
- 法力消耗：法力容量的3%。
- 原始施法時間：1.75秒。
- 基準有效距離：30碼。
- 作用區域：半徑2碼。
- 持續時間：12秒。
- 目標：區域內一名接觸地面且可被實體根鬚纏繞的目標。
- 提前解除：每次承受實際傷害後，獨立進行一次解除判定。
- 選配傷害：每3秒造成2點擠壓或穿刺物理傷害。
- 檢定：依[[檢定值]]進行一次技能檢定。

## 構築方案

主路徑：

> [[根鬚]]→[[生長]]→[[構造]]→[[區域]]→[[定身]]

選配傷害由並行控制節點分出，再以[[時間之週期]]驅動根鬚核心明載的擠壓或穿刺傷害。未使用精通時，完整方案的技能複雜度與迴路負載都為7。

## 行為

1. 檢查位置、目標、植物或生物質來源及資源。
2. 生長並構造可承力根鬚，在區域內纏繞目標。
3. 套用定身。到期、根鬚結構失效或解除判定成功時終止。
4. 啟用選配傷害時，每3秒獨立結算一次，主路徑仍可在未啟用傷害時成立。
