# 心靈震爆

心靈震爆以暗影能量衝擊遠方敵人。具有暗影專精時，成功傷害另產生瘋狂。

## 技能根節點

- 基準有效距離：40碼。
- 傷害：12＋法術強度×1.0點暗影傷害。
- 專精分支：暗影專精且傷害路徑成立時，由[[瘋狂生成]]增加6點瘋狂。
- 每次施放最多生成一次。

## 構築方案

> [[暗影]]→[[投射]]→[[暗影之毀滅]]
> 成功分支：[[專精資格]]（暗影專精）→[[瘋狂生成]]

未使用精通時，技能複雜度與迴路負載都為5。

## 行為

1. 投射暗影並在命中時結算傷害。
2. 傷害路徑成立後檢查暗影專精。
3. 資格成立時產生6點瘋狂，超出上限溢失。
