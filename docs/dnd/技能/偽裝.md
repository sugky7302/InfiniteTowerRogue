# 偽裝

偽裝讓施放者與一名受控寵物配合周遭環境進入潛行，並各自週期恢復生命值。

## 技能根節點

- 原始施法時間：0秒。冷卻60秒。
- 有效距離：施放者自身及30碼內一名[[受控寵物]]。
- 持續時間：60秒。
- 每名承受者每1秒恢復自身最大生命值的2%，最多60次，不超過最大生命值。
- 偽裝訊號：輪廓、表面色彩與亮度。不消除聲音、氣味與痕跡。
- 終止：主動攻擊、造成傷害、外顯施法、實際受傷、離開取樣環境或被驅散。寵物失控、超距或遭隔離時只終止寵物分支。

## 構築方案

> [[環境偽裝]]→[[覆體]]→[[受控寵物]]→並行：[[潛行]]／[[時間之週期]]→[[治療]]

並行控制節點計入後，技能複雜度與迴路負載都為7。目標數量不另增加節點。

## 行為

1. 建立施放者及一名合格寵物的目標集合。
2. 對每名目標取樣其周遭背景並覆體。
3. 並行建立潛行與每秒治療。各承受者獨立保存週期與終止原因。
4. 依[[潛行與偵測]]處理視覺、聲音、氣味、距離、遮蔽與行動偵測。
