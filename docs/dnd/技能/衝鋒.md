# 衝鋒

衝鋒讓使用者沿可通行路徑高速接近敵人，抵達合法近戰位置後產生怒氣。

## 技能根節點

- 檢定屬性：力量。
- 目標：8至25碼內一名可見敵人。
- 移動速度：15碼／秒。
- 終點：目標旁一處可站立的合法近戰位置。
- 成功資源：抵達終點後由[[怒氣生成]]增加20點怒氣。
- 原始施法時間：0秒。移動仍依距離與速度占用實際時間。

## 構築方案

> [[機動戰技]]→[[軌跡]]→[[接敵]]→[[怒氣生成]]

未使用精通時，技能複雜度與迴路負載都為4。

## 行為

1. 檢查距離、視線、可通行路徑及合法終點。
2. 沿軌跡移動。遇到障礙或失去合法終點時失敗。
3. 成功抵達後產生20點怒氣。
