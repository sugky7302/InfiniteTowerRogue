# 冰凍陷阱

冰凍陷阱把裝有低溫載荷的單次陷阱投到指定位置，第一名進入感應區的敵人會觸發癱瘓。

## 技能根節點

- 基準有效距離：40碼。投射速度20碼／秒。
- 部署後存續：60秒。冷卻30秒。
- 感應區：半徑2碼，只接受敵人。
- 同時進入：依進入時間、距離、識別序穩定排序，取第一名。
- 癱瘓：60秒，禁止主動移動、攻擊、施法、技能與物品操作。
- 受傷解除：100%。任一次實際生命值損失立即解除。
- 單次啟動：成功觸發後停止偵測並消耗裝置。

## 構築方案

> [[陷阱裝置]]→[[投射]]→[[區域]]→[[區域進入時]]→[[癱瘓]]→[[受傷解除]]

未使用精通時，技能複雜度與迴路負載都為6。

## 行為

1. 投射陷阱，落地部署後才開始60秒計時與偵測。
2. 到期、被破壞或首次成功觸發三者只執行最先發生的一項。
3. 觸發時消耗裝置並對選定敵人施加癱瘓。
4. 癱瘓到期、驅散或受實際傷害時解除。
