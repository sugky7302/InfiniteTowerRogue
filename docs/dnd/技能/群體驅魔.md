# 群體驅魔

群體驅魔掃描指定區域，分別從有限友軍移除有害魔法、從有限敵軍移除增益魔法。

## 技能根節點

- 基準有效距離：30碼。作用半徑15碼。
- 法力消耗：法力容量的8%。
- 目標上限：友軍至多5名、敵軍至多5名。
- 友軍：每名移除至多一個合法有害魔法。
- 敵軍：每名移除至多一個合法增益魔法。
- 排序：距區域中心由近至遠，同距離取效果剩餘時間較長者。
- 特殊驅散：允許嘗試特殊保護，門檻依規則提高。不可驅散仍不能處理。

## 構築方案

> [[魔法解析]]→[[區域]]→並行
> ├─[[效果篩選]]（友軍、有害）→[[驅散]]
> └─[[效果篩選]]（敵軍、增益）→[[驅散]]

未使用精通時，技能複雜度與迴路負載都為7。

## 行為

1. 支付法力並建立區域候選。
2. 兩條分支分別篩選及排序。
3. 對每名合法目標進行獨立驅散檢定。
