# 戰吼

戰吼以可傳播聲音鼓舞周圍友軍，使其攻擊力暫時提高。

## 技能根節點

- 作用區域：以使用者為中心，半徑200碼。
- 合法目標：區域內聲音可抵達且能聽見的友軍。
- 攻擊力倍率：1.3。
- 持續時間：30秒。
- 疊加群組：士氣增益。
- 效果分類：非魔法士氣增益。不能被一般魔法驅散。

## 構築方案

> [[戰吼技藝]]→[[區域]]→[[可聽見]]→[[增益]]

未使用精通時，技能複雜度與迴路負載都為4。

## 行為

1. 發出戰吼並建立聲音作用區域。
2. 對區域內單位逐一檢查友軍關係、聲音傳播與聽覺。
3. 合法目標取得30秒攻擊力1.3倍率增益。
