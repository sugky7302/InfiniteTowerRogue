# 啟動

啟動向友方治療者注入魔力，使其短時間施放合格法術時不消耗法力。

## 技能根節點

- 基準有效距離：40碼。
- 目標：一名友方治療者。
- 持續時間：8秒。
- 權限：效果期間開始支付的法術，其法力消耗改為0。
- 不影響其他資源、材料、施法時間、檢定、冷卻或維持條件。

## 構築方案

> [[魔力注入]]→[[投射]]→[[法力消耗豁免]]

未使用精通時，技能複雜度與迴路負載都為3。

## 行為

1. 投射魔力注入並建立8秒豁免。
2. 合格法術開始支付時，只把法力成本改為0。
3. 到期後不返還先前消耗，也不影響已開始支付的法術。
