# 剔骨

剔骨消耗能量與綁定在目標上的連擊點，以近戰武器造成隨支付點數增加的物理傷害。參考原型為 [Wowhead 技能 196819](https://www.wowhead.com/tw/spell=196819)。

## 技能根節點

- 檢定屬性：精準。
- 前置：由[[持握中]]確認一件可用近戰武器。
- 目標：5碼內一名敵人。
- 資源成本：35點[[能量]]及本次選定的1至5點[[連擊點]]。
- 傷害：[[近戰攻擊力]]×0.37325×已支付連擊點，傷害類型依戰具資料。
- 原始施法時間：0秒。

## 構築方案

純知識版：

> [[持握中]]→[[武器技藝]]→[[接觸]]

精通版：

> [[持握近戰構築]]

純知識版技能複雜度與迴路負載都為3。精通版都為1。[[持握近戰構築]]展開後仍是相同三知識結構。

## 行為

1. 檢查近戰武器、目標距離、35點能量及至少1點綁定本目標的連擊點。
2. 選擇並支付1至5點連擊點，同時支付35點能量。
3. 命中時按實際支付點數結算一次物理傷害。
4. 未支付、超出5點或綁定其他目標的連擊點不增加本次傷害。
