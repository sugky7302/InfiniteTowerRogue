# 生命烈焰

生命烈焰依施放時的目標關係選擇唯一結果：傷害敵人，或治療盟友。

## 技能根節點

- 檢定屬性：智力。
- 法力消耗：法力容量的2%。
- 原始施法時間：1.25秒。
- 基準有效距離：25碼。
- 投射速度：20碼／秒。
- 敵方結果：8＋[[法術強度]]×0.8點直接火焰傷害。
- 友方結果：8＋[[治療強度]]×0.8點治療。
- 目標：一名可見敵人或具有生命活動與可修復結構的盟友。
- 檢定：依[[檢定值]]進行一次技能檢定。

## 構築方案

技能以關係選擇器建立兩條互斥路徑：

> 敵人：[[火焰]]→[[投射]]→直接火焰傷害
> 盟友：[[生命]]→[[投射]]→[[治療]]

未使用精通時，最大實際路徑有3個知識節點，加上選擇控制節點，技能複雜度與迴路負載都為4。

## 行為

1. 施放時依[[增益與目標選取]]固定目標關係，只選擇一條分支。
2. 支付法力並投射相應核心力量。
3. 命中時只結算所選分支。關係在飛行中改變不會改選另一分支。
4. 敵方分支讀取[[法術強度]]結算直接火焰傷害。友方分支依[[治療與治療強度]]讀取[[治療強度]]結算治療。
