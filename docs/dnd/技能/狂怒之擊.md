# 狂怒之擊

狂怒之擊只能在狂怒狀態下使用，讓主手與副手各完成一次獨立武器攻擊，成功後產生怒氣。

## 技能根節點

- 檢定屬性：力量。
- 前置：[[狂怒中]]成立，且雙手各由[[持握中]]確認一把合格武器。
- 目標：接觸距離內一名敵人。
- 主手傷害：主手武器傷害×1.65。
- 副手傷害：副手武器傷害×1.65。
- 成功資源：至少一擊造成實際傷害後，由[[怒氣生成]]增加5點怒氣。同次施放最多一次。
- 原始施法時間：0秒，但仍受雙武器動作與接觸時間限制。

## 構築方案

> [[狂怒中]]→並行
> 主手：[[持握中]]→[[武器技藝]]→[[接觸]]
> 副手：[[持握中]]→[[武器技藝]]→[[接觸]]
> 並行結果：[[怒氣生成]]

未使用精通時，技能複雜度與迴路負載都為9。

## 行為

1. 檢查狂怒、雙持與目標距離。
2. 主手與副手分別進行命中及傷害結算。
3. 至少一擊造成實際傷害時產生5點怒氣。
4. 兩擊均失敗時不產生怒氣。
