# 心靈幻象

心靈幻象建立一條受限制的感官連結，讓施放者暫時接收目標實際看見的視覺。

## 技能根節點

- 法力消耗：法力容量的4%。
- 原始施法時間：1.75秒。
- 基準有效距離：30碼。
- 持續時間：30秒。
- 目標：一名可感知且未被空間隔離的生物。
- 非自願目標：施放者智力檢定對抗目標精神檢定，必須嚴格較高。

## 構築方案

> [[感官借用]]→[[鏈結]]→[[投影]]→[[同意或抵抗]]→[[連結中斷]]

技能複雜度與迴路負載都為5。

## 行為

1. 支付成本並檢查距離與[[空間之隔離]]。
2. 由[[同意或抵抗]]取得本次許可。
3. 建立鏈結與視覺投影，只轉送目標實際取得的視覺。
4. 每個事件時間重查意識、視覺、距離、驅散與隔離。任一中斷即終止。
