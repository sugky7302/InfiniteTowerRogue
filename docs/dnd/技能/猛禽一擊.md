# 猛禽一擊

猛禽一擊消耗集中值，以持握中的近戰武器對接觸距離內敵人造成一次物理傷害。參考原型為 [Wowhead 正式服技能 186270](https://www.wowhead.com/tw/spell=186270)。

## 技能根節點

- 原始施法時間：0秒。
- 前置：由[[持握中]]確認一件可用近戰武器。
- 目標：近戰接觸距離內一名敵人。
- 資源成本：30點[[集中值]]。
- 傷害：本次戰具基礎傷害＋[[近戰攻擊力]]×技能係數，造成戰具明載的物理傷害類型；係數由遊戲模式平衡表設定。

## 構築方案

純知識版：

> [[持握中]]→[[武器技藝]]→[[接觸]]

精通版：

> [[持握近戰構築]]

純知識版技能複雜度與迴路負載都為3。精通版都為1。精通不免除近戰武器與集中值前置，也不免費提高武器係數。

## 行為

1. 檢查可用近戰武器、合法近戰目標及至少30點集中值。
2. 開始技能時支付30點集中值。支付失敗時技能不開始。
3. 命中時讀取本次戰具資料，結算一次物理傷害。
4. 未命中時依[[資源]]保留已支付成本，除非其他效果明列返還。
