# 冷酷凜冬

冷酷凜冬在施放者兩側建立冰劫與霜奪，維持一段可供冰凍之魂監聽的低溫靈體效果。

## 技能根節點

- 目標：施放者自身。
- 持續時間：10秒，第一版平衡測試值。
- 冷卻：60秒，成功建立時起算。
- 來源位置：[[冰劫]]位於左側4碼，[[霜奪]]位於右側4碼。兩者隨施放者移動。
- 結束原因：自然到期、驅散、主動取消、來源死亡、條件失效或替換刷新。

## 構築方案

> [[冰霜]]→[[環繞]]→並行：[[冰劫]]／[[霜奪]]

並行控制節點計入後，技能複雜度與迴路負載都為5。

## 行為

1. 成功時建立唯一效果實例與兩個外部來源。
2. 兩個來源只提供位置與低溫能量，不自主攻擊。
3. 效果結束時先保存結束原因並允許相連觸發結算，再移除來源。
