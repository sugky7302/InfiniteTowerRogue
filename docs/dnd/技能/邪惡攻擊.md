# 邪惡攻擊

邪惡攻擊消耗能量，以單手戰具近戰攻擊敵人，命中後產生連擊點。

## 技能根節點

- 檢定屬性：精準。
- 能量消耗：45點。
- 前置：由[[持握中]]確認一件可用單手戰具。
- 目標：接觸距離內一名敵人。
- 傷害：單手武器傷害×1.0。
- 成功資源：命中後由[[連擊點生成]]對本次目標增加1點。

## 構築方案

> [[持握中]]→[[武器技藝]]→[[接觸]]→[[命中時]]→[[連擊點生成]]

未使用精通時，技能複雜度與迴路負載都為5。

## 行為

1. 檢查單手戰具、目標與能量，開始時支付45點能量。
2. 命中時依戰具資料結算物理傷害。
3. 命中成功後對本次目標增加1點連擊點。
