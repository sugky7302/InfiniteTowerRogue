# 自由祝福

自由祝福消耗法力，以光明力量解除一名隊伍或團隊成員身上的移動限制，並暫時阻止新的定身與移動減速。參考原型為 [Wowhead 技能 1044](https://www.wowhead.com/tw/spell=1044)。

## 技能根節點

- 檢定屬性：精神。
- 目標：40碼內一名隊伍或團隊成員。
- 法力消耗：法力容量的1.4%。
- 原始施法時間：0秒。冷卻25秒。
- 持續時間：8秒。
- 驅散分類：魔法。

## 構築方案

純知識版：

```text
並行
├─光明→投射→移動限制解除
├─光明→投射→狀態免疫（定身）
└─光明→投射→狀態免疫（移動減速）
```

精通版：

```text
並行
├─光明移動解除
├─光明狀態免疫（定身）
└─光明狀態免疫（移動減速）
```

純知識版技能複雜度與迴路負載都為10。精通版都為4，包括1個並行控制節點與3個精通節點。精通展開後仍逐路檢查完整作用路徑。

## 行為

1. 檢查目標資格、距離與法力，開始時支付法力並啟動冷卻。
2. 立即解除目標身上可解除且具有移動限制標籤的定身、減速與束縛。
3. 在8秒內分別拒絕新定身與新移動減速。
4. 祝福不免疫昏迷、恐懼、癱瘓、牆壁、碰撞、負重或其他未列效果。
