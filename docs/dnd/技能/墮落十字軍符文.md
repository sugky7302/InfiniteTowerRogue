# 墮落十字軍符文

墮落十字軍符文把一套受擊發動迴路刻入符文武器，使目前持有者在武器造成傷害後有機率獲得治療與力量增益。

## 技能根節點

- 改造時間：5秒，必須全程操作合法符文熔爐。
- 目標：一把具有銘文相容標籤、足夠剩餘刻印容量且標記為符文武器的裝備。
- 材料：一份墮落十字軍符文材料。開始改造時消耗。
- 占用：刻印容量9、調諧負載1。
- 拆除：在合法符文熔爐花費5秒移除。材料不返還。
- 觸發事件：目前持有者以該武器造成實際生命值傷害。
- 觸發率：每個合格傷害事件檢查一次，15%。內部冷卻45秒。兩者為第一版平衡測試值。
- 成功結果：持有者恢復自身最大生命值的6%，並使最終總力量乘1.15，持續15秒。
- 疊加：力量增益屬「墮落十字軍」群組，不疊層。再次成功刷新為15秒。治療每次重新結算。

並行控制節點計入後，技能複雜度、迴路負載與刻印容量都為9。15秒持續時間是技能根節點參數，不另建立修飾節點。

## 行為

1. 檢查熔爐、工具、材料、武器標籤、銘文相容性及剩餘刻印容量。
2. 消耗材料並持續操作5秒。任何前置失效都使改造失敗。
3. 成功後保存模組，直到符文被覆寫、拆除或結構損壞。
4. 武器由合法持有者造成實際傷害時，每事件只進行一次機率判定。
5. 內部冷卻可用且15%判定成功時，立即進入45秒冷卻，並行治療目前持有者及刷新力量增益。
6. 武器轉手後，後續觸發改作用於新的合法持有者，不綁定製作者。
