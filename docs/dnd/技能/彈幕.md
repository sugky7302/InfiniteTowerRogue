# 彈幕

彈幕讓使用者在移動中以遠程武器連續掃射前方錐域，對持續留在射界內的敵人累計多次武器傷害。

## 技能根節點

- 集中值消耗：60點。
- 原始施法時間：0秒。立即開始3秒引導。
- 冷卻：20秒，技能成功開始時起算。
- 武器：一件合法持握、射程至少40碼且可進行連射的遠程武器。
- 錐域：以使用者當下位置與朝向為起點，長40碼、夾角90度。
- 射擊：首次延遲0.375秒，每0.375秒一次，共8次。
- 傷害：每次對每名合格目標造成1.0倍武器傷害。單次引導對同一目標最多累計8.0倍。
- 彈藥：每次每名目標消耗一份。不足時按距離近到遠、同距離由朝向左界順時針排序。
- 移動：引導期間可用自身地面移動速度移動並改變朝向。

## 構築方案

> [[武器技藝]]→[[錐域]]→並行：[[移動引導]]／[[時間之週期]]→[[敵對資格]]

並行控制節點計入後，技能複雜度與迴路負載都為6。總倍率、射擊次數與週期間隔是技能根節點參數，不另建立修飾節點。

## 行為

1. 檢查[[持握中]]、武器射程、彈藥及60點[[集中值]]，支付後開始冷卻與引導。
2. 移動引導每次射擊前更新使用者位置與朝向。
3. 在0.375、0.75、1.125、1.5、1.875、2.25、2.625及3秒各建立一次錐域。
4. 逐次排除自身、友軍、中立、超距、受遮蔽或射線不通的候選。
5. 依穩定順序消耗彈藥並各自結算1.0倍武器傷害。
6. 失去持握、昏迷、癱瘓、武器無法射擊或主動取消時中斷。保留已結算事件，不補發其餘射擊。
