# 治療術

治療術把生命修復作用送往一名盟友，依基礎值與治療強度恢復生命值。

## 技能根節點

- 檢定屬性：智力。
- 法力消耗：法力容量的2%。
- 原始施法時間：1.25秒。
- 基準有效距離：30碼。
- 目標：一名可見、具有生命活動與可修復結構的盟友。
- 治療量：10＋[[治療強度]]×1.0，不超過目標最大生命值。
- 檢定：依[[檢定值]]進行一次技能檢定。

## 構築方案

> [[生命]]→[[鏈結]]→[[治療]]

未使用精通時，技能複雜度與迴路負載都為3。

## 行為

1. 檢查目標、距離、視線與法力。
2. 支付法力並完成施法。中斷時不結算治療。
3. 以生命核心建立修復作用，沿鏈結抵達目標。
4. 依[[治療與治療強度]]計算並套用治療量。
