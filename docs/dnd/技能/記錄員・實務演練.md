# 記錄員・實務演練

記錄員・實務演練是[[記錄員]]的標準代表技能。此技能演示的實務如下：核對訊息。辨識立場。建立可理解的表達。保留當事人能動性。完成後記錄結果、失敗條件與後續責任。技能產出一份專業結果，供第三者查驗。

## 技能根節點

- 作用距離：接觸合格工具、材料、場所或服務對象。
- 原始施法時間：6秒。這段時間只代表一個可檢定的實務片段，不能把長期工作壓縮成6秒完成。
- 必要輸入：由[[記錄員]]實務與當前工作契約指定，技能不會免費生成工具、材料或權限。
- 合法結果：完成一個範圍明確、可重查且符合資格邊界的專業步驟。
- 失敗結果：不產生合格成果。依情境保留已消耗的時間與材料，並記錄需要修正或交接的問題。

## 行為

1. 確認目標、必要輸入、工具、權限與停止條件。
2. 接觸工作對象，執行一個包含下列工作的實務片段：
   - 核對訊息。
   - 辨識立場。
   - 建立可理解的表達。
   - 保留當事人能動性。
   - 完成後記錄結果、失敗條件與後續責任。
3. 依公開完成標準產生成果或失敗紀錄。超出資格時，停止並交接。

## 邊界

- 本技能不會自動取得[[記錄員]]認證或[[記錄員・專業實務]]。
- 不會免費增加數值、免除材料與時間、跳過研究前置，或取代其他職業的專門結果。
- 若工作涉及傷害、治療、狀態、移動、召喚或法則干涉，必須另加入對應的合法效果與作用路徑。
- 本技能的「專業結果」不能擴大為任意效果。
