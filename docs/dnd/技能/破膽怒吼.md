# 破膽怒吼

破膽怒吼以威嚇聲音使主要敵人畏縮，並迫使附近其他敵人減速逃離。受傷會解除。

## 技能根節點

- 主要目標：一名可聽見使用者的敵人，恐懼8秒。
- 區域目標：8碼內其他可聽見敵人。
- 區域結果：恐懼、[[強制逃離]]及移動速度降低70%，持續8秒。
- 受傷解除：100%，每名目標分別監聽。
- 不具相容心智或無法聽見者不受影響。

## 構築方案

> [[戰吼技藝]]→[[區域]]→[[可聽見]]→選擇
> ├─主要目標：[[恐懼]]→[[受傷解除]]
> └─其他敵人：[[恐懼]]→[[強制逃離]]→[[移動減速]]→[[受傷解除]]

未使用精通時，技能複雜度與迴路負載都為10。

## 行為

1. 聲音抵達後逐一檢查目標關係、聽覺與心智資格。
2. 主要目標畏縮。其他敵人沿可通行路徑遠離並降低速度。
3. 到期、驅散或承受實際傷害時，各目標獨立解除。
