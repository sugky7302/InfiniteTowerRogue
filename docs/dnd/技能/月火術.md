# 月火術

月火術以星光表現的秘法射線命中敵人，先造成直接秘法傷害，再留下週期秘法灼蝕。

## 技能根節點

- 基準有效距離：40碼。
- 直接傷害：6＋法術強度×0.4點秘法傷害。
- 持續傷害：每3秒4＋法術強度×0.2點秘法傷害，持續18秒。
- 驅散類型：魔法有害效果。

## 構築方案

> [[秘法]]→[[射線]]→[[秘法灼蝕]]→[[時間之週期]]

直接傷害由秘法核心明載機制支持。未使用精通時，技能複雜度與迴路負載都為4。

## 行為

1. 射線命中時結算一次直接秘法傷害。
2. 建立18秒秘法灼蝕，每3秒獨立結算一次。
3. 到期或驅散後取消所有未來週期。
