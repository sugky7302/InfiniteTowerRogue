# 死亡之握

死亡之握以空間力量抓住遠處敵人，通過抵抗後將其強制移至施術者旁的合法位置。參考原型為 [Wowhead 技能 49576](https://www.wowhead.com/tw/spell=49576)。

## 技能根節點

- 檢定屬性：智力。
- 目標：30碼內一名可見敵人。
- 原始施法時間：0秒。冷卻25秒。
- 資源消耗：無。
- 終點：施術者旁可容納目標的合法近戰位置。
- 抵抗：施術者智力技能檢定對抗目標力量或體質通用檢定。施術者須嚴格較高。

## 構築方案

純知識版：

> [[空間]]→[[投射]]→[[空間之位移]]

精通版：

> [[空間牽引構築]]

純知識版技能複雜度與迴路負載都為3。精通版都為1。[[空間牽引構築]]展開後仍須檢查距離、邊界、抵抗與終點。

## 行為

1. 檢查敵對資格、視線、30碼距離與施術者旁的候選終點。
2. 進行強制位移抵抗。
3. 成功時把目標移至合法終點。抵抗成功、終點失效或封閉邊界阻擋時不移動目標。
4. 本技能不建立額外仇恨，也不強制目標攻擊施術者。
