# 死亡纏繞

死亡纏繞消耗符能並依目標關係選擇唯一結果：傷害敵人，或治療不死盟友。敵方分支還能延長指定疾病。

## 技能根節點

- 符能消耗：30點。
- 基準有效距離：30碼。
- 敵方結果：12＋法術強度×0.8點暗影傷害。
- 不死盟友結果：12＋治療強度×0.8點治療。
- 疾病操作：敵方目標已有技能明列疾病時，剩餘時間增加1.5秒；每次施放最多一次，不超過原最大持續時間。

## 構築方案

> 選擇
> ├─敵人：[[暗影]]→[[投射]]→[[暗影之毀滅]]→[[疾病資格]]→[[持續時間延長]]
> └─不死盟友：[[不死資格]]→[[生命]]→[[投射]]→[[治療]]

未使用精通時，技能複雜度與迴路負載都為10。

## 行為

1. 檢查並支付30點符能，再依目標關係固定一條分支。
2. 敵方分支結算暗影傷害，之後檢查並延長指定疾病。
3. 不死盟友分支通過資格後結算治療。
4. 沒有合格疾病時只略過延長，不影響敵方傷害。
