# 哥布林

## 種族概述

哥布林是體型、膚色與骨架差異很大的類地精族群。小型支系身材矮小、反應迅速，善於利用大型建築與廢棄物形成生活空間。中型支系身形高大、耐力穩定，在部分地區俗稱「大哥布林」。這些稱呼是體型、家族或地方傳統的差異，不再代表獨立種族。

## 生理特徵

哥布林普遍具有靈敏耳廓、容易辨識的身體輪廓，並習慣以姿勢判斷遮蔽是否足以中斷視線。創角時從小型或中型中選定一種體型。體型會影響通道、裝備與遮蔽物判斷，但不改變適性或血脈核心。

## 社群與文化

哥布林可組成回收工坊、地下街區、商旅團、農村、學院、軍事國家或一般家庭，生存方式不等同品格。某些大哥布林社群以固定輪值、隊伍節拍與長時勤務聞名，但這些能力來自訓練、制度與後天知識，不是必然的血統命令。
