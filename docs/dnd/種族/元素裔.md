# 元素裔

## 種族概述

元素裔是血脈或身體受單一元素長期改變的人形族群。創角時從火、水、風或土中選定一種血脈相性，它會改變外觀徵候與感知方式，但不直接授予元素操控、傷害或抗性。

## 生理特徵

火相可能體溫偏高並有餘燼般紋路。水相可能膚色呈流動光澤。風相的髮絲與呼吸常受微氣流牽動。土相則可能有礦晶、陶質或石紋。這些特徵可被觀察，也可能暴露角色的狀態與來歷。

## 創角特徵

### 適性

### 血脈核心

## 社群與文化

元素裔可出生於火山工坊、沿海城鎮、高山觀測站、礦業聚落或普通都市家庭。有些社群會記錄血脈徵候與環境變化，有些則把它視為私人特徵。血脈相性不決定性格、職業或信仰。
