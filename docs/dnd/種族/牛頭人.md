# 牛頭人

## 種族概述

牛頭人是具有牛科頭部、角、蹄與寬厚軀幹的高大人形族群。他們的眼睛位置與可轉動耳廓適合觀察開闊環境，但不會因此自動看穿遮蔽、隱形或精細偽裝。

## 生理特徵

牛頭人的脖肩肌群發達，能支撐角部並承受長時間負重。寬闊側向視野與靈活耳廓能讓他們較早注意到側面的大幅動作，但狹窄頭盔、門框與不合身頭具會限制這些感官。

## 社群與文化

牛頭人社群可建立於草原聚落、河谷農區、山城、商隊或都市工業區。常見傳統包括土地記錄、共用糧倉、長途護送與公開議事，但體格高大不代表每位牛頭人都擅戰、沉默或保守。
