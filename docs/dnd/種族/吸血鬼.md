# 吸血鬼

## 種族概述

吸血鬼是血液循環與代謝經過遺傳或轉化而改變的人形族群。他們能從合適血液取得部分營養，但不因此自動成為不死生物，也不會天生具有永生、魅惑、變形、再生或吸取生命的能力。

## 生理特徵

吸血鬼常見特徵包括體溫偏低、犬齒較長、嗅覺對血液特別敏感，以及對強光與飢餓的不適較明顯。陽光會造成刺眼、皮膚不適與暴露風險，但除非另有效果或世界契約，不會自動造成傷害。

## 社群與文化

吸血鬼可以來自夜間工坊、地下城鎮、醫療行會、牧畜聚落或一般都市家庭。不同社群可透過志願捐血、動物血液、代用營養品與受規範的醫療供應處理需求。飲血不代表殘暴、貴族身分或特定道德立場。
