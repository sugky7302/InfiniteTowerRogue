# 林精

## 種族概述

林精是高大而步履輕緩的林地人形族群，對氣味、低頻聲響與周遭生物的緊張反應尤為敏銳。他們不是樹木化身，卻常在古林、牧地與河谷間擔任長期的守望者。

## 生理特徵

林精的身高普遍超過人類，骨架寬大，耳廓能微幅轉向聲源，嗅覺也能辨識濕氣、煙霧與動物留下的氣味變化。他們步幅雖大，但足掌寬闊，在林地與鬆軟土壤上行動時不易製造巨響。

### 適性

從[[精神]]或[[親和]]選一項增加1點。

### 血脈核心

[[林息安撫]]—不直接授予完整能力。創角時與三個個人原型分別混成，再由玩家三選一。

## 社群與文化

林精社群可建立於林間聚落、季節牧區、河道守望站、寺院或城市園圃。許多社群用界石、歌謠與季節路線記錄土地變化，並透過長期契約分配採集、放牧與復育的責任。親近自然是生活經驗與知識傳承，不是每位林精與生俱來的職業或品格。
