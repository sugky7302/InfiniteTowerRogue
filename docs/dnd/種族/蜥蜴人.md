# 蜥蜴人

## 種族概述

蜥蜴人覆有鱗片，能調節代謝以適應溼熱、水域與食物短缺。

## 生理特徵

可閉氣較久，體溫受環境影響明顯，在極寒中活動會變得遲緩。

## 創角特徵

### 適性

從[[體質]]或[[精神]]選一項增加1點。

### 血脈核心

[[潛息]]—不直接授予完整能力。創角時與三個個人原型分別混成，再由玩家三選一。

## 社群與文化

蜥蜴人可來自濕地部落、河港、沙洲城或混居聚落，情感表達方式因文化而異。
