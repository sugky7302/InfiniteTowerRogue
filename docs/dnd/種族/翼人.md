# 翼人

## 種族概述

翼人是具有鳥類羽毛、翼骨或寬大翼膜的人形族群。常見翼型包括背生獨立羽翼，以及手臂與羽翼合一的翼臂型。後者在部分地區俗稱「天狗」。各翼型都能感受細微氣流，並具有飛行或滑翔潛力，但起飛、持續飛行、滑翔、盤旋與俯衝仍需要混成天賦、知識、空間與體力，不是深度1自動獲得的完成能力。

## 生理特徵

翼人的肩背、胸腔與呼吸系統適合展翼運動，骨架較輕，卻也害怕翼部關節被束縛、主羽或翼膜大面積受損。獨立翼型需要背部開口。翼臂型的雙手操作與展翼動作會互相限制。所有翼型都需要寬闊起飛面與可安全收翼的室內空間。

## 社群與文化

翼人可生活於崖城、高原、海島、森林冠層、高塔聚落或經過改造的都市頂層。有些社群以「天狗」命名翼臂型家族、傳統或地方身分，但這不再是獨立種族。空中信號、氣象觀測、懸吊建築與山脊信使網是常見技術，也有人從不飛行。能否飛行、飛得多高與擅長何種空中動作，都來自後天構築與訓練。
