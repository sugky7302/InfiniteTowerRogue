# 半獸人

## 種族概述

半獸人具有獸人與其他人形族群血統，體格結實、犬齒明顯，外貌差異很大。

## 生理特徵

肌肉恢復快，能在短時間劇烈用力後較快調整呼吸。

## 創角特徵

### 適性

從[[力量]]或[[體質]]選一項增加1點。

### 血脈核心

[[血脈續命]]—不直接授予完整能力。創角時與三個個人原型分別混成，再由玩家三選一。

## 社群與文化

半獸人可能在任一方親族、混居邊鎮或獨立家庭中成長，血統不代表暴力傾向。
