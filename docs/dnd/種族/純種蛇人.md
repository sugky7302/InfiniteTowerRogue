# 純種蛇人

## 種族概述

純種蛇人具有蛇類瞳孔、細鱗與敏銳化學感受，外貌仍接近一般人形。

## 生理特徵

舌與嗅覺器官能辨認空氣中的氣味方向，低溫會降低其反應速度。

## 創角特徵

### 適性

從[[精神]]或[[智力]]選一項增加1點。

### 血脈核心

[[蛇信尋息]]—不直接授予完整能力。創角時與三個個人原型分別混成，再由玩家三選一。

## 社群與文化

純種蛇人可來自隱密家系、古城、商會或一般混居社群。血統不代表欺詐或邪惡。
