# 德萊尼

## 種族概述

德萊尼原為阿古斯的埃雷達爾人。薩格拉斯引誘大多數埃雷達爾人加入燃燒軍團時，擁有預知天賦的費倫在那魯協助下帶領追隨者逃離母星。他們從此自稱「德萊尼」，意為被放逐者，並在跨越多個世界的逃亡中尋找新家園。

## 生理特徵

德萊尼體格高大，常見藍色、紫色或灰藍色膚色，具有角、裂蹄、尾巴與不同程度的面部觸鬚。部分個體的眼睛、角或皮膚紋路會呈現柔和光芒，但這不自動提供照明、治療、驅散或魔能抗性。

## 創角特徵

### 適性

從[[親和]]或[[精神]]選一項增加1點。

### 血脈核心

[[那魯餘輝]]—不直接授予完整能力。創角時與三個個人原型分別混成，再由玩家三選一。

## 社群與文化

德萊尼的共同歷史包括阿古斯的流亡、那魯引導、燃燒軍團的追擊、德拉諾的創傷，以及乘坐水晶飛船艾克索達抵達艾澤拉斯的經歷。他們的建築、工藝與航行技術常把水晶、奧術與那魯科技結合，宗教傳統則重視聖光、克制、服務與對燃燒軍團的抵抗。這些歷史不會強制每名德萊尼信奉聖光、效忠聯盟或擔任特定職業。
