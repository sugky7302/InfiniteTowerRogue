# 精靈

## 種族概述

精靈是壽命漫長、感官細緻的人形族群，常以數十年的尺度經營技藝與關係。

## 生理特徵

身形輕盈、耳廓修長，睡眠較淺，能在微弱光線下維持清楚的輪廓辨識。

## 創角特徵

### 適性

從[[身法]]或[[精神]]選一項增加1點。

### 血脈核心

[[微光靈瞳]]—不直接授予完整能力。創角時與三個個人原型分別混成，再由玩家三選一。

## 社群與文化

精靈社群可能重視長期記錄、林地共生、航海觀星或城市工藝，個人不必遵循族群傳統。
