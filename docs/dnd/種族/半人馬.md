# 半人馬

## 種族概述

半人馬具有人形上身與馬形四足下身，擅長在開闊地形維持步伐與長距離移動。四足構造提供穩定承載面，也使樓梯、繩梯與狹窄轉角成為明顯障礙。

## 生理特徵

成年半人馬身體修長、胸腔與心肺負擔較大，四足能快速回報地面高低差與步幅是否安全。他們需要專用寢具、載具、階梯與下身裝備，不能直接套用一般人形族群的尺寸。

## 社群與文化

半人馬社群可建立於草海、丘陵、農牧地、驛站城鎮或擁有寬闊街道的都市。許多社群重視道路保養、季節路線、長途通訊與共用水源，但擅長騎射、遊牧或奔跑都必須經過學習。
