# 熊貓人

## 種族概述

熊貓人是披覆黑白或褐白毛色的熊科人形族群，體格厚實卻動作靈活。他們常以呼吸、步伐與重心轉移來維持身體節奏，即使沒有學習武藝，也能在推擠或落地時敏銳察覺自身平衡。

## 生理特徵

熊貓人的軀幹寬厚、關節活動幅度大，能在失衡時迅速沉低重心，並用四肢與軀幹分散衝擊。濃密毛層能抵禦濕冷，但在高溫環境中需要更頻繁地休息與補充水分。

## 社群與文化

熊貓人社群可建立於雲霧山谷、竹林農村、河川港口、旅行商隊或城市街區。許多地方重視共餐、烹飪、釀造、茶禮、節慶與身心訓練，也有以遠行、記載與調停衝突為職責的傳統。「平衡」是一種需要反覆實踐的理想，不代表每位熊貓人都沉著、愛飲酒或懂得武藝。
