# 半身人

## 種族概述

半身人是體型矮小、重心穩定且手腳靈活的人形族群。不同支系可能生活於農莊、船隊、城市街區、山麓工坊或地下聚落。其中擅長精密工藝的支系常被俗稱為「侏儒」或「地侏」，但並非獨立種族。

## 生理特徵

成年身高通常約為人類的一半，足底耐磨，能在狹窄或擁擠的環境中穩定移動。各支系的體態略有差異。地侏支系常有靈活手指與細緻近距視覺，但這些差異不足以形成另一套血脈核心。

## 社群與文化

半身人社群常以家庭、農莊、船隊或旅行商團維繫，也有人在大城市中生活。被稱為侏儒或地侏的工藝支系，常以工坊、學舍、園藝區與公共檔案庫串聯社群，重視師徒傳承、同行評議、開放圖紙，以及能否把技藝修復並傳給下一代。機巧、幻術、測繪與辨識微小結構都是可由背景、職業或感知知識取得的後天專業，不是獨立血脈天賦。
