# 矮人

## 種族概述

矮人骨架厚實、耐力穩定，能在山地、坑道與長時間勞動中維持活動。

## 生理特徵

身材不高但軀幹結實，對常見礦塵與低氧環境的忍受力較強。

## 創角特徵

### 適性

從[[體質]]或[[力量]]選一項增加1點。

### 血脈核心

[[山肺]]—不直接授予完整能力。創角時與三個個人原型分別混成，再由玩家三選一。

## 社群與文化

矮人可生活於山城、地下聚落、工業港或商業家族，工藝不是天生能力。
