# 哥利亞

## 種族概述

哥利亞是高大厚實的山地族群，四肢適合攀越岩坡與承受寒冷風壓。

## 生理特徵

成年個體明顯高於多數人形族群，肺活量大，皮膚常有天然斑紋。

## 社群與文化

哥利亞可來自山村、牧團、傭兵隊或低地城市，競爭並非所有社群的共同價值。
