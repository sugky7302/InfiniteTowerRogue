# 娜迦

## 種族概述

娜迦原本是艾薩拉女王統治下的上層精靈。約一萬年前，永恆之井崩毀引發大分裂，辛艾薩莉與艾薩拉的臣民沉入海中。艾薩拉與古神恩佐斯締結交易，使倖存者轉化為娜迦，並在舊帝國廢墟上建立以納沙塔爾為中心的深海帝國。

## 生理特徵

娜迦具有覆滿鱗片的蛇形下身、人形軀幹與手臂，能在深海長期生活，也能上岸活動。個體可能具有棘刺、鰭、額外手臂或其他深海變異，但這些外觀差異不自動授予額外攻擊、操作次數或血脈核心。其水生身體不等同使用可見鰓器官，也不自動提供深海抗壓、黑暗視覺或高速游泳能力。

## 社群與文化

艾薩拉的娜迦帝國延續上層精靈的王權、貴族、宮廷與祕法傳統，以女王為最高權威，下有受寵貴族、海巫、軍官、施法者、士兵與被奴役者。其文明擅長祕法工程、潮汐與風暴法術、召喚儀式、深海孵化及海域征服，也重視血統、古代榮耀與服從。這些是帝國文化而非天生道德。玩家角色可以是流亡者、叛逃者、地方支系成員或拒絕艾薩拉與古神影響的人，也不會因種族自動取得祕法、潮汐或召喚知識。
