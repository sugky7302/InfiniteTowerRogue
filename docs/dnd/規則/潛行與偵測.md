# 潛行與偵測

潛行是降低觀察者取得可辨識訊號的持續狀態，不會讓承受者消失或免除感官判定。

依[[根塵識資訊]]，潛行逐項降低、遮蔽或偽裝色、聲、香、味、觸、法中的實際訊號。遮蔽一種塵不會消除其他塵，也不會直接改寫觀察者已形成的識事件。

## 偵測檢定

觀察者以適用感知進行檢定，潛行者以偽裝或潛行技能對抗。主持人依下列可觀察因素加入有利加成或不利修正：

- 距離越遠、遮蔽越完整、背景越相似，越不易發現。
- 強光下的輪廓差、移動、攻擊、施法與操作物件會提高可見度。
- 腳步、呼吸、碰撞與說話可由聽覺發現。氣味與痕跡可由相容感官發現。
- 一種訊號被遮蔽不影響其他感官。[[環境偽裝]]必須逐項列出實際改變的訊號。

## 建立與終止

[[潛行]]必須指定持續時間、偽裝來源、可用感官、重查時點與終止條件。第一次建立及觀察者主動搜索時進行偵測。距離、照明、遮蔽或行動顯著改變時可重新檢定。

預設在承受者主動攻擊、造成傷害、施放具有外顯訊號的技能、受到實際生命值傷害或偽裝來源失效後終止。技能可以覆寫其中一項，但必須逐項明列。被一名觀察者發現只使該觀察者能定位目標，不自動移除其他觀察者面對的潛行。
