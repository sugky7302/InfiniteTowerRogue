# 因果律

因果律是七大法則共同遵守的總綱，不是第八種基礎法則。它檢查一個效果是否具有足夠原因、資訊、能量、材料與可追蹤結果。

## 基本要求

- 結果必須由已執行的節點與已支付的代價產生，名稱或敘事不能免費增加效果。
- 物質、能量、資訊與狀態的來源、去向或保存方式必須可說明。
- 改變過去、刪除存在、確定未來或把後果轉移給別處，都不能只靠時間、空間或暗影核心成立。
- 隨機結果必須列出候選、機率與判定時點。未知不等於無因。

## 在技能中的作用

因果律通常不占技能節點。它是所有技能的合法性檢查。只有技能主動操控因果關係時，才需建立相應知識與效果節點。精通可以壓縮已驗證的因果子樹，但不能省略輸入、代價、限制或失敗條件。

本規則是[[道法術]]中「道」的總綱，並約束[[知識體系]]、[[技能]]與[[精通]]。
