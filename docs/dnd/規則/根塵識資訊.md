# 根塵識資訊

根塵識資訊模型把「世界存在某種現象」到「角色辨認其意義」拆成可追蹤的感知鏈，供調查、潛行、幻術、感官連結、陷阱與敵人行為共同使用。

```text
現象來源
→形成可感知的塵
→經介質與空間抵達相應根
→通過遮蔽、閾值與分辨條件
→形成識事件
→心智理解並決定後續行動
```

## 感知鏈欄位

| 欄位 | 必須回答的問題 |
|---|---|
| 現象來源 | 什麼物體、生命、技能或事件產生訊號？ |
| 塵 | 訊號以色、聲、香、味、觸或法的哪一類存在？ |
| 介質與路徑 | 訊號如何抵達接收者，會被何種距離、邊界或介質影響？ |
| 根 | 眼、耳、鼻、舌、身、意中的哪一接收介面能取得訊號？ |
| 接觸條件 | 訊號是否超過閾值，是否受到遮蔽、雜訊或根失效影響？ |
| 識事件 | 接收者形成了什麼最低限度的辨識？ |
| 理解結果 | 還需哪些記憶、知識或檢定才能知道身分、原因、弱點或意義？ |

不是每項普通觀察都要逐欄擲骰。沒有壓力、訊號清楚且角色具備相應根時可以直接形成基本識事件。只有結果不確定且失敗會改變局面時才使用[[D20檢定]]。

## 六塵不是六種元素

- 色：形狀、光暗、顏色、位置與可見運動等可見面。
- 聲：震動經介質傳到耳根的可聽面。
- 香：物質隨介質抵達鼻根的氣味面。
- 味：物質接觸舌根後形成的味覺面。
- 觸：壓力、溫度、質地、疼痛、姿勢與內部體感等身體接觸面。
- 法：記憶、概念、想像、情緒或已形成識事件等既有心智內容被意根接觸的一面。

同一現象可以同時形成多種塵。遮蔽其中一種不會消除其他訊號。法塵只是既有心智內容的可接觸面，不是新元素、獨立法則或無來源資訊。

## 資訊深度

| 深度 | 玩家可以知道 | 常見條件 |
|---|---|---|
| 接觸 | 有訊號、方向或強弱變化 | 相應根與塵成功接觸 |
| 辨識 | 訊號屬於已知類型或對象 | [[認知之辨識]]、經驗或簡單比對 |
| 理解 | 知道關係、機制、目的或可能後果 | [[認知之理解]]及相應領域知識 |
| 利用 | 能據此改變技能、機關、路徑或策略 | 合法操作知識、工具、時間與代價 |

較深資訊包含較淺資訊，但取得接觸不等於辨識，辨識不等於理解，理解也不等於具備操作能力。必要資訊不得被單次檢定永久封鎖。失敗改變取得時間、風險、代價、完整度或敵方反應。

## 干涉分類

| 干涉位置 | 作用 | 範例 |
|---|---|---|
| 改變來源 | 真的改變現象本身 | 熄滅光源、停止震動、降溫 |
| 改變塵 | 保留來源但改變可感知訊號 | 偽造聲音、扭曲影像、掩蓋氣味 |
| 改變路徑 | 阻擋、衰減或轉送訊號 | 隔音牆、霧、[[感官連結]] |
| 改變根 | 強化、限制或替換接收介面 | 失明、夜視、借用他者聽覺 |
| 改變識 | 訊號抵達但形成錯誤辨認 | 把敵人認成友軍、忽略已見物件 |
| 改變理解 | 保留辨識但扭曲解釋或記憶 | 假線索、錯誤知識、記憶改寫 |

每項幻術、偽裝、感知強化或心智干涉至少指定一個干涉位置、受影響的塵或根、抵抗方式及失效後可觀察線索。不能只寫「欺騙所有感官」或「看穿一切」。

## 與既有規則的關係

- [[潛行與偵測]]：潛行降低、遮蔽或偽裝一種以上的塵，不使角色從世界消失。
- [[感官連結]]：轉送來源的根已接收之訊號，保留原有遮蔽與雜訊，不直接轉送理解或記憶。
- [[遙感]]：改變訊號取得的空間視點或路徑，仍受指定根、塵與資訊深度限制。
- [[認知]]：擁有六識事件及從辨識到理解的轉換。六識不是六項永久知識。
- [[心智法則]]：可以處理意根、法塵、識與理解，但不能無來源取得外界資訊。

## 範例：追蹤隱形敵人

敵人只扭曲色塵，因此眼根不能從輪廓形成眼識。腳步仍形成聲塵，體重使地面形成可見痕跡，呼吸與體溫仍可能形成觸塵或其他可感知訊號。玩家可以先取得「附近有移動訊號」，再以多項線索辨識位置。隱形不等於無聲、無味、無熱或不可碰觸，除非能力逐項提供合法效果。
