# 非戰鬥模組

非戰鬥領域預設使用[[CONTEXT|統一行動解析框架]]。只有需要持續追蹤狀態與反覆決策的領域，才建立獨立模組；遊戲框架不必實作所有模組。

## 成立門檻

一項非戰鬥模組必須同時具備：

1. 可追蹤狀態。
2. 反覆選擇。
3. 推進壓力。
4. 不同方法。
5. 失敗後果。
6. 能流入[[CONTEXT|成長鏈]]或[[CONTEXT|四層持久狀態]]的活動產出。

只有單次[[D20檢定]]或專屬數值、但沒有上述決策循環時，仍屬一般行動解析，不建立獨立模組。

## 首版模組家族

| 模組家族 | 處理問題 | 不處理 |
|---|---|---|
| 探索 | 未知空間、路線、地點特徵、危險與發現 | 特定事件真相、長距離旅行消耗 |
| 調查 | 線索、證詞、矛盾、假說與特定事件真相 | 客觀知識形成、未知空間揭露 |
| 社交與派系 | 需求、信任、承諾、聲望、立場與群體關係 | 無持續狀態的單次說服 |
| 潛入與追緝 | 身分、視線、警戒、通行權、追捕與脫離 | 一般移動、單次潛行檢定 |
| 研究 | 樣本、觀察、文獻、實驗、知識碎片與完整知識 | 特定事件真相 |
| 製作與交易 | 材料、工具、工序、品質、供需、交換與維修 | 只有固定價格的商店清單 |
| 旅行與生存 | 大尺度路線、時間、補給、氣候、疲勞與環境適應 | 單一地點探索、戰鬥移動 |
| 組織與據點 | 人員、設施、計畫、影響力、維護與長期工程 | 單次任務隊伍、個人物品欄 |

## 遊戲框架選用

每個[[CONTEXT|遊戲框架]]應只深化能支撐其重複選擇的模組，首版建議選用二至四類。其餘領域沿用統一行動解析。選用一項模組時，必須說明：

- 它在[[CONTEXT|四層核心循環]]中的位置。
- 六項成立門檻分別由哪些規則承擔。
- 它與其他選用模組交換哪些狀態與產出。
- 未選用的相鄰領域如何用通用解析處理。

新增家族前，必須先證明需求無法合理歸入現有八類。同一狀態應由一個模組擁有，其他模組只透過明列介面讀取或改變。

## 模組組合

每項活動只能指定一個[[CONTEXT|主導模組]]，由它擁有主要重複選擇、推進壓力與退出條件。活動可以加入零至多個[[CONTEXT|支援模組]]，提供替代方法、資訊、資源或狀態轉換。

模組組合必須遵守：

- 所有模組共同服務同一份[[CONTEXT|活動契約]]。
- 同一狀態只有一個擁有模組，其他模組透過明列介面讀取或改變。
- 支援模組不能建立與主導模組競爭的活動終點。
- 支援內容若形成獨立目標、推進壓力與退出條件，應拆成巢狀或後續活動。

例如以潛入與追緝為主導模組的王宮滲透，可以用社交改變守衛立場、探索發現密道、調查辨認名冊。警戒、追捕與撤離仍由主導模組擁有，所有結果回到同一活動契約。

## 世界規則與玩家操作

世界中的規則過程不必全部展開成[[CONTEXT|玩家操作模組]]。未選用完整模組時，相關行動仍須遵守系列公理、來源合法性與統一行動解析，但可以由劇情、非玩家角色、機構或簡化程序完成。

知識形成與來源合法性是所有作品的共同義務，完整研究模組則由遊戲框架選用：

- 未選研究模組：角色可以使用預先形成的知識，或從導師、記憶、載體、觀察及其他合法來源取得知識。遊戲仍須能追溯來源。
- 選用研究模組：玩家直接管理樣本、文獻、實驗、解析進度、研究設施及失敗後果，使知識形成成為反覆決策循環。

同一原則可以套用於製作、職業認證與組織運作：世界規則可以持續存在，玩家操作深度由遊戲框架決定。

## 資訊取得

探索、調查與研究模組必須把資訊分成[[CONTEXT|必要資訊]]與[[CONTEXT|增益資訊]]：

- 必要資訊：角色抵達正確資訊來源並採取合理方法後直接取得，不由單次檢定永久封鎖。
- 增益資訊：可以受檢定、時間、風險與資源限制，並提供捷徑、優勢、完整背景、額外獎勵或更佳判斷。

必要資訊直接取得不等於自動公開所有秘密。角色仍須找到正確地點、對象、文獻或樣本，並提出足以接觸資訊的方法。檢定可以決定取得速度、內容完整度、樣本保存、暴露風險及額外線索，但不能讓活動唯一的推進線索因一次失敗永久消失。

取得線索也不代表自動解答。玩家或角色仍須把已取得內容整理成假說、研究方向或行動判斷。只有使用相應知識與解析方法時，才由規則提供進一步結論。

## 社交與角色能動性

社交行動只能在目標目前的[[CONTEXT|社交可接受範圍]]內影響信任、理解、情緒、交換條件與承諾。要求超出範圍時，行動者必須先提供新資訊、交換利益、建立關係、製造壓力或改變局勢，使該選項成為目標可能接受的結果；提高檢定結果不能直接把不可能要求變成服從。

威脅、欺騙與利益交換都必須記錄具體主張及後果：

- 威脅可以換得短期服從，但可能增加恐懼、敵意、報復或揭發風險。
- 欺騙成功只代表目標相信具體主張，不會使其永久失去判斷能力。
- 承諾與交換必須明列雙方認知的條件，違反後依關係及局勢產生後果。

社交規則只改變角色作決定時掌握的資訊、關係與利害，不能代替角色意志。直接干涉意志必須使用合法的心智效果技能。非玩家角色的社交檢定也不能替玩家決定其角色接受何種選項。

## 製作、交易與價值

物品的[[CONTEXT|物品規則價值]]與[[CONTEXT|情境交換價值]]分開記錄：

- 物品規則價值由材料性質、品質、階級、效果與製作難度形成。
- 情境交換價值由交易地點、時間、雙方需求、稀缺性、資訊、合法性、運輸及支付能力形成。

物品階級可以協助當地市場估價，但不能直接生成全宇宙固定價格。同一物品在不同市場可以價值懸殊，甚至因無人辨識、缺乏相容工具或禁止持有而無法正常交易。

貨幣、信用、匯率、交易所與跨界商會都屬特定文明、組織或遊戲框架建立的制度，不是系列公理。它們必須明列接受範圍、兌換依據、履約方式及失效條件。
