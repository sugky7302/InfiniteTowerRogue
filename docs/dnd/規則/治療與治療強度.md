# 治療與治療強度

[[治療]]把[[生命]]核心提供的生命修復作用轉成生命值恢復。它不能讓生命值超過最大值，也不能對沒有生命值或缺乏可修復結構的目標成立。一般目標還必須具有生命活動。不死目標則須由[[不死資格]]確認其維持結構能接受該治療。

> 治療量＝基礎治療量＋[[治療強度]]×治療強度係數

係數以小數記錄，例如500%記為5。治療量先按公式計算，再受目標的治療加成、減益及上限影響。超過最大生命值的部分預設溢失。

治療強度只決定標示「治療強度係數」的效果數值，不提高命中、射程或驅散強度。修復斷肢、疾病或死亡等結構性問題，需要額外知識與效果，不能只靠提高治療量完成。[[生命]]核心也不會繞過這項限制。
