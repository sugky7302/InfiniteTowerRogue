# 內容適用層級

資料庫與故事中的內容頁必須用 frontmatter 的「適用層級」欄位說明條目如何生效。`CONTEXT.md`、ADR、目錄、日誌、範本與測試已有固定文件職責，不重複標記。

## 五種層級

| 適用層級 | 生效方式 | 選用權 |
|---|---|---|
| 系列公理 | 所有作品共享且不能改寫的世界真相 | 不能停用 |
| 設計規範 | 所有相關作品文件必須遵守的結構與驗證契約 | 不能任意省略 |
| 世界規則 | 共同宇宙中客觀存在的過程，即使玩家不直接操作仍有效 | 不能違反，可不展開 |
| 遊戲模組 | 遊戲框架選用後才展開成玩家操作的完整狀態與決策循環 | 遊戲框架選用 |
| 內容套件 | 角色、種族、職業、裝備、技能、世界或故事等可引用素材 | 作品明確納入 |

## 生效順序

遊戲框架先接受全部系列公理與適用的設計規範，再遵守所有與作品內容相關的世界規則。之後明列選用的遊戲模組及內容套件。未選遊戲模組時，對應世界過程仍可透過通用解析、劇情、機構或非玩家角色處理；未納入內容套件時，該素材不會自動出現在作品中。

較低層級不能改寫較高層級：

- 內容套件不能推翻遊戲模組或世界規則。
- 遊戲模組不能推翻世界規則、設計規範或系列公理。
- 世界規則不能推翻系列公理。
- 設計規範只約束作品文件與驗證方式，不用來宣稱宇宙內現象。

## 頁面邊界

一頁原則上只使用一種適用層級。若同一頁同時包含世界真相、玩家機制與可選素材，應依責任拆頁並以雙向連結組織，不能使用「混合」作為層級。

新建頁面必須立即標記。既有頁面在本頁建立後採增量遷移，每次更新時補上分類。尚未分類的既有頁面不能只因所在資料夾或名稱而推定生效方式。

## 遊戲框架引用

每個[[CONTEXT|遊戲框架]]必須列出：

- 接受的系列公理版本。
- 適用的設計規範。
- 會影響作品的世界規則。
- 明確選用的遊戲模組。
- 明確納入的內容套件。
- 未展開模組所採用的簡化處理方式。

每款遊戲只能由一份根級[[遊戲框架]]頁宣告上述內容。其他關卡、角色、故事與系統頁可展開細節或連回框架，不能自行改寫適用層級與組裝關係。
