# 形態與墜落

形態是角色目前用來行動的身體資料。[[形態切換]]必須指定來源形態、目標形態、進入與離開事件，以及哪些資料保留或重算。

## 形態資料

- 身分、記憶、意識、生命值比例與已支付資源預設保留。
- 體積、外形、碰撞範圍、肢體、移動方式、基礎速度、感官與可用技能依目標形態重算。
- 裝備必須逐項指定為保留作用、收納停用、掉落或因尺寸不合而失效。不能因變形免費取得裝備能力。
- 離開形態時移除所有標為「形態限定」的效果，再恢復原形資料。原形位置若無合法容積，切換失敗而不把角色擠入物件。

同一時間發生切換與控制時，依「支付成本→建立切換事件→結算[[進入形態時]]→套用形態限定持續效果→處理後續事件」排序。

## 墜落

墜落先由重力、落差與阻力求落地速度；第一版無其他資料時，以 `落地速度＝√(2×9.8×落差公尺)` 估算。落地傷害只計超過安全落地速度的部分：

> 墜落傷害＝承受係數×max(0，落地速度－安全速度)²

承受係數與安全速度由生物形態、著地面、護具及落地動作指定。[[墜落減傷]]在原始傷害求出後乘算，不能把沒有支撐面的墜落改成飛行，也不能忽略落地位置與碰撞。
