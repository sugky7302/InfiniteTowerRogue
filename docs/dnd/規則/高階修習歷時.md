# 高階修習歷時

五至七階不是完成一次考試便能快速取得的資格。角色必須在漫長時間中反覆研究、實作、失敗、修正，並親自承受不同文明與宇宙尺度的真實回饋，才能把知識整合成法則。

本頁規定高階悟證的最低累積有效修習歷時。時間門檻只提供報考資格，不會自動形成法則、通過認證或授予任何能力。

## 最低時間門檻

| 目標階級 | 最低累積有效修習歷時 | 必須經歷的尺度 |
|---|---:|---|
| 五階聖者 | 一千年 | 多世代知識更替、行星環境與完整次級法則的反覆實踐 |
| 六階半神 | 十萬年 | 恆星環境變化、跨文明節點興衰與銀河網的長期自治、失聯和重建 |
| 七階神明 | 一億年 | 星系結構變遷、文明多次誕滅及至高根法則在宇宙年代中的穩定驗證 |

門檻採累積總額：角色抵達六階時至少已有十萬年有效修習，抵達七階時至少已有一億年。作品可以要求更久，不能縮短最低值。

## 何謂有效修習歷時

只有角色持續形成、校驗或整合目標法則的因果歷程才能計入，包括：

- 在真實環境中觀測、施作、失敗、修復及比較結果。
- 維護跨世代工程，親自處理制度變質、載體失傳與後繼者偏差。
- 讓既有理論接受不同地區、物種、文明與天體條件的反證。
- 保存足以重建自身理解的記憶、身分與知識載體。
- 對先前錯誤作出可查核修正，而不是只重複成功流程。

單純活著、等待、沉睡或擁有古老出生日期不算有效修習。

## 不能縮短時間的方式

- **冬眠與封印**：沒有心智活動與真實回饋的時間不計入。
- **時間加速**：只有角色實際經歷、能留下等量因果與記憶負擔的主觀時間可計入；外界看似短暫不會免費產生億年經驗，維持加速仍須能源、載體與承受極限。
- **模擬世界**：可用於訓練和假說篩選，不能取代恆星、銀河或真實文明的長期不可預測回饋。
- **記憶灌注**：取得前人記憶只取得資訊。若沒有自己對其校驗、整合和承擔的歷程，不計入本人修習時間。
- **轉世與更換載體**：只有自我連續、記憶可重建且法則理解沒有被當成外來資料重新載入時，前一載體的時間才可累積。
- **多人合計**：組織可以保存億年工程，不能把一百萬人各修習一百年的時間相加，直接製造一名七階神明。
- **神位繼承**：主神席位只轉移主導資格與責任，不轉移前任的修習年數。

## 各階時間的意義

### 五階：千年校驗

千年足以讓王朝、語言、學派與基礎設施多次變化。五階候選者必須證明自己的法則理解能跨越載體與制度更替，而不是只在一位導師、一座實驗室或一場戰役中成立。

### 六階：十萬年法則網

十萬年使恆星環境、行星生態和多個文明發生不可逆變化。六階候選者必須維護由多項次級法則構成的分散網路，經歷節點自治、通信延遲、文明滅亡與後繼者重建。

### 七階：億年神格

一億年足以觀察星系尺度結構和大量文明週期。七階候選者必須證明至高根法則不是一個時代的局部模型，而能在宇宙年代、不同載體和大尺度因果變化中持續成立。

因此神明必然是深時存在。祂可以使用年輕化身與地方名字，卻不能只有數百或數千年的完整生平。

## 與認證和壽命的關係

- 時間門檻、知識門檻、精通、真實實踐和認證考核必須全部成立，缺一不可。
- 候選者必須用延壽、載體更替、心智保存、文明接續或其他合法方法維持自我。職業不預先贈送不死能力。
- 壽命方法本身也必須接受[[因果律]]檢查，說明材料、能量、記憶損失、人格連續與失敗條件。
- 一至四階沒有統一最低年數。它們仍依各職業培訓、實務與考核成立。

## 故事使用原則

- 五階人物通常比當代國家更古老，可能保有已失傳制度的第一手記憶。
- 六階人物不應只屬於單一行星史，其關係和責任至少橫跨多輪文明興衰。
- 七階人物的完整生平不可能只由一個現存文明保存。人物頁必須區分本人記憶、外部載體、地方傳說與已校驗史實。
- 古老不等於全知。長期記憶會受載體、索引、人格連續和可觀測範圍限制。
- 低階文明可能只認識神明最近幾千年的地方化身，不知道祂億年生平的全貌。

## 驗證問題

1. 五、六、七階人物是否分別具備至少千年、十萬年與一億年有效修習？
2. 年代是否包含真實實踐，而非只以沉睡或時間跳躍填滿？
3. 角色如何維持壽命、自我連續與可重建記憶？
4. 高階資格是否仍具備知識、精通、實踐和考核，而非只看年齡？
5. 地方文明知道的是完整生平、局部化身，還是未校驗神話？
