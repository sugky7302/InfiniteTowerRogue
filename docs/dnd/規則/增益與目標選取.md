# 增益與目標選取

增益是使承受者某項參數提高或取得有利權限的持續效果。技能必須指出受影響參數、運算方式、持續時間、作用範圍、合法目標與疊加群組。

## 陣營與目標

友軍、敵軍與中立是施放當下依隊伍、敵意或場景規則計算的目標關係，不是永久生物標籤。區域效果先檢查位置，再檢查關係、感知、遮蔽與其他條件。關係改變不會追溯已結算結果。持續效果是否保留須由技能指定。

## 關係選擇器

技能可以用一個選擇控制節點，依施放時的友軍、敵軍或中立關係選擇唯一一條分支。選擇器本身計入技能複雜度與迴路負載，但不是知識，也不提供核心、型態或結果。

- 技能根節點必須列出每種關係對應的分支。未列出的關係是非法目標。
- 選擇在支付成本前完成並固定。投射途中關係改變時，不會改選另一分支；命中時若原分支資格已失效，該分支失敗。
- 每條分支都要獨立具有完整的「核心→至少一個型態→合法結果」路徑。
- 生物類型、生命狀態或其他非陣營條件仍須由相應觸發知識檢查，例如[[不死資格]]。

## 受控寵物與共享效果

[[受控寵物]]只承認施放當下由施放者直接控制、具有獨立生命值且位於技能有效距離內的個體。隊友、召喚物的召喚物、已失控個體與僅有敘事所有權的動物都不自動合格。

共享效果不是跨距離永久鏈結。技能建立目標集合後，每名承受者各自保存持續時間、生命值比例、驅散狀態與終止原因。一名承受者失格不會倒轉其他承受者已結算的結果。技能若要求持續共享，必須指定重查間隔；受控寵物超出有效距離、控制關係中斷或跨越[[空間之隔離]]時，只終止該寵物的分支。

## 數值與疊加

> 最終參數＝（基礎值＋固定加值總和）×（1＋最高同群組百分比）×其他不同群組倍率

同一疊加群組只取最高百分比，不相加。不同群組才相乘。戰吼的「攻擊力提高30%」應記為1.3倍率、士氣增益群組，並記錄持續時間與魔法效果分類。

聲音或情緒核心只提供傳播與作用機制，不會免費產生攻擊力加成。
