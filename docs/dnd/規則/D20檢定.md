# D20 檢定

擲出的骰值必須嚴格大於[[檢定值]]才算成功。骰值與檢定值相等時仍然失敗。

通用檢定、技能檢定、技能複雜度、知識修正值與完整計算順序，統一見[[檢定值]]。

自然骰的必定成功、必定失敗與額外代價規則見[[檢定值#自然骰與成功率]]。

## 檢定時機與行動後果

只有成功與失敗都會改變局面時才進行檢定。檢定前必須能說明角色要達成的目標、採用的方法，以及失敗可能造成的時間、資源、暴露、傷勢、關係或局勢後果。

檢定結果維持二元：

- 成功：原目標依宣告方法成立。
- 失敗：原目標沒有依宣告方法成立。

行動後果與檢定結果分開記錄。失敗不能自動改寫成原目標成立，但也不代表流程停止。角色可以承擔代價、改用替代方法、尋找另一條路或面對已改變的新局面。

安全、可以無限重試且沒有時間壓力的行動，不反覆進行檢定。角色具備必要條件時，投入足夠時間後依[[CONTEXT|統一行動解析框架]]中的「直接成立」處理；缺少必要條件時，重複嘗試也不會使行動成立，必須先改變方法或補足條件。

## 挑戰等級

挑戰等級與[[職業系統#戰鬥等級|戰鬥等級]]使用相同且可持續上升的絕對進度尺度。檢定公式以「挑戰等級－戰鬥等級」表達角色與阻力的進度差。

- 同等進度的敵人或障礙：挑戰等級約等於角色戰鬥等級。
- 低3級的阻力：角色在公式中取得3點優勢。
- 高3級的阻力：檢定值增加3。
- 敵人、機關、傷勢、知識與環境都使用相同尺度。

挑戰等級1～8只代表低階冒險範圍，不是整個遊戲的威脅上限。檢定值最低為2、最高為19。完整算法見[[檢定值]]。
