# 種族

種族描述角色出生時具有的身體構造與可遺傳特徵。文化、語言、信仰、職業與道德立場來自成長經歷，不由種族決定。同族角色可以來自完全不同的社群。

可選名單參考原始資料[[DND5E創角參考]]，具體特徵則依本知識庫的屬性、檢定與知識系統重新設計，不直接沿用 D&D 5E 數值。

## 角色建立

每名角色建立時選擇一個種族，取得該種族頁列出的初始適性，並以該頁的血脈核心參與[[天賦]]混成。血脈核心本身不作為第二項天賦保留。

### 初始適性

每個種族提供兩項適性屬性。玩家從中選一項增加1點。這1點在角色完成10點自由配點後套用，不占用自由配點，也不受「單項建立時最多投入5點」限制。

所有種族提供相同總值的初始適性，不因體型、壽命或社會地位改變。混血角色選擇一個種族頁作為規則底稿，再自由描述另一方血統。除非另有規則，不會同時取得兩頁特徵。

### 血脈核心

每個種族具有一項種族血脈天賦的核心成分。血脈頁只描述所有混成候選都必須保留的生理、血脈或規則入口，以及哪些舊效果需要改由知識與精通構築。

血脈核心不直接提供完成的主動技能。每個核心頁都要明列主動構築需求。需要主動啟動、選目標、指定方向、選擇時機或支付成本的運用，都必須由混成天賦授予具名知識或精通，再由玩家依[[技能]]自行構築。只有不需決策的弱被動生理許可或自動觸發能直接留在深度1。

混血角色仍只選擇一個種族頁作為規則底稿，因此只有一項血脈核心參與創角混成。另一方血統可以自由描述。若日後因重大事件真正改變角色本質，只能依[[天賦#累積改造]]融合進既有天賦，不能新增第二項。

## 體型

種族頁以小型、中型或大型描述常見成年體型。同一種族若包含明確的體型支系，可並列兩種體型；角色創建時必須選定其中一種，且不因此取得額外適性或第二項血脈核心。體型決定角色能否通過空間、使用合身裝備及被搬運，不直接修改生命值、傷害、防禦或檢定值。

玩家可以在合理範圍內描述高矮胖瘦。明顯偏離常見體型時，由主持人依場景判斷空間與裝備是否合用，不改變種族的初始適性。

## 文化與語言

種族頁的社群與文化只提供常見範例，不是強制背景。角色會哪些語言、工具、禮俗或專業知識，應由實際成長環境、背景與學習經歷決定。
