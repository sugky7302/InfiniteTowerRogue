# 事件記錄與外部來源

跨技能事件必須以效果實例、來源與時間範圍建立有限記錄，不能讀取沒有邊界的戰鬥歷史。

## 效果實例與結束原因

每個持續效果建立唯一實例識別，記錄施放者、承受者、開始時間、預定結束時間與目前狀態。結束時必須分類為自然到期、驅散、主動取消、來源死亡、條件失效或替換刷新。[[效果結束時]]只接受技能明列的原因。

## 期間命中集合

[[期間命中記錄]]以「效果實例＋施放者＋目標實例」保存唯一集合。重複命中同一目標只保留一筆。死亡後復活形成新目標實例，不沿用舊紀錄。記錄只證明期間內曾命中，不免除後續效果的存活、位置、陣營、範圍或其他資格檢查。

效果結束並完成所有相連結算後立即清除集合。記錄不提供傷害、仇恨、視野或追蹤能力。

## 外部施放來源

[[外部施放來源]]讓技能分支從明列的其他實體、召現物或裝備位置發出。每個來源必須記錄身分、位置、控制者、可用期間、可提供的核心與失效條件。

外部來源只改變分支起點，不替代核心、型態、資源或合法結果。多個來源各自建立完整分支並分別計算節點、區域、命中與傷害。來源失效只使該分支失敗。
