# 感官連結

感官連結把來源感官已接收的資訊轉送給接收者，不建立全知視角。技能必須指定來源、接收者、感官種類、同意或抵抗方式、距離、持續時間與中斷條件。

依[[根塵識資訊]]，感官連結改變的是訊號路徑：它轉送來源之根已接收的塵，不免費轉送來源後續形成的辨識、理解、記憶或意圖。

## 資訊範圍

- 來源看不見、聽不見或無法分辨的內容，接收者也不能取得。
- 感官受遮蔽、失明、幻覺或雜訊影響時，轉送相同受限資訊。
- 接收者只是借用訊號，不會自動控制來源身體或讀取其記憶。

## 建立與維持

自願目標可直接建立。非自願目標要以施法者心智檢定對抗目標心智檢定。連結建立後按[[時間與距離]]持續計算距離成本。

來源或接收者失去意識、對應感官失效、連結被驅散、維持者主動終止或[[空間之隔離]]切斷路徑時，連結立即中斷。普通距離不直接中斷，但超出技能有效距離時終止。
