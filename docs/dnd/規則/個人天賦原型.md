# 個人天賦原型

個人天賦原型不是角色直接持有的能力，而是[[天賦]]在創角時用來改寫血脈核心的模組。每個原型都提供唯一轉化、五層生成骨架、流派方向，以及實踐與突破種子。

## 力量

- [[蓄勢本能]]—把尚未釋放的血脈能力保存為可控制的蓄勢。
- [[破界直覺]]—把核心硬限制轉為可研究且須付代價突破的邊界。
- [[重心支配]]—用全身受力軸穩定核心方向與承受面。
- [[負荷轉化]]—把反作用力、疲勞或壓力保存為後續構築材料。
- [[威勢外放]]—把血脈徵兆轉為可被理解、但不強迫服從的壓迫訊號。

## 體質

- [[恆常代謝]]—把短時核心拆成有供應與衰減的長效運轉。
- [[傷勢適應]]—從實際承受並恢復的傷勢建立針對性適應。
- [[極境耐受]]—研究核心在惡劣環境中的最低功能與失效次序。
- [[循環再生]]—讓核心消耗材料透過有速率的身體循環補回。
- [[內穩]]—隔離核心對宿主其他系統的副作用與干擾。

## 身法

- [[慣性借步]]—延續核心產生或承受的方向與速度。
- [[空隙穿行]]—把真實可用的短暫空隙標成資格窗口。
- [[連動姿態]]—讓核心隨公開姿勢切換而改變用途。
- [[失衡回正]]—用核心留下的偏差線索恢復姿勢、軌跡或感官。
- [[節奏變速]]—讓核心在具有轉換成本的快慢節拍間運作。

## 精準

- [[微差校正]]—持續辨認並修正方向、強度或時點誤差。
- [[軌跡預讀]]—用已知資訊預估核心軌跡而不保證命中。
- [[分段操控]]—把連續核心拆成不重複結算的控制階段。
- [[弱點描摹]]—用觀察與接觸標記可驗證的結構弱點。
- [[多工手感]]—讓兩個低強度相容操作共享一套手眼節律。

## 智力

- [[結構洞見]]—把核心拆成因果清楚、可以重用的固定結構。
- [[模式歸納]]—從多次運作中找出有樣本邊界的可預測規律。
- [[逆向拆解]]—從結果回推候選原因並逐步排除。
- [[心智模擬]]—以角色已知資訊模擬有限結果分支。
- [[原理遷移]]—把已理解的共同原理移到另一相容領域。

## 精神

- [[意志定錨]]—讓核心以可被動搖也可恢復的信念錨點維持。
- [[感知延伸]]—把注意力沿核心實際擁有的訊號延伸。
- [[痛苦轉念]]—把仍須承受的痛苦轉為可理解的心智訊號。
- [[心境共振]]—讓核心隨可驗證的單一心境改變表現。
- [[執念凝形]]—讓長期目標在核心中留下穩定結構。

## 親和

- [[同調共鳴]]—與明確對象交換相容訊號而不產生控制。
- [[關係感知]]—辨認對象之間已存在且可驗證的關係。
- [[性質借鳴]]—暫時響應已接觸的相容性質而不奪取或複製。
- [[群體連結]]—在自願群體間共享單一低頻訊號。
- [[異質包容]]—為陌生性質建立隔離與翻譯界面。
