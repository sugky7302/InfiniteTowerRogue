# 資源

資源是技能可以消耗或產生的數值。每項[[戰鬥資源]]獨立記錄目前值、容量、取得條件、消耗時點、衰減、恢復及脫離場景後的處理。

## 支付順序

技能開始前先檢查資源是否足夠，開始施放時扣除。施放被中斷時預設不返還。若技能另有返還比例則按其記錄。支付失敗時技能不開始，也不進入冷卻。

## 戰鬥資源

[[戰鬥資源]]分為主要戰鬥資源與次要戰鬥計量。

角色預設只能承載一種主要戰鬥資源。缺少技能指定的主要資源時，即使角色具有所需知識，也只能保存[[技能草稿]]，不能完成、配置或施展技能。尚未持有主要資源的角色可由明列的培訓、修練或儀式取得第一種。職業認證本身不會自動授予。

角色必須先取得指定資源橋接知識，再依該知識明列的修練、儀式或其他途徑取得第二種主要資源。橋接知識本身不直接授予資源，也不使所有主要資源相容。

[[能量]]、[[怒氣]]、[[符能]]、[[瘋狂]]、[[集中值]]與[[法力]]是主要戰鬥資源。[[連擊點]]是次要戰鬥計量，不占主要資源欄，也不需要資源橋接。但仍須由合法效果生成，並遵守自己的目標綁定、容量與消耗規格。

各項資源自行定義容量、生成、衰減與恢復。容量可以固定或讀取一級屬性，但仍是資源規格，不是二級屬性。恢復效果必須明列作用資源，不能使用通用恢復同時影響所有資源。

## 消耗豁免

[[法力消耗豁免]]只把合格技能的一筆法力成本改為0。它不返還既有消耗，不影響其他資源，也不免除材料、施法時間、檢定、冷卻或維持條件。

## 冷卻

冷卻不是資源，而是再次開始同一技能前必須經過的時間。技能成功開始後進入冷卻。是否在命中、完成或中斷時才開始，須由技能明定。

冷卻反映角色疲憊、精神消耗與周圍元素稀薄。冷卻縮減只由裝備提供，而且必須限定指定技能或指定元素技能。具有元素容量的寶石、遺物、吊飾或其他特殊裝備，可以消耗匹配容量支援一次施放。容量不足時仍可施法，但不取得冷卻縮減。裝備容量不占角色的戰鬥資源。
