# 角色建立

## 一級屬性

每名角色初始擁有10點屬性點，可以自由分配在力量、體質、身法、精準、智力、精神與親和七項一級屬性上。單項建立時最多投入5點。

| 屬性 | 功能 |
|---|---|
| [[力量]] | 施力、承載與克服物理阻力 |
| [[體質]] | 生命、承傷與生理負荷 |
| [[身法]] | 閃避、平衡、移動與姿勢控制 |
| [[精準]] | 瞄準、開鎖、拆除、製作與精細施法 |
| [[智力]] | 解析、理解、研究與術式構築 |
| [[精神]] | 意志、感知、心靈與精神負荷 |
| [[親和]] | 與指定生物、元素或其他對象建立共鳴 |

完成配點後另擲D6，初始[[幸運]]等於骰值減1，範圍0～5，不占用上述10點。一般職業升級不增加幸運。

完成自由配點後，依[[種族#初始適性]]從該種族的兩項適性屬性中選一項增加1點。種族適性不占用上述10點，也不受單項自由投入上限限制。

一級屬性不直接參與檢定、傷害、生命或其他最終結算，統一先形成[[屬性|二級屬性]]。職業升級依[[職業系統]]增加預先固定的一級屬性。

## 唯一混成天賦

每名角色只持有一項[[天賦]]。創角後不能因升級或事件取得第二項。改變角色本質的事件只能累積改造既有天賦。

### 建立抽取袋

只讀取玩家自由分配的10點初始屬性：

- 每投入[[力量]]、[[體質]]、[[身法]]、[[精準]]、[[智力]]、[[精神]]或[[親和]]1點，加入1枚相應屬性籤。
- 種族適性增加的1點不加入。
- [[幸運]]不加入。
- 投入0點的屬性沒有籤。

### 抽取個人原型

連抽3枚屬性籤，再分別從相應的[[天賦#一點一籤|個人天賦池]]抽出3個不同的[[個人天賦原型]]。同一屬性可以中籤多次。同一原型不能重複。不相容原型從同屬性池重抽。

### 與血脈核心混成

角色種族提供一項[[種族血脈天賦範本|血脈核心]]。把該核心分別與三個個人原型混成，形成三項候選。候選必須：

- 保留血脈核心可辨識的入口。
- 完整列出深度1至5、二至三條流派、授予節點、實踐條件與兩次突破考驗。
- 不直接提供完成的主動技能。
- 把所有主動效果改寫為知識或精通，交由玩家自行構築。

### 三選一定型

玩家完整查閱三項候選後選擇1項。選中者成為角色唯一的混成天賦，初始為深度1並具有4份深化潛能。未選兩項永久消失。原始血脈核心也不作為第二項獨立天賦保留。
