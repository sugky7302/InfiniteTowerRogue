# 效果原子

效果原子是系統可以獨立驗證、比對與結算的最小效果。自然語言說明不能取代必要欄位。

## 必要欄位

| 欄位 | 說明 |
|---|---|
| 原子類型 | 傷害、加成、減傷、抗性、觸發、恢復、免疫等 |
| 數值與單位 | 點數、百分點、倍率、秒、次數或布林旗標 |
| 事件與傷害標籤 | 技能、元素、輸出分類、命中、週期等 |
| 來源限制 | 武器、法術、近戰、指定技能、裝備部位等 |
| 目標範圍 | 自身、單體、區域、召喚物、連結對象等 |
| 輸出欄位 | 原子實際修改的數值或狀態 |
| 結算層 | 建立、轉換、加成、暴擊、防禦、抗性等 |
| 優先級 | 同階段需要先後時使用 |
| 疊加群組 | 供矩陣判定相加、相斥或獨立 |
| 上限與下限 | 普通上限、絕對上限及最低值 |
| 觸發能力 | 能否觸發其他原子及禁止的連鎖 |

## 標籤

技能構築依知識自動生成可見傷害標籤及內部防禦通道。一般技能介面顯示玩家可用的成長標籤，不顯示防禦通道、原子識別碼或矩陣優先級。進階詳情可以展開來源與逐層試算。

欄位不足或同層輸出沒有合法互動關係時，技能不能正式完成，只能保存為[[技能草稿]]。
