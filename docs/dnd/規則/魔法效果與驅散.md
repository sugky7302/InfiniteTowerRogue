# 魔法效果與驅散

每個可持續的魔法效果都記錄下列欄位：來源、受益方向、效果標籤、驅散類型、效果強度、驅散門檻與特殊保護。

## 分類

- 受益方向：增益、有害或中性，以效果對當前承受者的直接作用判定。
- 效果標籤：狀態、傷害、治療、控制、移動、感知、心智、召現或其他可並列標籤。
- 驅散類型：魔法、疾病、毒素、詛咒、物理或不可驅散。
- 特殊保護：一般驅散不可處理。只有明確允許「特殊驅散」的技能可嘗試。

## 驅散判定

> 驅散檢定值＝施放者相關屬性＋[[驅散]]知識修正值＋技能加成

當驅散檢定值達到效果的驅散門檻時移除效果。特殊保護使門檻提高5，且技能必須具有特殊驅散權限。不可驅散不是更高門檻，不能以數值強行移除。

## 群體選取

區域驅散由[[魔法解析]]辨識效果，再用[[效果篩選]]建立全部合法候選，最後依技能指定順序選到目標上限。未指定時依距施法中心由近到遠，同距離以效果剩餘時間較長者優先。友軍可選有害效果，敵軍可選增益效果。每名目標的移除數量分開計算。
