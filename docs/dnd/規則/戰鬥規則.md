
## 戰鬥時間

戰鬥底層使用連續時間。每個行動都記錄開始時間、完成時間與可能的命中時間。系統依下一個事件發生的時間依序結算：

1. 角色宣告並開始行動。
2. 依[[時間與距離]]計算實際施法、移動、投射或延遲時間。
3. 時間推進到下一個事件。
4. 事件完成時，依[[檢定值]]或該遊戲模式的判定規則確認結果。
5. 成功時結算傷害、狀態及後續觸發。
6. 把新事件加入時間軸，繼續推進。

角色能否同時移動、施法、對話或互動，由行動本身與遊戲模式決定。技能規則不預設每輪只有一次主要行動。

即時動作、即時暫停、時間格、回合制與純敘事模式共用相同秒數與距離。回合制若需要輪次，必須先指定每輪代表多少秒，再把行動安排到對應時間內。

## 基礎傷害

| 攻擊方式 | 傷害 |
|---|---:|
| 徒手或臨時武器 | 2＋[[近戰攻擊力]]×0.5 |
| 單手武器 | 4＋[[近戰攻擊力]]×0.5 |
| 雙手武器 | 6＋[[近戰攻擊力]]×0.75 |
| 遠程武器 | 4＋[[遠程攻擊力]]×0.5 |
| 法術與進階技能 | 基礎值＋指定效果強度×技能係數 |

技能必須分開記錄檢定屬性與效果強度。一級屬性不能直接加入傷害。

## 傷害結算順序

完整公式與逐段範例由[[傷害]]統一擁有。摘要順序如下：

1. 驗證[[效果互動矩陣]]，生成傷害部分、可見標籤及內部防禦通道。
2. 命中後依序建立基礎傷害、附加傷害、額外獲得傷害及傷害轉換。
3. 最終標籤形成後，立即移除免疫部分。
4. 套用加算傷害、額外乘算、暴擊與格擋。
5. 格擋後仍有正傷害時，先處理[[壓碎打擊]]。
6. 依序處理降低防禦、穿透、物理或法術防禦、降低抗性、元素穿透及最終抗性。
7. 處理承傷降低、95%聯合上限、固定減傷、元素吸收與易傷。
8. 處理傷害分攤與各承受者護盾。
9. 剩餘值形成實際生命損失，再處理阻止死亡、斬殺、生命偷取、反射、受傷解除與[[施法穩定]]。

所有中間值、生命與護盾保留固定小數精度。護盾吸收不算生命值損失。固定傷害與無視減傷效果必須逐項寫明忽略哪些結算層。
