# 效果互動矩陣

矩陣由中央群組規則、[[效果原子]]自述與少量例外共同形成。系統可以展開完整矩陣供查閱，但不人工維護所有 `N×N` 格子。

## 五種關係

| 關係 | 行為 |
|---|---|
| 相斥 | 不能同時生效，依優先級或明列條件保留合法結果 |
| 相加 | 進入同一加算層 |
| 相乘 | 依固定順序形成不同乘區 |
| 相減 | 正負效果或攻防數值互相抵消 |
| 獨立 | 各自判定並可同時成立 |

關係可以有方向性，必須記錄作用者、受作用者、執行階段及優先級。相加或獨立可以明列對稱。其他關係不能只填一側後自動鏡射。

## 安全預設

- 不同結算層、不同輸出欄位且沒有觸發關係：預設獨立。
- 同一結算層或修改同一輸出欄位但沒有群組規則或例外：阻擋正式構築。
- 被阻擋內容可以保存為[[技能草稿]]，並列出缺少的矩陣關係。
- 系統不得自行猜測應該相加、相乘、覆蓋或互斥。

## 中央群組規則

| 原子A | 原子B | 關係 | 結果 |
|---|---|---|---|
| 同群組傷害增加 | 同群組傷害增加 | 相加 | 形成單一傷害加成層 |
| 傷害增加 | 傷害降低 | 相減 | 先合併再限制最低-100% |
| 傷害加成層 | 額外提高／降低 | 相乘 | 依固定乘區結算 |
| 防禦增加 | 降低防禦 | 相減 | 形成降低後防禦 |
| 降低防禦 | 攻擊者穿透 | 相乘 | 先降低再穿透 |
| 總抗性 | 降低抗性 | 相減 | 以百分點扣除 |
| 降抗後抗性 | 元素穿透 | 相減 | 以百分點扣除 |
| 壓碎打擊 | 撕裂傷口 | 獨立 | 可各自判定並同時成立 |
| 同名同強度機率 | 同名同強度機率 | 相加 | 合併後只判定一次 |
| 同名不同強度機率 | 同名不同強度機率 | 相斥 | 各自判定，成功時取最強 |
| 不同施加者持續傷害 | 不同施加者持續傷害 | 獨立 | 各自保存快照 |

## 方向性例外

| 作用原子 | 受作用原子 | 關係 | 結果 |
|---|---|---|---|
| 匹配傷害免疫 | 傷害部分 | 相斥 | 最終標籤形成後立即移除該部分 |
| 暴擊免疫 | 暴擊增幅 | 相斥 | 暴擊等同普通傷害 |
| 壓碎傷害 | 生命偷取 | 相斥 | 壓碎不提供偷取基數 |
| 分攤傷害 | 生命偷取／反射／再次分攤 | 相斥 | 禁止後續連鎖 |
| 荊棘或反射 | 荊棘或反射 | 相斥 | 禁止相互遞迴 |
| 持續週期 | 命中效果 | 相斥 | 預設不是命中。明載例外才改寫 |
| 傷害標籤 | 元素異常 | 獨立 | 標籤本身不免費建立異常 |

新增原子時，測試器必須確認同層輸出已有群組規則或例外。修改中央關係時，必須列出受影響技能、裝備與狀態。
