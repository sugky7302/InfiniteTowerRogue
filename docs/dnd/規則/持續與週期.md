# 持續與週期

持續效果使用連續時間，不依賴回合。每個效果至少記錄開始時間、持續時間、終止條件。週期效果另記錄首次觸發延遲與週期間隔。

## 結算公式

> 第 n 次觸發時間＝開始時間＋首次觸發延遲＋（n－1）×週期間隔

只有觸發時間小於或等於結束時間的事件才結算。建立效果當下不會額外跳一次，除非首次觸發延遲明定為0。週期傷害每次分別結算傷害、抵抗與觸發，不把總量預先一次扣除。

## 更新與疊加

- 同來源、同效果再次施加時，預設刷新剩餘時間，不增加層數。
- 若技能允許疊層，必須記錄層數上限、每層數值及各層共用或獨立計時。
- 數值較強但不可疊加的同類效果，以較強者生效。較弱者仍可保留計時。
- 提前解除時，移除尚未發生的事件，不追回已結算結果。

## 跨技能時間修改

[[持續時間延長]]只能修改執行時仍存在、且由[[疾病資格]]或其他明確資格觸發選中的效果。它增加剩餘時間，不改變來源、強度、週期、承受者或驅散分類，也不補發已錯過的週期事件。

燃燒因燃料耗盡、隔絕氧化條件、降溫或驅散而終止。其他效果也必須列出符合其機制的終止條件。
