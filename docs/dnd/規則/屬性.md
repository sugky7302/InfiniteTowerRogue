# 屬性

## 一級屬性

一級屬性描述角色本質能力，不由其他屬性公式產生，也不直接參與檢定、傷害、生命或其他最終結算。

- [[力量]]、[[體質]]
- [[身法]]、[[精準]]
- [[智力]]、[[精神]]
- [[親和]]、[[幸運]]

## 二級屬性

二級屬性由一級屬性與明列加成經公式形成：

- 檢定：[[屬性修正值]]
- 輸出：[[近戰攻擊力]]、[[遠程攻擊力]]、[[法術強度]]、[[治療強度]]
- 生存：[[生命值]]、[[迴避]]、[[物理防禦]]、[[法術防禦]]
- 速度與穩定：[[移動速度]]、[[攻擊速度]]、[[施法速度]]、[[施法穩定]]
- 暴擊：[[暴擊率]]、[[暴擊傷害]]
- 探索與關係：[[負重上限]]、[[尋寶率]]、[[羈絆容量]]

## 不屬於一級或二級屬性

- [[戰鬥資源]]及其容量、目前值、衰減與恢復。
- [[特殊屬性]]：傷害加成、元素抗性、穿透、減傷、吸收及命中特殊效果。
- 指定技能或元素的冷卻縮減。
- 無法冰凍、狀態免疫與忽略防禦等規則旗標。
