# 世界契約

每個主要星球、位面、文明圈或世界區域都以世界契約說明現況為何成立、衝突如何持續，以及它如何位於[[CONTEXT|共同宇宙]]中。世界契約不要求一次寫完全球百科，只要求目前會影響故事與遊戲的設定形成因果閉環。

## 八項必要欄位

### 範圍與邊界

說明本頁所稱「世界」實際涵蓋的地理、位面、文明或政治範圍，以及邊界如何辨識、進入、離開或封閉。邊界不能只用名稱假定。

### 環境條件

說明當地材料、能量、介質、空間、生命及其他會影響行動的條件。特殊環境只能改變技能的輸入、應用條件與結果，不能改寫[[CONTEXT|系列公理]]。

### 生命與文明來源

說明主要生命與文明是獨立形成、外來移民、多源混合或尚未確定。主張歷史傳播時，必須能指出旅行、交流或資訊載體證據；相似成果不自動證明共同起源。

### 知識生態

說明知識如何被發現、保存、教育、驗證、壟斷、禁止、竄改與失傳，以及哪些載體、場所與群體維持這些過程。知識生態應能解釋角色實際可接觸的學習入口。

### 力量分配

說明哪些個人、組織或制度控制資源、知識、技術、合法性與暴力，以及它們維持位置所依賴的條件。強大勢力不能只靠設定宣告，必須能追溯其供給、支持與限制。

### 歷史因果鏈

列出造成目前局勢的關鍵事件，並說明每件事改變了哪些環境、人口、知識、制度、關係或資源。只有年代與事件名稱、沒有後果連線時，不構成歷史因果鏈。

### 當代核心張力

說明目前有哪些行動者在爭奪什麼、各自害怕失去什麼，以及若沒有玩家介入，局勢將如何繼續發展。張力可以呼應[[CONTEXT|系列核心張力]]，但不必服務任何強制共同主線。

### 跨界關係

說明本世界知道哪些外部世界、透過何種旅行或資訊方式接觸，以及各方法的原因、媒介、代價與失敗條件。完全不知道外部世界也是合法答案，但必須明確記錄。

## 驗證問題

- 目前局勢能否沿歷史因果鏈追溯到具體原因？
- 主要勢力的權力是否有可失去的供給與支持？
- 知識分布是否能解釋誰能學會什麼，以及為何？
- 當代衝突是否會在沒有玩家時繼續變化？
- 特殊環境是否只改變應用條件，而未改寫系列公理？
- 跨界接觸是否符合[[因果律]]與[[0010-shared-universe-is-connected-but-usually-isolated|共同宇宙決策]]？

#規則 #世界觀 #共同宇宙 #世界契約
主要世界的契約必須先服從[[共同宇宙觀]]，再定義自身八項因果欄位。世界可以是行星、棲地、依附位面或心智域。若涉及星際、跨世界或跨宇宙，必須分別說明路徑，不得只用「傳送」概括。
