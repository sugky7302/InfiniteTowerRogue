# 時間與距離

技能系統以連續時間與實際距離作為底層資料。即時動作、即時暫停、時間格、回合制與純敘事玩法都讀取相同數值，再由各自的遊戲模式轉譯。技能本身不使用「一個主要行動」或「下一輪」作為基本單位。

## 標準單位

- 時間：秒。
- 距離：碼。1碼等於0.9144公尺。
- 速度：碼／秒。
- 百分比：計算時改寫成小數，例如20%寫成0.2。

技能根節點應依需要記錄準備時間、原始施法時間、觸發延遲、有效距離、投射速度、引導時間、持續時間、週期間隔與冷卻時間。沒有使用的欄位可以省略。

## 施法時間

第一版測試公式為：

> 原始施法時間＝0.5秒＋表面技能複雜度×0.25秒＋性能附加時間－資源折抵時間

> 實際施法時間＝原始施法時間÷（1＋[[施法速度]]）

實際施法時間最低為0.1秒。性能附加時間與資源折抵時間必須來自射程級距、效果規則、知識、精通、裝備或技能根節點明確記載的代價，不能由玩家臨時宣告。

精通降低表面技能複雜度時，也會降低由節點造成的施法時間；精通展開結構仍用於合法性與效果判定。

## 射程級距

每種遠距型態應記錄基準射程。尚未個別定義時，通用基準射程為10碼。

> 有效射程＝型態基準射程×2^射程級距

| 射程級距 | 基準10碼時的有效射程 |
|---:|---:|
| 0 | 10碼 |
| 1 | 20碼 |
| 2 | 40碼 |
| 3 | 80碼 |

每提高一個射程級距，技能設計者必須選擇並記錄一項支付方式：

- 原始施法時間增加0.25秒。
- 支付由資源規則定義的等值消耗。
- 由適用的知識、精通或裝備承擔。
- 依技能規則降低其他性能。

同一項射程成本不能被重複折抵。距離本身不會自動延長施法時間。只有選擇以時間支付射程成本時才會增加。

## 投射飛行

投射型技能在完成施法後才產生投射物：

> 投射飛行時間＝實際飛行距離÷投射速度

> 命中時間＝施法開始時間＋實際施法時間＋觸發延遲＋投射飛行時間

投射途中可以被移動、障礙、攔截、追蹤或速度變化影響。瞬間抵達的射線、傳送或其他型態必須由各自知識明確說明，不能把投射速度直接視為無限。

## 遊戲模式轉譯

- 即時動作：直接按照秒與碼更新。
- 即時暫停：按照秒更新，暫停時只停止時間推進。
- 時間格：每格代表固定秒數，所有事件向上對齊至最近時間格。
- 回合制：每輪代表由該模式指定的秒數，角色在輪內安排不超過可用時間的動作。
- 純敘事：主持人仍以秒、距離與速度判斷先後，再決定是否需要檢定。

回合長度、行動點或動畫鎖定屬於遊戲模式規則，不能改寫技能的原始秒數。

持續、週期與疊加的結算方式見[[持續與週期]]。資源支付與冷卻見[[資源]]。

指定技能或元素的冷卻縮減只能由裝備提供。寶石、遺物、吊飾或其他元素儲能裝備必須記錄元素類型、容量、每次支援成本與補充條件。一次施放預設只選一件相容裝備支付，容量不足時不取得冷卻縮減。
