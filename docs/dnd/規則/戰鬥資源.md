# 戰鬥資源

戰鬥資源是由技能或明列規則生成、消耗、衰減及恢復的獨立量表，分為主要戰鬥資源與次要戰鬥計量。每項資源自行定義容量、成本、生成、衰減與恢復。容量可以固定或讀取一級屬性，但仍屬資源規格，不是二級屬性。

## 主要戰鬥資源

[[能量]]、[[怒氣]]、[[符能]]、[[瘋狂]]、[[集中值]]與[[法力]]是角色自身持有、可供多個技能支付的主要戰鬥資源。

角色預設只能承載一種主要戰鬥資源。尚未持有主要戰鬥資源的角色，可以透過職業培訓、修練、儀式或其他明列途徑取得第一種主要戰鬥資源，不需要橋接知識。職業等級或認證本身不會自動授予資源。

角色可以學習需要其他主要資源的知識，但系統會阻止缺少指定資源的技能完成、配置或施展。未完成內容只能保存為[[技能草稿]]。

角色必須先取得指定資源的橋接知識，再透過該知識明列的修練、儀式或其他途徑取得第二種主要戰鬥資源。橋接知識本身不會直接授予資源，也不會讓所有主要資源自動相容。

## 次要戰鬥計量

[[連擊點]]是由特定技能建立並綁定目標的次要戰鬥計量。次要戰鬥計量不占主要戰鬥資源欄，因此能與一種主要戰鬥資源同時使用，也不需要資源橋接。

次要戰鬥計量不會因分類改變而免費取得。角色仍須具有合法的生成效果、目標、容量與消耗規格。缺少任一項時不能宣告、支付或保留該計量。

## 支付、衰減與恢復

- 支付順序統一見[[資源]]。
- 每種資源自行定義衰減率與衰減時點。
- 恢復效果必須明列能恢復哪一種戰鬥資源。
- 通用資源恢復不能同時影響所有資源。
