# 狀態與解除

狀態是暫時改變目標可執行行為或參數的效果。每項狀態必須記錄分類、來源、開始時間、持續時間、限制內容、解除條件及是否可被驅散。

## 狀態分類

- [[定身]]：只禁止主動位移。
- [[移動減速]]：降低移動速度，但仍可移動。
- [[昏迷]]：禁止主動移動、攻擊、施法、技能與主動反應。
- [[癱瘓]]：禁止主動移動、攻擊、施法、技能與物品操作，但不必代表意識中斷。
- [[恐懼]]：建立威脅反應。是否畏縮、不能接近或[[強制逃離]]由技能明載。
- 變形：以外來效果強制改寫承受者目前形態。自願使用自己的[[形態切換]]不是變形狀態。

定身、移動減速與技能明列為「束縛」的效果可共同帶有「移動限制」標籤。標籤只供[[移動限制解除]]篩選，不代表三種狀態彼此等同，也不包含牆壁、地形、負重、碰撞或不可驅散限制。

每項狀態分開判定與解除，名稱相近不代表彼此包含。免疫或解除其中一種狀態，不會自動影響其他狀態。

## 狀態免疫

[[狀態免疫]]必須指定一種明確狀態分類。預設只拒絕免疫生效後新施加的相符狀態，不移除既有狀態，也不阻止同一技能的傷害或其他結果。

## 受傷解除

若狀態連接[[受傷解除]]，每次實際生命值損失後獨立判定一次：

> 解除率＝基礎解除率＋本次生命值損失÷目標最大生命值

解除率限定在0至1。護盾完全吸收、免疫或零傷害不觸發。第一版基礎解除率為0。技能可以另行設定。多段傷害按實際傷害事件逐次判定。

例如[[癱瘓]]或[[恐懼]]連接受傷解除時，就使用本節公式；狀態本身限制哪些行為，則由各自的效果知識定義。

## 一般解除

到期、來源中斷、條件不再成立、成功驅散或技能指定事件都可解除狀態。解除只終止未來作用，不倒轉已發生結果。
