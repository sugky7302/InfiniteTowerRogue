# 特殊屬性

特殊屬性由裝備、天賦、知識、狀態或生物資料提供，不由一級屬性固定推導，也不加入二級屬性清單。每項特殊屬性都必須轉成[[效果原子]]，再由[[效果互動矩陣]]決定相斥、相加、相乘、相減或獨立。

## 進攻

- [[傷害加成]]：指定技能、傷害標籤與額外乘算。
- [[傷害轉換]]：附加傷害、額外獲得傷害與類型轉換。
- [[防禦削弱與穿透]]：共享防禦降低與攻擊者個人穿透。
- [[暴擊防禦]]：目標端的暴擊迴避與暴擊傷害降低。
- [[壓碎打擊]]、[[撕裂傷口]]、[[斬殺]]與[[生命百分比傷害]]。
- [[生命與資源偷取]]：生命偷取、命中恢復、擊殺恢復與指定資源抽取。
- [[外部效果係數]]：控制多段、範圍與高速技能取得外部效果的效率。

## 防禦

- [[元素抗性]]：指定抗性、降抗、元素穿透、上限與免疫。
- [[減傷與元素吸收]]：承傷降低、固定減傷、元素吸收與聯合上限。
- [[格擋與動作恢復]]：格擋率、格擋值、受擊恢復與格擋恢復。
- [[護盾與傷害分攤]]：護盾、攔截與傷害分攤。
- [[狀態與速度修正]]：指定狀態時間、速度降低、治療降低與禁療。
- [[荊棘與傷害反射]]：接觸反擊與依實際生命損失回傳的傷害。

## 持續效果

- [[持續傷害]]：快照、暴擊、週期是否視為命中及疊加模式。

所有公式與固定順序統一見[[傷害]]。個別頁面只定義來源限制、上限及與其他效果的邊界。
