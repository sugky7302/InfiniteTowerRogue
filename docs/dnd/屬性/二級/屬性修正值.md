# 屬性修正值

力量、體質、身法、精準、智力、精神、親和與幸運各自形成同名修正值：

> 屬性修正值＝min（10，⌊√一級屬性⌋）

| 一級屬性 | 修正值 |
|---:|---:|
| 0 | 0 |
| 1～3 | 1 |
| 4～8 | 2 |
| 9～15 | 3 |
| 16～24 | 4 |
| 25～35 | 5 |
| 36～48 | 6 |
| 49～63 | 7 |
| 64～80 | 8 |
| 81～99 | 9 |
| 100以上 | 10 |

屬性修正值只供[[檢定值]]及明列公式使用，不代替攻擊力、速度、防禦或其他二級屬性。
