# 尋寶率

> 尋寶率＝[[屬性修正值|幸運修正值]]×5%＋其他加成

一般上限為100%。尋寶率只提高隨機掉落成為較高品質的權重，不增加固定任務獎勵、必掉素材、劇情道具、金幣或物品數量。

## 品質加權

> 調整後權重＝基礎權重×（1＋尋寶率×階級序位）

尋寶率以小數代入。普通、精良、名品與傳世的階級序位依序為0、1、2、3。各合法階級完成加權後再正規化為100%。基礎權重為0的階級仍為0，尋寶率不能解鎖來源未提供的階級，也不提高[[掉落機制#稀有機會層|稀有命中率]]。

多人共同取得掉落時，使用實際完成搜索、開箱或採集者的尋寶率，不能把隊伍數值相加。自動結算、戰利品負責人、數值鎖定時點與完整結算順序依[[掉落機制]]處理。
