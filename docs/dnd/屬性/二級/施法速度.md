# 施法速度

施法速度是二級百分比屬性。第一版測試公式為：

> 施法速度＝（[[屬性修正值|精準修正值]]＋[[屬性修正值|智力修正值]]）×5%＋其他加成

一般上限為100%。

> 實際施法時間＝原始施法時間÷（1＋施法速度）

例如原始施法時間3秒、施法速度20%時，實際施法時間為2.5秒。最低施法時間與原始施法時間公式見[[時間與距離]]。

同一時間完成多項事件時，依序比較：

> 實際完成時間 → [[精準]] → [[身法]] → 該遊戲模式的隨機判定

受到攻擊時維持法術改用[[施法穩定]]。
