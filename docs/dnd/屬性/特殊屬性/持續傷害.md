# 持續傷害

效果建立時鎖定攻擊者端的基礎總傷害、傷害加成、額外乘算、轉換與暴擊結果。攻擊者後續換裝或增益變化不回溯修改。每次週期才讀取目標當下防禦、抗性、減傷、吸收、易傷與護盾。

持續傷害預設不能暴擊。技能若明載可以暴擊，建立時只判定一次，先計算總傷害並乘暴擊倍率，再分攤至各段；刷新時間不重擲。

週期預設不是命中，不能反覆觸發壓碎、撕裂、命中附傷或回能。只有技能明載「週期視為命中」並指定外部效果係數與施放上限時才例外。

預設同技能、同施加者只保留最強效果。不同施加者可以獨立存在。允許疊層時必須明列最大層數、時間與刷新方式，每層保存自己的快照。
