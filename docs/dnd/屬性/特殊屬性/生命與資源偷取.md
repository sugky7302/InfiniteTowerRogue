# 生命與資源偷取

## 生命偷取

> 生命偷取恢復＝合格直接命中的實際生命值損失×生命偷取率

基數不含溢出、持續、壓碎、反射、荊棘及分攤部分。生命偷取不讀取治療強度或治療暴擊，但受生命恢復降低與禁療影響。

## 命中與擊殺恢復

命中恢復是固定值，必須乘[[外部效果係數]]。完全迴避、免疫或格擋的事件不會恢復。擊殺恢復只在合法擊殺確認後觸發，不乘外部效果係數。

## 戰鬥資源

詞綴必須指定法力、怒氣、能量或其他[[戰鬥資源]]。命中恢復只增加自身。只有明寫抽取才同時減少目標相容資源。主要戰鬥資源要求角色已持有該資源或具有相應橋接資格。次要戰鬥計量則必須明列相容的綁定目標、容量與轉移規則，不能用主要資源橋接代替。
