# 狀態與速度修正

指定狀態持續時間縮短在狀態成功施加後生效，普通上限80%。持續傷害先建立原始快照，再移除超出新結束時間的後續週期。不足完整週期的尾段預設不造成傷害。

移動、攻擊與施法速度降低分開記錄：

> 實際動作時間＝原始時間÷（1＋速度加成－速度降低）

普通淨速度最低暫定-75%，即移動至少保留25%、動作時間至多為原始四倍。定身、冰凍與停止施法是獨立控制效果。

治療效果降低作用於施術者輸出端。受到生命恢復降低作用於目標端，普通上限80%。重傷只是常見狀態名稱。禁止生命恢復是獨立旗標，不影響復活、護盾或戰鬥資源恢復。
