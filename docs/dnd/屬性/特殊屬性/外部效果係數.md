# 外部效果係數

單次命中預設100%。多段、範圍或高速週期技能由技能根節點明列每段係數。

> 實際觸發率＝詞綴觸發率×外部效果係數

> 實際固定附傷＝詞綴固定附傷×外部效果係數

固定命中資源恢復也乘係數。生命偷取按實際生命損失計算，不再乘係數。技能自身內建效果不受影響。

持續傷害週期預設不是命中，外部命中效果係數為0%。引導式重複命中則屬多段直接命中，必須逐段明列係數。

同名同強度且來源限制相容的機率效果先加總，再乘係數並判定一次。強度不同時各自判定，同次成功只執行最強結果。
