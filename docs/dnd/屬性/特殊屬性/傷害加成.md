# 傷害加成

「增加／降低傷害」是同一加算層。「額外提高／額外降低傷害」才形成獨立乘區。

> 加算後傷害＝匹配傷害×max(0, 1＋增加總和－降低總和)

> 乘算後傷害＝加算後傷害×各項額外提高倍率×各項額外降低倍率

- `火焰傷害增加20%`只匹配火焰傷害部分。
- `火球術傷害增加20%`匹配仍由火球術擁有的直接與持續傷害。
- `元素傷害增加10%`同時匹配所有元素標籤，屬較稀有的廣域詞綴。
- 獨立觸發技能與召喚物傷害不自動繼承來源技能的加成。
- 同一加成來源對同一傷害部分最多套用一次。
