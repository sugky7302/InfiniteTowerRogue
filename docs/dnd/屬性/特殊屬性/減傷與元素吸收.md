# 減傷與元素吸收

承受傷害降低在防禦與抗性後結算，匹配來源加總，普通上限80%。物理或法術防禦、抗性與承傷降低乘算後，普通事件至少保留防禦前傷害的5%，等同聯合減傷上限95%。

固定傷害減少在百分比層之後，每個事件只扣一次。混合傷害按各部分占比分攤。多段技能逐段處理，最低降至0。

元素吸收再依序處理：

> 吸收後元素傷害＝max(0, 固定減傷後元素傷害×（1－百分比吸收）－固定吸收)

百分比吸收普通上限40%。吸收量預設只是不造成傷害。只有來源明載時才轉為生命、護盾或指定戰鬥資源。
