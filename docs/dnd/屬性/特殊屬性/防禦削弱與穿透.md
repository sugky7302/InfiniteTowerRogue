# 防禦削弱與穿透

降低防禦是施加於目標的共享狀態。穿透是攻擊者自己的詞綴。

> 降低後防禦＝基礎防禦×max(0, 1＋防禦增加%－防禦降低%)－固定防禦降低

> 有效防禦＝max(0, 降低後防禦×max(0, 1－百分比穿透)－固定穿透)

> 防禦減傷率＝min(80%, 有效防禦÷（有效防禦＋100）)

結算順序固定為百分比降低、固定降低、百分比穿透、固定穿透。物理與法術防禦最低為0。需要把承傷放大時使用易傷，不能建立負防禦。

每個傷害部分只有一個內部防禦通道：物理、法術或無廣泛防禦。通道由實際致傷機制生成，不顯示在一般技能介面。
