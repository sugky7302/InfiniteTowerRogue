# 元素抗性

各傷害抗性彼此獨立，預設0%，普通上限75%。全元素抗性只是同時提高各元素抗性的稀有詞綴，不形成額外減傷層。

> 總抗性＝種族＋天賦＋裝備＋知識＋狀態

> 最終抗性＝clamp(總抗性－降低抗性－元素穿透, -100%, 目前抗性上限)

降低抗性與穿透都使用百分點。降低抗性是目標共享狀態。元素穿透只供攻擊者自己使用。超額抗性在套用上限前保留，因此可以抵消降抗與穿透。

特殊來源可以提高指定元素抗性上限。單元素絕對上限暫定90%。傷害免疫是獨立規則旗標，不是100%抗性，來源必須明列能否破除。
