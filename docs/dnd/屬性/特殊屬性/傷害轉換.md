# 傷害轉換

## 固定附加傷害

固定附傷不讀取攻擊力或法術強度，但繼承承載事件的技能所有權、輸出分類、匹配加成與暴擊。詞綴必須限制武器命中、法術命中、持續週期或其他事件類型。

例如一支箭造成50物理傷害，裝備提供「遠程武器命中附加10火焰傷害」，結果為50物理＋10火焰。火焰傷害加成只提高10點部分，遠程暴擊則可同時影響兩部分。

## 額外獲得傷害

預設讀取轉換前、已完成基礎值與固定附傷的指定類型總量，再建立新的傷害部分。新部分可以被後續轉換，但不能再次觸發額外獲得。

## 傷害轉換

轉換只改變既有傷害部分，不複製傷害。總轉換率最高100%。超額來源依技能明列優先級正規化。轉換完成後才套用傷害加成、暴擊、防禦與抗性。
