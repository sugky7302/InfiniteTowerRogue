# 礦脈勘探師

## 職業概述

### 社會職責

礦脈勘探師是處理棲地、自然資源、採收時機與復育的二階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 辨識資源狀態。
- 選擇採收量。
- 留下可恢復的環境。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

採集工具、樣本袋、環境標記與防護具。

> 常用裝備只描述執業需求，不會因職業認證自動取得。
