# 林地射手

## 職業概述

### 社會職責

林地射手是處理遠程觀測、射線管理與精準投送的二階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 辨識目標。
- 估算距離與軌跡。
- 維持安全射界。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

遠程武器、觀測工具、距離標記與彈藥容器。

> 常用裝備只描述執業需求，不會因職業認證自動取得。
