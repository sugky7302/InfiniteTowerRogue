# 通靈導師

## 職業概述

### 社會職責

通靈導師是處理生命照護、精神承載、儀式邊界與異常淨化的三階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 辨識承受者。
- 記錄同意與代價。
- 在異常擴大前停止。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

儀式書、救護工具、淨化載體與記錄用品。
