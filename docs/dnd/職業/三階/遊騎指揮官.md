# 遊騎指揮官

## 職業概述

### 社會職責

遊騎指揮官是處理複合任務、多方協作、資源分配與公共責任的三階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 公開目標。
- 分配資源。
- 保留撤退與交接。
- 對結果負責。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

任務圖、通訊節點、資源清單與公開記錄。

> 常用裝備只描述執業需求，不會因職業認證自動取得。

### 認證考核

- 認證者：具有本職業資格的導師與一名獨立受影響者。
- 考核形式：現場實作、失效處理與結果交接。
