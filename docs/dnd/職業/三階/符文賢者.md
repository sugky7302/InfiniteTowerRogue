# 符文賢者

## 職業概述

### 社會職責

符文賢者是處理魔法現象、術式結構與失效邊界的三階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 辨識力量來源。
- 建立可停止的術式。
- 記錄代價。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

術式手冊、觀測器、防護符與可中止的練習載體。

> 常用裝備只描述執業需求，不會因職業認證自動取得。

### 認證考核

- 認證者：具有本職業資格的導師與一名獨立受影響者。
- 考核形式：現場實作、失效處理與結果交接。
- 通過條件：達成公開目標，正確使用工具，並在超出資格時停止。
