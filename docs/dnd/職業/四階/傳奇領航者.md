# 傳奇領航者

## 職業概述

### 社會職責

傳奇領航者是處理路線、地形、環境風險與未知區域記錄的四階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 觀測環境。
- 規劃路線。
- 維持撤退條件。
- 更新地圖。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

地圖、羅盤、量測工具、信標與野外防護具。
