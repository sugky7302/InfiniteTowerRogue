# 傳奇魔裝工匠

## 職業概述

### 社會職責

傳奇魔裝工匠是處理材料、工具、工序與可維修的成品的四階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 辨識材料。
- 控制工序。
- 檢驗品質。
- 保留維修記錄。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

量具、手工工具、防護具、樣本與工序記錄。

> 常用裝備只描述執業需求，不會因職業認證自動取得。

### 認證考核

- 認證者：具有本職業資格的導師與一名獨立受影響者。
- 考核形式：現場實作、失效處理與結果交接。
- 通過條件：達成公開目標，正確使用工具，並在超出資格時停止。
