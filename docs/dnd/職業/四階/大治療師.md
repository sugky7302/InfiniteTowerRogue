# 大治療師

## 職業概述

### 社會職責

大治療師是處理日常供應、照護、現場安全與工作交接的四階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 確認需求。
- 安排工序。
- 處理常見風險。
- 清楚交接。
- 完成後記錄結果、失敗條件與後續責任。
