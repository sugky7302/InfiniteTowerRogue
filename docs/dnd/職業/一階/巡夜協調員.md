# 巡夜協調員

## 職業概述

### 社會職責

巡夜協調員是處理複合任務、多方協作、資源分配與公共責任的一階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 公開目標。
- 分配資源。
- 保留撤退與交接。
- 對結果負責。
- 完成後記錄結果、失敗條件與後續責任。
