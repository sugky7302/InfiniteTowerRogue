# 說書人

## 職業概述

### 社會職責

說書人是處理訊息傳遞、文化表達、關係協調與公開承諾的一階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

核對訊息、辨識立場、建立可理解的表達並保留當事人能動性；完成後記錄結果、失敗條件與後續責任。

### 常用裝備

文書、樂器或演出工具、公開記錄與身分證明。

> 常用裝備只描述執業需求，不會因職業認證自動取得。
