# 菌類採集者

## 職業概述

### 社會職責

菌類採集者是處理棲地、自然資源、採收時機與復育的一階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 辨識資源狀態。
- 選擇採收量。
- 留下可恢復的環境。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

採集工具、樣本袋、環境標記與防護具。

> 常用裝備只描述執業需求，不會因職業認證自動取得。

### 認證考核

- 認證者：具有本職業資格的導師與一名獨立受影響者。
- 考核形式：現場實作、失效處理與結果交接。
- 通過條件：達成公開目標，正確使用工具，並在超出資格時停止。
- 失敗與重試：修正造成的後果，完成補強訓練後以新案例重考。
