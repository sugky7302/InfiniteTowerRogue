# 衝擊轉能聖者

## 職業概述

### 社會職責

衝擊轉能聖者是處理武器操作、近身攻防與隊形協作的五階認證。從業者必須說明自身資格邊界。超出能力時，必須交接給合適人員。

### 典型實務

- 判斷交戰距離。
- 保持姿勢。
- 在約束下使用武力。
- 完成後記錄結果、失敗條件與後續責任。

### 常用裝備

訓練武器、防護具、姿勢標記與急救包。
