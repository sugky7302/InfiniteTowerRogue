# 來源掉落表：失衡調律核心

本表依[[掉落機制]]處理[[失衡調律核心]]。終局必要物與方案結果使用必掉或活動契約，不由稀有骰封鎖。稀有層只提供非必要的陣列與共振配方。

## 來源與結算

- 來源識別：`boss-unbalanced-tuning-core-v1`
- 來源家族識別：`unbalanced-tuning-core`
- 獎勵層級：四階
- 結算觸發：完成封印、修復或分散控制之一。
- 失敗或撤退：未完成終局不結算。前庭或檔案室物品依本作根級遊戲框架的失敗與撤退剖面保存。

## 參與資格與尋寶率

- 合格參與：在終局方案確定前加入，並完成回流閥、守衛牽制、拆分、穩定或記錄職責之一。
- 戰利品負責人：進入核心室前指定。未指定時採合格者最高尋寶率。
- 鎖定時點：核心開始掃描時。

## 四層產出

| 層 | 設定 |
|---|---|
| 必掉 | 星紋晶片2份。分散控制另取得名品調律核心片3份 |
| 常規 | 抽取1次精良或名品星紋晶片 |
| 稀有 | 三環調律陣列配方或逆流分配共振配方，2500基點 |
| 貨幣 | 無 |

## 公開因果修正

| 條件 | 階段與運算 | 結果 |
|---|---|---|
| 分散控制 | 公開因果。必掉條件成立 | 取得三枚名品、完整、潔淨核心片並交由三方保管 |
| 斷片後繼續攻擊 | 公開因果。`set-state star-chip integrity=受損` | 常規星紋晶片受損，不提高數量或稀有率 |
| 修復調律 | 公開因果。不拆核心 | 不掉落核心片，世界保留受控星脈 |

## 來源研究與保底

- 保底鍵：`unbalanced-tuning-core＋四階`。
- 每次合格完成進度：1。門檻：1。
- 玩家從尚未登錄的兩份非必要配方中選一份。配方全收集後替代為1份名品星紋晶片。
- 隨機提前掉落不重置進度。必要終局資料與核心處置不在候選池。

## 經濟與刷取目標

- 節奏：劇情型。
- 單次預估：45分鐘終局段落。
- 必要內容：一次完成必定交付終局紀錄與方案結果。
- 非必要配方：隨機平均4次，但第一次完成即達保底，可立即選一份，沒有刷取門檻。
- 重複物出口：星紋晶片用於調律鑰、紀錄板及魔導陣列。
