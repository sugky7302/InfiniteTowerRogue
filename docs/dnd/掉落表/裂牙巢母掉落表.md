# 來源掉落表：裂牙巢母

本表依[[掉落機制]]結算[[裂牙巢母]]的戰利品。強攻能取得較多牙材，但治療與誘離保留生態及聲望。必要樣本不因打法或運氣被封鎖。

## 來源與結算

- 來源識別：`boss-fang-mother-v1`
- 來源家族識別：`fang-mother`
- 獎勵層級：一階
- 結算觸發：完成強攻、誘離或治療方案。
- 失敗或撤退：不結算巢母來源。先前區域素材依本作根級遊戲框架的失敗與撤退剖面保存。

## 參與資格與尋寶率

- 合格參與：在方案尚未確定前加入，並完成戰鬥、誘離、治療或現場支援之一。
- 實際處理者：完成牙垢採樣或戰後採收者。
- 鎖定時點：進入舊風車遭遇時。治療或誘離改派採樣者須在完成方案前公開。

## 公開因果修正

| 條件 | 階段與運算 | 結果 |
|---|---|---|
| 強攻 | 公開因果。`add commonDraws 1` | 多一次常規抽取，但第二關失去狼群路線提示 |
| 治療 | 公開因果。`exclude fang` | 不拔取健康牙齒，仍取得必要牙垢樣本 |
| 火焰焚燒頭部 | 公開因果。`set-state fang integrity=受損` | 裂牙批次成為受損，尋寶率不能洗掉 |

## 來源研究與保底

本來源沒有稀有候選，研究進度與門檻都為0。

## 經濟與刷取目標

- 節奏：戰役型。
- 單次預估：20分鐘首領段落。
- 代表性需求：一份可靠樣本與一份牙材。
- 基準狀態下裂牙期望產量：1.05份／次。強攻會抽完兩個不可重複候選，因此裂牙固定出現一批，平均1.50份／次。
- 重複物出口：箭頭、刀具、年齡研究及公會委託。
- 兩人共享時每人材料價值約為單人完成的50%。本作以共享製作與共同考核吸收差異。
