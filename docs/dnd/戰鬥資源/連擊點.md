# 連擊點

連擊點是綁定目標、記錄連續攻擊優勢的次要戰鬥計量，預設範圍為0～5。它不占角色唯一的主要戰鬥資源欄，因此可以和[[能量]]等一種主要資源同時使用，也不需要資源橋接。

- 角色同時只對一名目標保存連擊點。
- 改換綁定目標時，舊目標的連擊點清除，除非其他知識明載保留或轉移。
- [[連擊點生成]]只在相連攻擊成功命中後執行。
- 沒有合法生成效果時，角色不能自行建立或宣告連擊點。
- 終結技必須明列消耗時點與失敗處理。
