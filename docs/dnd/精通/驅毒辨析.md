# 驅毒辨析

驅毒辨析把[[魔法解析]]、[[投射]]與[[效果篩選]]整合成遠距建立毒素候選的固定操作。本精通不會自行終止候選。

## 取得方式

角色須具備三項前置知識各1級、已取得[[魔法解析投射]]，並完成遠距毒素分類與排序練習，再透過合法途徑取得。

## 展開結構

```text
魔法解析（核心）
└─投射（型態）
  └─效果篩選（觸發）
```

技能必須保留目標關係、受益方向、驅散類型、效果上限與排序。本精通不能把未指定候選自動視為毒素。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得印記時，以「你開始理解遠距解析與毒素篩選的連續關係（1／6）」提示。

## 精通等級

> 驅毒辨析精通等級＝魔法解析、投射與效果篩選知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 候選分層：多個毒素訊號互相干擾時，排序檢定的不利修正降低1；不增加效果上限。 |
| 5 | 毒性辨紋：未知毒素的驅散類型可被正常解析時，辨識不利修正降低1；不繞過特殊保護。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
