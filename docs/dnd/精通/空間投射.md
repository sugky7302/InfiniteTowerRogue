# 空間投射

空間投射把[[空間]]核心與[[投射]]型態整合成遠距空間作用的基礎節點。本精通不會自行移動目標。

## 取得方式

角色須使[[空間]]與[[投射]]都達1級，完成位置量測與遠距落點校準練習，再透過研究、訓練、實戰領悟或導師傳授取得。二知識精通不需要前置精通。

## 展開結構

```text
空間（核心）
└─投射（型態）
```

本精通只把空間作用送往遠方目標或落點。位移、折疊、隔離等結果仍須接上相容效果知識。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解空間定位與投射的穩定關係（1／4）」提示角色。

## 精通等級

> 空間投射精通等級＝空間與投射知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 坐標校正：因可見落點輕微移動造成的不利修正降低1。不忽略視線或遮蔽。 |
| 5 | 邊界感知：辨識投射路徑上的已知封閉邊界時，相關觀察不利修正降低1；不使技能穿越邊界。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入成本。
