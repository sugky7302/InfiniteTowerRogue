# 暗影箭構築

暗影箭構築把[[暗影]]、[[投射]]與[[暗影之毀滅]]整合成一個精通節點，用於遠距集中釋放即時暗影傷害。本精通不能單獨配置或施展。

## 取得方式

角色需三項知識都達1級、已取得[[暗影投射]]，並完成暗影儲能、投射與命中釋放練習，再透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。

## 展開結構

```text
暗影（核心）
└─投射（型態）
  └─暗影之毀滅（效果）
```

展開後形成完整即時暗影傷害路徑。距離、速度、傷害、施法時間與資源仍由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始理解暗影投射物命中後的集中釋放（1／6）」提示；正式領悟後公開全部里程碑。

## 精通等級

> 暗影箭構築精通等級＝暗影、投射與暗影之毀滅知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 儲能保真：施法維持受短暫光照擾動時，相關不利修正降低1；不降低受傷維持難度。 |
| 6 | 命中釋放：投射物成功命中時，因儲能洩漏造成的傷害不利修正降低1；不提高基礎傷害。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入負載。
