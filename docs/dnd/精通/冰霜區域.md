# 冰霜區域

冰霜區域把[[冰霜]]核心與[[區域]]型態整合，使低溫作用穩定覆蓋指定空間。本精通不會自行分辨敵我或建立控制。

## 取得方式

角色需要冰霜1級與區域1級，完成低溫邊界與範圍展開練習後，透過訓練、研究、實戰領悟或特殊事件取得。二知識精通不需要前置精通。

## 展開結構

```text
冰霜（核心）
└─區域（型態）
```

技能根節點可以啟用[[冰霜]]支持的直接冰霜傷害。區域大小、中心、代價與目標資格仍由技能記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得印記時，以「你開始理解低溫與區域邊界的穩定關係（1／4）」提示。

## 精通等級

> 冰霜區域精通等級＝冰霜與區域知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 冷界穩定：環境溫差直接干擾區域邊界時，相關不利修正降低1；不擴大區域。 |
| 5 | 低溫均布：區域內介質差異直接造成低溫分布不利修正時降低1。不提高傷害或控制強度。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
