# 加速覆體

加速覆體把[[加速]]核心與[[覆體]]型態整合成讓指定速率調整貼合自身或目標的固定操作。本精通不會自行指定被提高的參數或倍率。

## 取得方式

角色需要加速1級與覆體1級，完成指定過程、能量輸入與自身承受練習後，透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。二知識精通不需要前置精通。

## 展開結構

```text
加速（核心）
└─覆體（型態）
```

技能仍須指定被加速過程、倍率、持續時間、安全上限與合法結果。持續提高參數必須另接[[增益]]。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得印記時，以「你開始理解速率調整與覆體承載的穩定關係（1／4）」提示。

## 精通等級

> 加速覆體精通等級＝加速與覆體知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 負荷調節：普通姿態變化直接干擾覆體加速時，相關不利修正降低1；不提高加速倍率。 |
| 5 | 均勻輸入：能量分布不均造成的不利修正降低1。不延長持續時間或免除資源。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
