# 範圍投射

範圍投射是把[[投射]]與[[區域]]整合成一個精通節點的技巧，讓力量抵達指定落點後向周圍展開。本精通缺少核心與結果來源，不能單獨配置或施展。

## 取得方式

角色需要投射1級與區域1級，完成落點與範圍展開的整合練習，再透過訓練、研究、實驗、實踐、戰鬥領悟、導師傳授或特殊事件取得。二知識精通不需要前置精通。滿足知識條件本身不會自動取得。

## 展開結構

```text
投射（型態）
└─區域（型態）
```

放入技能時，前方必須接上適用核心，並由技能中的核心或後續效果提供合法結果。區域本身不會自動分辨敵我、穿越障礙或產生傷害。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解投射落點與範圍展開之間的穩定關係（1／4）」提示角色。達到最低門檻時，公開本精通名稱、展開結構與領悟檢定條件；正式領悟後，再公開全部里程碑與技法。

## 精通等級

> 範圍投射精通等級＝投射與區域知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 落點校準：落點可被正常判定時，風勢、移動表面、碰撞偏移或地形起伏造成的落點不利修正降低1；不降低看不見落點、感知不足或空間異常造成的不利修正。 |
| 5 | 邊界穩定：障礙物或不規則地形使作用區域變形或縮小時，縮小程度降低一級；區域仍不能穿越原本無法穿越的邊界，也不能超過原始作用區域。 |

達到里程碑只會解鎖技法。技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入技能複雜度與迴路負載。
