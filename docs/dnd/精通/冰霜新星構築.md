# 冰霜新星構築

冰霜新星構築把區域冰霜傷害、敵對資格、定身及受傷解除整合成完整固定子樹。

## 取得方式

角色須具備五項前置知識各2級、已取得[[冰霜新星定身]]，並完成受傷解除凍結的完整實踐，再透過合法途徑取得。

## 展開結構

```text
冰霜（核心）
└─區域（型態）
  └─敵對資格（觸發）
    └─定身（效果）
      └─受傷解除（觸發）
```

技能根節點可以啟用冰霜直接傷害。傷害數值、區域、法力、持續時間、冷卻及解除公式仍須由技能記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 5 |
| 進入領悟池 | 10枚整合印記 |
| 自動領悟 | 20枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級5 |

第一次取得印記時，以「你開始整合冰霜新星與受傷解除的完整關係（1／10）」提示。

## 精通等級

> 冰霜新星構築精通等級＝五項內含知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 5 | 破冰讀取：多段傷害快速發生時，受傷解除事件排序的不利修正降低1；仍逐次判定。 |
| 7 | 凍結分流：多名目標同時受傷時，分別保存解除判定，不因事件重疊獲得不利修正；不改變解除率。 |
| 9 | 冰殼辨傷：護盾吸收與生命損失訊號直接混淆時，解除觸發辨識不利修正降低1；護盾完全吸收仍不觸發。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
