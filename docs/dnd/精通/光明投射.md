# 光明投射

光明投射把[[光明]]核心與[[投射]]型態整合成遠距傳遞光明作用的基礎節點。

## 取得方式

角色須使[[光明]]與[[投射]]都達1級，完成光譜穩定與遠距落點練習，再經由研究、訓練、實戰領悟或導師傳授取得。二知識精通不需要前置精通。

## 展開結構

```text
光明（核心）
└─投射（型態）
```

本精通只負責產生並傳遞光明。解除、免疫、增益或其他結果仍須由相容效果知識提供。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解光明與投射的穩定關係（1／4）」提示角色。

## 精通等級

> 光明投射精通等級＝光明與投射知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 光譜穩定：環境光直接干擾投射辨識時，相關不利修正降低1；不忽略看不見目標。 |
| 5 | 遠距校準：在技能原有合法射程內，極端距離造成的不利修正降低1。不增加最大射程。 |

技法必須附掛在本精通節點上。附掛技法時，必須支付技法成本。
