# 陷阱範圍投射

陷阱範圍投射把[[陷阱裝置]]、[[投射]]與[[區域]]整合成一個精通節點，用於把陷阱部署到遠方並建立感應區。本精通尚未提供啟動條件或載荷結果。

## 取得方式

角色需三項知識都達1級、已取得[[範圍投射]]，並完成裝置落點與感應邊界練習，再透過訓練、研究、實踐、戰鬥領悟、導師傳授或特殊事件取得。

## 展開結構

```text
陷阱裝置（核心）
└─投射（型態）
  └─區域（型態）
```

展開後已有核心與型態，但必須接上啟動觸發及合法載荷結果。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始理解陷阱落點與感應區展開的關係（1／6）」提示；正式領悟後公開全部里程碑。

## 精通等級

> 陷阱範圍投射精通等級＝陷阱裝置、投射與區域知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 落點校準：合法射程內因普通地形起伏造成的落點不利修正降低1。不忽略遮蔽。 |
| 6 | 邊界整形：感應區受狹窄地形壓縮時，控制邊界的不利修正降低1；不穿越牆面。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入負載。
