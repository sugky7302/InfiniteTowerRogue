# 淨魔辨析

淨魔辨析把[[魔法解析]]、[[投射]]與[[效果篩選]]整合成遠距辨識並建立有限魔法效果候選的固定操作。本精通不會自行終止候選效果。

## 取得方式

角色需三項知識都達1級、已取得[[魔法解析投射]]，並完成遠距辨識與分類練習，再透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。

## 展開結構

```text
魔法解析（核心）
└─投射（型態）
  └─效果篩選（觸發）
```

技能仍須記錄射程、目標關係、受益方向、驅散類型、候選上限、排序與失敗處理。實際終止效果必須另接[[驅散]]。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得印記時，以「你開始理解遠距解析與效果分類的連續關係（1／6）」提示。

## 精通等級

> 淨魔辨析精通等級＝魔法解析、投射與效果篩選知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 類別聚焦：技能已明列單一效果標籤時，魔法雜訊造成的分類不利修正降低1；不增加候選數或繞過特殊保護。 |
| 6 | 快速排序：候選同時符合既定分類時，排序判定造成的不利修正降低1；不改寫技能指定的排序規則。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
