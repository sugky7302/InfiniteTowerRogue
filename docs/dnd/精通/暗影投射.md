# 暗影投射

暗影投射把[[暗影]]核心與[[投射]]型態整合成一個精通節點，用於把暗影作用送往遠方。本精通缺少結果來源，不能單獨配置或施展。

## 取得方式

角色需要暗影1級與投射1級，完成暗影承載與飛行路徑練習，再透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。滿足條件不會自動取得。

## 展開結構

```text
暗影（核心）
└─投射（型態）
```

展開後已有核心與型態，但尚未產生合法結果。放入技能時必須接上相容效果。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解暗影如何穩定承載於投射路徑（1／4）」提示；正式領悟後公開全部里程碑。

## 精通等級

> 暗影投射精通等級＝暗影與投射知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 輪廓收束：暗影投射物因低照度而難以維持輪廓時，相關不利修正降低1；不提供隱形。 |
| 5 | 路徑穩定：環境光變化直接干擾投射時，相關不利修正降低1；不增加射程或速度。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入負載。
