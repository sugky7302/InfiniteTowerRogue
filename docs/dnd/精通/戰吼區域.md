# 戰吼區域

戰吼區域把[[戰吼技藝]]與[[區域]]整合為一個聲音作用區節點，用於穩定控制咆哮的距離與邊界。本精通沒有接收資格或效果，不能單獨配置或施展。

## 取得方式

角色須使兩項知識都達1級，完成不同介質與障礙環境中的咆哮邊界練習，再透過訓練、實踐、戰鬥領悟、導師傳授或特殊事件取得。二知識精通不需要前置精通。符合條件不會自動取得。

## 展開結構

```text
戰吼技藝（核心）
└─區域（型態）
```

展開後已有核心與型態，但仍須接上接收資格及合法結果。音量、距離、形狀與障礙處理由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解咆哮強度與區域邊界的關係（1／4）」提示角色；正式領悟後公開全部里程碑。

## 精通等級

> 戰吼區域精通等級＝戰吼技藝與區域知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 邊界校準：普通環境回聲干擾區域邊界時，相關不利修正降低1；不增加距離。 |
| 6 | 聲壓均布：區域內普通介質差異造成傳播不穩時，相關不利修正降低1；不忽略完全隔音。 |

達到里程碑只解鎖技法。技法須附掛本精通節點，並依[[精通#精通技法成本|精通技法成本]]計入負載。
