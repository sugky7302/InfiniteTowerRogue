# 火焰投射

火焰投射是把[[火焰]]核心與[[投射]]型態整合成一個精通節點的技巧，專注於穩定地把火焰送往遠方。本精通本身不是技能，必須放入具有技能根節點的設計稿。

## 取得方式

角色需要火焰1級與投射1級，並完成基礎遠程火焰練習，再透過訓練、研究、實戰領悟或特殊事件取得本精通。二知識精通不需要前置精通。滿足知識條件本身不會自動取得。

## 展開結構

```text
火焰（核心）
└─投射（型態）
```

本精通展開後可以由技能根節點啟用[[火焰]]支持的直接火焰傷害或其他合法內稟結果。結果數值、距離、資源與性能代價仍須由技能記錄。若技能沒有啟用合法結果，本精通只完成火焰的遠程傳遞。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解火焰與投射之間的穩定關係（1／4）」提示角色正在理解的關係。達到最低門檻時，公開本精通名稱、展開結構與領悟檢定條件；正式領悟後，再公開全部里程碑與技法。

## 精通等級

> 火焰投射精通等級＝火焰與投射知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 抗擾投射：風勢、降水或能量擾動直接干擾火焰形態或投射路徑時，相關不利修正降低1；不降低視線遮蔽、看不見目標或感知不足造成的不利修正。 |
| 5 | 遠距校準：在技能原有合法射程內，極端距離造成的投射不利修正降低1。不增加最大射程，也不降低視線或感知問題造成的不利修正。 |

達到里程碑只會解鎖技法。技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入技能複雜度與迴路負載。
