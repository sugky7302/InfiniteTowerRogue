# 戰吼傳聲

戰吼傳聲把[[可聽見]]加入[[戰吼區域]]的固定結構，整合咆哮區域與聲音接收資格。本精通尚未提供鼓舞、恐懼或其他結果，不能單獨配置或施展。

## 取得方式

角色須使三項知識都達1級、已取得[[戰吼區域]]，並完成距離、遮蔽、介質與聽覺閾值的整合練習，再透過訓練、實踐、戰鬥領悟、導師傳授或特殊事件取得。符合條件不會自動取得。

## 展開結構

```text
戰吼技藝（核心）
└─區域（型態）
  └─可聽見（觸發）
```

展開後可以建立有限聲音候選並檢查是否能接收，但仍須接上合法效果。聲音來源、距離、介質、遮蔽與最低感知條件由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始把咆哮區域與聽覺接收整合起來（1／6）」提示角色；正式領悟後公開全部里程碑。

## 精通等級

> 戰吼傳聲精通等級＝戰吼技藝、區域與可聽見知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 回聲辨位：普通回聲使目標接收方向不明時，相關不利修正降低1；不繞過遮蔽。 |
| 7 | 閾值維持：聲音剛好接近聽覺閾值時，接收檢定的不利修正降低1；不影響無法聽見者。 |

達到里程碑只解鎖技法。技法須附掛本精通節點，並依[[精通#精通技法成本|精通技法成本]]計入負載。
