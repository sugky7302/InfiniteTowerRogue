# 逃脫構築

逃脫構築把[[機動戰技]]、[[軌跡]]與[[躍擊]]整合成一個精通節點，用於沿已檢查路線主動躍離原位。本精通不能單獨配置或施展。

## 取得方式

角色需三項知識都達1級、已取得[[機動軌跡]]，並完成方向固定、起跳與安全落地練習，再透過訓練、實踐、戰鬥領悟、導師傳授或特殊事件取得。

## 展開結構

```text
機動戰技（核心）
└─軌跡（型態）
  └─躍擊（效果）
```

展開後形成完整主動躍擊路徑。方向、距離、速度、落點與冷卻仍由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始理解規劃路線、起跳與著地的完整節奏（1／6）」提示；正式領悟後公開全部里程碑。

## 精通等級

> 逃脫構築精通等級＝機動戰技、軌跡與躍擊知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 急速轉勢：固定躍擊方向時，普通姿勢變化造成的不利修正降低1；不改變最終方向。 |
| 6 | 收身著地：成功抵達合法落點時，恢復站立姿態的動作延遲降低0.1秒；不免疫墜落或碰撞。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入負載。
