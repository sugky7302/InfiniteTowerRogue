# 腐蝕構築

腐蝕構築把[[暗影]]、[[印記]]與[[暗影之侵蝕]]整合成一個精通節點，用於讓暗影印記持續破壞目標結構。本精通不能單獨配置或施展。

## 取得方式

角色需要暗影1級、印記1級、暗影之侵蝕2級，已取得[[暗影印記]]，並完成持續侵蝕與驅散觀察，再透過訓練、研究、實戰領悟或特殊事件取得。滿足前置不會自動取得。

## 展開結構

```text
暗影（核心）
└─印記（型態）
  └─暗影之侵蝕（效果）
```

展開後形成完整週期暗影傷害路徑。每次傷害、週期、總持續時間、刷新、驅散分類與終止條件仍由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始理解暗影印記與持續侵蝕的固定循環（1／6）」提示。正式領悟後公開全部里程碑。

## 精通等級

> 腐蝕構築精通等級＝暗影、印記與暗影之侵蝕知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 侵蝕保真：介質或表層差異直接干擾侵蝕時，相關不利修正降低1；不忽略免疫或驅散。 |
| 6 | 末期加深：只剩最後一個週期時，該次週期檢定獲得有利加成1；不提高傷害數值。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入技能複雜度與迴路負載。
