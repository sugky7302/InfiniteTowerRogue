# 空間門徑

空間門徑把[[空間]]核心與[[門徑]]型態整合成連接兩個合法位置的固定操作。本精通只建立入口與出口，不會自行移動目標。

## 取得方式

角色需要空間1級與門徑1級，完成入口、出口、方向與邊界測量練習後，透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。二知識精通不需要前置精通。

## 展開結構

```text
空間（核心）
└─門徑（型態）
```

技能仍須指定兩端位置、尺寸、方向、通行限制與失敗處理。位移必須另接[[空間之位移]]。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得印記時，以「你開始理解空間位置與門徑連接的穩定關係（1／4）」提示。

## 精通等級

> 空間門徑精通等級＝空間與門徑知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 邊界校準：普通空間邊界雜訊直接干擾門徑定位時，相關不利修正降低1；不穿越封閉邊界。 |
| 5 | 出口穩定：合法出口附近的輕微空間擾動造成的不利修正降低1。不使非法落點合法化。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
