# 冰霜敵域

冰霜敵域把[[冰霜]]、[[區域]]與[[敵對資格]]整合，使區域低溫作用在執行結果前排除自身、友軍與中立候選。

## 取得方式

角色須具備三項前置知識各1級、已取得[[冰霜區域]]，並完成區域關係辨識練習後透過合法途徑取得。

## 展開結構

```text
冰霜（核心）
└─區域（型態）
  └─敵對資格（觸發）
```

目標關係依每次觸發時判定。本精通不會繞過視線、遮蔽、免疫或其他資格。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得印記時，以「你開始理解低溫區域與敵對資格的連續關係（1／6）」提示。

## 精通等級

> 冰霜敵域精通等級＝冰霜、區域與敵對資格知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 關係定界：區域邊緣的目標關係判定受直接干擾時，相關不利修正降低1；不改變陣營關係。 |
| 5 | 敵域校準：多名敵人重疊直接干擾候選辨識時，相關不利修正降低1；不增加作用範圍。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
