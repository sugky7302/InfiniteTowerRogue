# 移動加速構築

移動加速構築把[[加速]]、[[覆體]]與[[增益]]整合成短時間提高承受者移動速度的完整精通節點。

## 取得方式

角色需三項知識都達1級、已取得[[加速覆體]]，並完成移動速率、安全負荷與持續增益練習，再透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。

## 展開結構

```text
加速（核心）
└─覆體（型態）
  └─增益（效果）
```

本精通形成完整移速增益路徑。倍率、持續時間、目標、疊加群組、資源與受影響移動方式由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得印記時，以「你開始理解覆體加速與移動增益的完整關係（1／6）」提示。

## 精通等級

> 移動加速構築精通等級＝加速、覆體與增益知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 起步穩定：從靜止開始移動時的普通姿態干擾降低1。不提高移動速度倍率。 |
| 6 | 轉向協調：高速轉向直接造成的不利修正降低1。不免疫地形、碰撞或移動限制。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
