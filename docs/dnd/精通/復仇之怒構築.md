# 復仇之怒構築

復仇之怒構築把[[光明]]、[[覆體]]與[[增益]]整合成一個精通節點，用於以貼身光明同時維持多項自身參數增益。本精通不能單獨配置或施展。

## 取得方式

角色需要光明1級、覆體1級、增益2級，已取得[[光明覆體]]，並完成多參數增益與到期移除練習，再透過訓練、研究、實戰領悟或特殊事件取得。滿足前置不會自動取得。

## 展開結構

```text
光明（核心）
└─覆體（型態）
  └─增益（效果）
```

展開後形成完整自身增益路徑。受影響參數、倍率、疊加群組、持續時間、驅散分類與冷卻仍由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始理解光明覆體如何同步維持多項增益（1／6）」提示。正式領悟後公開全部里程碑。

## 精通等級

> 復仇之怒構築精通等級＝光明、覆體與增益知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 同步退散：增益到期或被驅散時，三項參數必定在同一結算時點移除；不提高效果強度。 |
| 6 | 光勢穩定：直接干擾光明覆體的維持檢定獲得有利加成1。不抵抗正式驅散。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入技能複雜度與迴路負載。
