# 魔法解析投射

魔法解析投射把[[魔法解析]]與[[投射]]整合成遠距辨識持續效果的固定操作。本精通只傳遞解析作用，不會自行篩選或驅散效果。

## 取得方式

角色需要魔法解析1級與投射1級，完成遠距效果辨識練習後，透過訓練、研究、實戰領悟或特殊事件取得。二知識精通不需要前置精通。

## 展開結構

```text
魔法解析（核心）
└─投射（型態）
```

技能仍須記錄射程、目標、遮蔽及辨識失敗處理。終止效果必須另接[[驅散]]。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得印記時，以「你開始理解如何把解析作用穩定送往遠處（1／4）」提示。

## 精通等級

> 魔法解析投射精通等級＝魔法解析與投射知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 訊號校準：距離直接干擾效果辨識時，相關不利修正降低1；不增加射程或繞過遮蔽。 |
| 5 | 解析穩定：相容魔法雜訊直接干擾解析投射時，相關不利修正降低1；不降低目標特殊保護。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
