# 空間牽引構築

空間牽引構築把[[空間]]、[[投射]]與[[空間之位移]]整合成遠距移動目標的固定結構。

## 取得方式

角色須使三項知識都達1級、已取得[[空間投射]]，並反覆完成合法終點、抵抗成功及終點失效等牽引實驗，再透過研究、實戰領悟或導師傳授取得。

## 展開結構

```text
空間（核心）
└─投射（型態）
  └─空間之位移（效果）
```

本精通形成完整位移路徑，但技能仍須記錄目標、起點、終點、距離、方向、抵抗方式、邊界與失敗條件。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始整合遠距定位與目標位移（1／6）」提示角色。

## 精通等級

> 空間牽引構築精通等級＝空間、投射與空間之位移知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 終點校正：候選終點因輕微占位而需在原合法區域內調整時，相關不利修正降低1；不擴大區域。 |
| 5 | 穩定牽引：環境擾動直接干擾位移方向時，相關不利修正降低1；不降低目標抵抗。 |
| 8 | 強制收束：施展前可承受不利修正2。若對抗成功，可把合法終點距離施術者再縮短2碼，但仍不得重疊或穿越邊界。 |

技法不會免除強制位移抵抗、合法終點或封閉邊界。
