# 敵對陷阱感應

敵對陷阱感應把[[敵對資格]]加入[[陷阱感應部署]]，讓裝置只接受敵人進入事件。本精通仍須接上具體載荷結果。

## 取得方式

角色需五項知識都達1級、已取得[[陷阱感應部署]]，並完成友軍、中立與敵對候選的辨識測試，再透過訓練、研究、實踐、戰鬥領悟、導師傳授或特殊事件取得。

## 展開結構

```text
陷阱裝置（核心）
└─投射（型態）
  └─區域（型態）
    └─區域進入時（觸發）
      └─敵對資格（觸發）
```

展開後能選出第一名合格敵人，但仍須接上場域、控制或其他合法結果。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 5 |
| 進入領悟池 | 10枚整合印記 |
| 自動領悟 | 20枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級5 |

第一次取得整合印記時，以「你開始理解感應事件與敵對資格的先後關係（1／10）」提示；正式領悟後公開全部里程碑。

## 精通等級

> 敵對陷阱感應精通等級＝陷阱裝置、投射、區域、區域進入時與敵對資格知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 5 | 關係重查：觸發瞬間重算敵對關係時，短暫辨識干擾造成的不利修正降低1；不鎖定永久關係。 |
| 10 | 自身排除：混亂場面中排除施放者自身的資格檢查自動成功。不排除友軍或中立者的正常檢查。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入負載。
