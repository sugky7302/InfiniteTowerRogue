# 振奮咆哮構築

振奮咆哮構築把[[增益]]加入[[戰吼傳聲]]，封裝咆哮傳播、接收資格與有利參數調整的完整固定結構。本精通不能單獨配置或施展。

## 取得方式

角色須使四項知識都達1級、已取得[[戰吼傳聲]]，並完成隊伍關係、聲音邊界、生命倍率與效果結束的整合練習，再透過訓練、實踐、戰鬥領悟、導師傳授或特殊事件取得。符合條件不會自動取得。

## 展開結構

```text
戰吼技藝（核心）
└─區域（型態）
  └─可聽見（觸發）
    └─增益（效果）
```

展開後形成合法的戰吼增益路徑。受影響參數、倍率、目標關係、持續時間、疊加群組與驅散分類仍由技能根節點記錄。因此本精通可重用於不同士氣增益技能。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 4 |
| 進入領悟池 | 8枚整合印記 |
| 自動領悟 | 16枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級4 |

第一次取得整合印記時，以「你開始理解咆哮如何把士氣轉成穩定增益（1／8）」提示角色；正式領悟後公開全部里程碑。

## 精通等級

> 振奮咆哮構築精通等級＝戰吼技藝、區域、可聽見與增益知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 4 | 同調起聲：隊伍成員分散於普通混響環境時，維持同一增益實例的相關不利修正降低1；不擴大範圍。 |
| 8 | 收聲穩定：增益自然到期時，移除本技能兩項同源倍率的順序不再受到普通事件排序干擾；不延長持續時間。 |

達到里程碑只解鎖技法。技法須附掛本精通節點，並依[[精通#精通技法成本|精通技法成本]]計入負載。
