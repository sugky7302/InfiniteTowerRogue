# 門徑位移構築

門徑位移構築把[[空間]]、[[門徑]]與[[空間之位移]]整合成建立短暫門徑並把指定目標移到合法出口的完整精通節點。

## 取得方式

角色需三項知識都達1級、已取得[[空間門徑]]，並完成起點、出口與位移安全練習，再透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。

## 展開結構

```text
空間（核心）
└─門徑（型態）
  └─空間之位移（效果）
```

本精通形成完整位移路徑。距離、目標、出口算法、邊界、重疊限制、資源與失敗處理由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得印記時，以「你開始理解門徑建立與安全位移的完整關係（1／6）」提示。

## 精通等級

> 門徑位移構築精通等級＝空間、門徑與空間之位移知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 安全落點：合法落點的細微地形誤差造成的不利修正降低1。不允許與障礙或實體重疊。 |
| 6 | 快速定標：已知且可感知出口的定位干擾降低1。不增加最大距離或繞過遮蔽。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
