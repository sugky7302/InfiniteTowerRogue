# 驅毒構築

驅毒構築把遠距辨識、毒素篩選與驅散整合成完整子樹，用於終止目標身上的合法毒素效果。

## 取得方式

角色須具備四項前置知識各2級、已取得[[驅毒辨析]]，並完成多毒素逐一驅散練習，再透過訓練、研究、實戰領悟、導師或特殊事件取得。

## 展開結構

```text
魔法解析（核心）
└─投射（型態）
  └─效果篩選（觸發）
    └─驅散（效果）
```

本精通形成完整作用路徑，但技能仍須記錄目標、射程、法力、毒素限定、效果上限、排序、驅散門檻及特殊保護。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 4 |
| 進入領悟池 | 8枚整合印記 |
| 自動領悟 | 16枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級4 |

第一次取得印記時，以「你開始整合遠距辨毒與逐一驅散（1／8）」提示。

## 精通等級

> 驅毒構築精通等級＝四項內含知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 4 | 驅散定序：同一目標有多個合法毒素時，可在施放前指定其中一個優先處理；不增加成功率或候選數。 |
| 6 | 殘毒追讀：一次驅散失敗後，對同一候選於本次技能內的後續辨識不利修正降低1。不允許額外驅散次數。 |
| 8 | 穩定淨毒：普通毒素的外部魔法雜訊直接造成不利修正時降低1。不處理不可驅散效果。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
