# 獻祭構築

獻祭構築把[[火焰]]、[[投射]]與[[火之燃燒]]整合成一個精通節點，用於先以火焰命中，再讓可燃目標持續燃燒的單體技能。本精通不能單獨配置或施展。

## 取得方式

角色需要火焰1級、投射1級、火之燃燒2級，已取得[[火焰投射]]，並完成單體點燃與週期控制練習，再透過訓練、研究、實戰領悟或特殊事件取得。滿足前置不會自動取得本精通。

## 展開結構

```text
火焰（核心）
└─投射（型態）
  └─火之燃燒（效果）
```

展開後形成完整的「核心→型態→合法結果」路徑。直接火焰傷害仍須由技能根節點啟用；燃燒數值、週期、持續時間與終止條件也保留在技能根節點。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始理解單體火焰命中後如何穩定維持燃燒（1／6）」提示。正式領悟後公開全部里程碑。

## 精通等級

> 獻祭構築精通等級＝火焰、投射與火之燃燒知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 穩定灼燒：直接傷害成功建立燃燒時，環境擾動造成的燃燒維持不利修正降低1；不忽略缺氧、無燃料或降溫。 |
| 6 | 延燃校準：技能原有持續時間內，刷新燃燒時可保留最多一個尚未觸發的週期。不增加總週期數。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入技能複雜度與迴路負載。
