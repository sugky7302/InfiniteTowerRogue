# 冰霜新星定身

冰霜新星定身把區域低溫、敵對篩選與凍結定身整合成固定子樹，但不包含受傷後解除。

## 取得方式

角色須具備四項前置知識各2級、已取得[[冰霜敵域]]，並完成敵對目標凍結練習，再透過訓練、研究、實戰領悟、導師或特殊事件取得。

## 展開結構

```text
冰霜（核心）
└─區域（型態）
  └─敵對資格（觸發）
    └─定身（效果）
```

技能必須記錄區域、傷害、定身時間、抵抗與驅散分類。本精通不提供受傷解除或額外傷害。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 4 |
| 進入領悟池 | 8枚整合印記 |
| 自動領悟 | 16枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級4 |

第一次取得印記時，以「你開始整合敵域低溫與凍結定身（1／8）」提示。

## 精通等級

> 冰霜新星定身精通等級＝四項內含知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 4 | 冰縛穩定：目標普通掙扎直接造成的定身維持不利修正降低1。不延長持續時間。 |
| 6 | 邊界凝結：區域邊緣目標的凍結成立檢定不利修正降低1。不擴大區域。 |
| 8 | 分離結晶：多名目標互相接觸直接干擾各自定身時，相關不利修正降低1；各目標仍獨立解除。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
