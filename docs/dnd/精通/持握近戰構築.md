# 持握近戰構築

持握近戰構築把[[持握中]]、[[武器技藝]]與[[接觸]]整合成一個近戰武器作用節點。

## 取得方式

角色須使三項知識都達1級、已取得[[持握武技]]，並完成以持握戰具在接觸距離內攻擊不同合法目標的整合練習，再經由訓練、實戰領悟或導師傳授取得。

## 展開結構

```text
持握中（觸發）
└─武器技藝（核心）
  └─接觸（型態）
```

戰具明載的切割、穿刺或衝擊可以由技能根節點啟用為合法內稟結果。武器係數、目標、資源與命中仍須由技能記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始整合持握、武技與近戰接觸（1／6）」提示角色。

## 精通等級

> 持握近戰構築精通等級＝持握中、武器技藝與接觸知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 貼身校準：目標仍在技能原有合法接觸距離內時，因相對站位不穩造成的不利修正降低1；不增加射程。 |
| 5 | 收勢防失：本技能未命中時，下一次抵抗同一目標繳械的不利修正降低1，持續至下次行動開始。 |
| 8 | 破綻追擊：施展前可承受不利修正2。若命中，由本精通啟用的該次武器傷害增加4點，不影響其他分支。 |

技法必須附掛於本精通節點並支付成本，不會免費改變武器係數或資源消耗。
