# 光明覆體

光明覆體把[[光明]]核心與[[覆體]]型態整合成一個精通節點，用於讓可見光能穩定貼合生物、物件或施術者表面。本精通缺少結果來源，不能單獨配置或施展。

## 取得方式

角色需要光明1級與覆體1級，並完成貼身光場與覆蓋邊界練習，再透過訓練、研究、實戰領悟或特殊事件取得。二知識精通不需要前置精通。滿足知識條件不會自動取得。

## 展開結構

```text
光明（核心）
└─覆體（型態）
```

展開後只完成光明在目標表面的依附。照明、增益、耀目或其他結果必須由後續效果與技能根節點提供。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解光明如何沿目標表面穩定覆蓋（1／4）」提示。正式領悟後公開全部里程碑。

## 精通等級

> 光明覆體精通等級＝光明與覆體知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 邊界收束：光明覆體越過指定身體或物件邊界時，相關控制不利修正降低1；不增加覆蓋範圍。 |
| 5 | 柔光維持：低照度或短暫遮蔽直接干擾覆體時，維持不利修正降低1；不穿透完整遮蔽物。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入技能複雜度與迴路負載。
