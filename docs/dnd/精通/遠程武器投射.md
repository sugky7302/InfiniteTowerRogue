# 遠程武器投射

遠程武器投射把[[武器技藝]]與[[投射]]整合成一次穩定的遠程武器射擊。本精通只壓縮武器核心與傳遞型態，不免費提供瞄準、增傷、彈藥、射程或目標辨識。

## 取得方式

角色需要武器技藝1級與投射1級，完成遠程武器持握、出手與路徑練習後，透過訓練、研究、實戰領悟或特殊事件取得。二知識精通不需要前置精通。

## 展開結構

```text
武器技藝（核心）
└─投射（型態）
```

技能必須指定由[[持握中]]確認的遠程戰具、彈藥、射程、武器係數、屬性係數及命中處理。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得印記時，以「你開始理解遠程戰具與投射路徑的穩定關係（1／4）」提示。

## 精通等級

> 遠程武器投射精通等級＝武器技藝與投射知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 出手校準：姿勢或一般風勢直接干擾投射路徑時，相關不利修正降低1；不增加射程或命中。 |
| 5 | 遠距讀線：在技能原有合法射程內，極端距離造成的投射不利修正降低1。不忽略遮蔽。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
