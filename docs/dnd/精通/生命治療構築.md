# 生命治療構築

生命治療構築把[[生命]]、[[鏈結]]與[[治療]]整合成向單一指定目標傳遞修復作用並恢復生命值的完整精通節點。

## 取得方式

角色需三項知識都達1級、已取得[[生命鏈結]]，並完成生命結構判讀、鏈結與治療結算練習，再透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。

## 展開結構

```text
生命（核心）
└─鏈結（型態）
  └─治療（效果）
```

本精通形成完整治療路徑。射程、施法時間、資源、基礎治療量、[[治療強度]]係數與失敗處理由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得印記時，以「你開始理解生命傳遞與治療結算的完整關係（1／6）」提示。

## 精通等級

> 生命治療構築精通等級＝生命、鏈結與治療知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 修復穩定：一般環境干擾直接妨礙修復結算時，相關不利修正降低1；不提高治療量。 |
| 6 | 精準修復：目標具有多處可修復損傷而造成判讀不利時，相關不利修正降低1；不移除疾病、狀態或結構缺損。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
