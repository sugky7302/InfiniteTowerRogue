# 光明移動解除

光明移動解除把[[光明]]、[[投射]]與[[移動限制解除]]整合成遠距解除可移動限制的固定結構。

## 取得方式

角色須使三項知識都達1級、已取得[[光明投射]]，並對多種可解除定身、減速與束縛完成辨識及解除練習，再經由研究、實戰領悟或導師傳授取得。

## 展開結構

```text
光明（核心）
└─投射（型態）
  └─移動限制解除（效果）
```

本精通只處理技能明列且可解除的移動限制。不能摧毀地形、忽略負重或解除其他狀態。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始整合光明傳遞與移動限制解除（1／6）」提示角色。

## 精通等級

> 光明移動解除精通等級＝光明、投射與移動限制解除知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 限制辨識：判斷一項效果是否具有移動限制標籤時，相關不利修正降低1；不改變其可解除性。 |
| 5 | 淨除校準：解除門檻直接來自相容能量強度時，相關不利修正降低1；不跳過驅散分類。 |
| 8 | 雙重解除：施展前可承受不利修正2。若成功，可在同一目標上額外處理一項合法移動限制候選。 |

技法不會讓不可解除狀態變得可解除。
