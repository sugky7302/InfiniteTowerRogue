# 淨魔構築

淨魔構築把[[魔法解析]]、[[投射]]、[[效果篩選]]與[[驅散]]整合成一個遠距選取並終止持續魔法效果的完整精通節點。

## 取得方式

角色需四項知識都達2級、已取得[[淨魔辨析]]，並完成合法候選辨識與驅散練習，再透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。

## 展開結構

```text
魔法解析（核心）
└─投射（型態）
  └─效果篩選（觸發）
    └─驅散（效果）
```

本精通形成完整驅散路徑。射程、目標關係、效果分類、候選上限、排序、資源與驅散權限仍由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 4 |
| 進入領悟池 | 8枚整合印記 |
| 自動領悟 | 16枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級4 |

第一次取得印記時，以「你開始理解解析、分類與終止魔法效果的完整關係（1／8）」提示。

## 精通等級

> 淨魔構築精通等級＝魔法解析、投射、效果篩選與驅散知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 4 | 穩定剝離：目標上的其他相容魔法效果直接干擾驅散時，相關不利修正降低1；不提高驅散上限。 |
| 7 | 精準終止：已按技能排序選定唯一候選時，終止該效果的檢定不利修正降低1；不處理不可驅散效果。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
