# 機動軌跡

機動軌跡把[[機動戰技]]與[[軌跡]]整合成一個精通節點，用於規劃主動身體位移路線。本精通尚未提供具體移動結果。

## 取得方式

角色需要機動戰技1級與軌跡1級，完成起點、方向、障礙與落點練習，再透過訓練、研究、實踐、戰鬥領悟、導師傳授或特殊事件取得。

## 展開結構

```text
機動戰技（核心）
└─軌跡（型態）
```

展開後有核心與型態，但必須再接[[躍擊]]、[[接敵]]或其他合法結果。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解身體發力與移動軌跡的固定關係（1／4）」提示；正式領悟後公開全部里程碑。

## 精通等級

> 機動軌跡精通等級＝機動戰技與軌跡知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 路線預整：狹窄空間造成的路徑控制不利修正降低1。不穿越障礙。 |
| 5 | 姿勢銜接：合法落點的普通地形高低差造成的著地不利修正降低1。不免疫墜落。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入負載。
