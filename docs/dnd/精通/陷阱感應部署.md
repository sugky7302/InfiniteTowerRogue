# 陷阱感應部署

陷阱感應部署把[[區域進入時]]加入[[陷阱範圍投射]]的固定結構，使遠距陷阱能在候選進入感應區時啟動。本精通尚未限定候選關係，也沒有載荷結果。

## 取得方式

角色需四項知識都達1級、已取得[[陷阱範圍投射]]，並完成進入事件與單次消耗測試，再透過訓練、研究、實踐、戰鬥領悟、導師傳授或特殊事件取得。

## 展開結構

```text
陷阱裝置（核心）
└─投射（型態）
  └─區域（型態）
    └─區域進入時（觸發）
```

展開後能監聽區域進入事件，但仍須指定候選資格並接上合法結果。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 4 |
| 進入領悟池 | 8枚整合印記 |
| 自動領悟 | 16枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級4 |

第一次取得整合印記時，以「你開始理解部署完成與區域進入事件的固定順序（1／8）」提示；正式領悟後公開全部里程碑。

## 精通等級

> 陷阱感應部署精通等級＝陷阱裝置、投射、區域與區域進入時知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 4 | 感應去噪：非生物環境擾動造成的誤觸發不利修正降低1。不提供敵我辨識。 |
| 8 | 單次鎖定：多名候選同時進入時，排序檢定獲得有利加成1；不增加觸發上限。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入負載。
