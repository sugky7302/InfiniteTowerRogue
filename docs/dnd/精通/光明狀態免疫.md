# 光明狀態免疫

光明狀態免疫把[[光明]]、[[投射]]與[[狀態免疫]]整合成遠距授予一項明確狀態免疫的固定結構。

## 取得方式

角色須使三項知識都達1級、已取得[[光明投射]]，並分別練習限定免疫分類、持續時間及解除方式，再經由研究、實戰領悟或導師傳授取得。

## 展開結構

```text
光明（核心）
└─投射（型態）
  └─狀態免疫（效果）
```

每個本精通節點只能由技能指定一種明確免疫分類。若要同時免疫定身與移動減速，必須在不同分支各放置一次並分別計算。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始整合光明傳遞與單類狀態免疫（1／6）」提示角色。

## 精通等級

> 光明狀態免疫精通等級＝光明、投射與狀態免疫知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 分類穩定：相近狀態名稱造成辨識混淆時，判定指定免疫分類的不利修正降低1；不擴張分類。 |
| 5 | 持續校準：外界干擾直接嘗試縮短本精通建立的免疫時，相關抵抗不利修正降低1；不延長原始時間。 |
| 8 | 預先拒絕：施展前可承受不利修正2。若成功，免疫建立同時可拒絕一項正在施加、但尚未成立的指定分類狀態。 |

技法不會解除施展前已存在的狀態，也不能指定「所有有害效果」等總類。
