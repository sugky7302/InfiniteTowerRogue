# 瀝青陷阱構築

瀝青陷阱構築把[[移動減速]]加入[[瀝青場域部署]]，封裝遠距部署、敵對感應、場域展開與區域減速的完整固定結構。本精通不能單獨配置或施展。

## 取得方式

角色需七項知識都達1級、已取得[[瀝青場域部署]]，並完成陷阱部署、首敵啟動、瀝青邊界與進出減速測試，再透過訓練、研究、實踐、戰鬥領悟、導師傳授或特殊事件取得。

## 展開結構

```text
陷阱裝置（核心）
└─投射（型態）
  └─區域（型態）
    └─區域進入時（觸發）
      └─敵對資格（觸發）
        └─場域（型態）
          └─移動減速（效果）
```

展開後形成完整區域減速路徑。射程、半徑、持續時間、減速倍率、同時上限與失效方式仍由技能根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 7 |
| 進入領悟池 | 14枚整合印記 |
| 自動領悟 | 28枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級7 |

第一次取得整合印記時，以「你開始理解瀝青陷阱從部署到區域減速的完整鏈條（1／14）」提示；正式領悟後公開全部里程碑。

## 精通等級

> 瀝青陷阱構築精通等級＝陷阱裝置、投射、區域、區域進入時、敵對資格、場域與移動減速知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 7 | 黏度校準：場域介質差異降低減速穩定性時，相關不利修正降低1；不提高減速倍率。 |
| 14 | 進出續效：同一敵人在1秒內離開又重入時，可沿用原效果實例的剩餘結算資料；不讓減速在區域外持續。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入負載。
