# 火焰範圍投射

火焰範圍投射是把[[火焰]]、[[投射]]與[[區域]]整合成一個精通節點的技巧，讓火焰抵達落點後向周圍展開。它可以支持直接範圍火焰傷害，但不會自行建立持續燃燒狀態。

## 取得方式

角色必須符合以下條件，再透過訓練、研究、實驗、實踐、戰鬥領悟、導師傳授或特殊事件取得：

- [[火焰]]、[[投射]]與[[區域]]都達1級。
- 已取得[[火焰投射]]或[[範圍投射]]其中一項。
- 完成火焰傳遞、落點與區域展開的整合練習。

兩項二知識精通都構成本精通的連續相符子樹，滿足任一項即可。符合條件本身不會自動取得本精通。

## 展開結構

```text
火焰（核心）
└─投射（型態）
  └─區域（型態）
```

技能根節點可以啟用[[火焰]]支持的直接火焰傷害，使本精通形成「核心→型態→合法結果」的完整作用路徑。傷害數值、作用區域、資源與性能代價仍須由技能記錄；若要建立燃燒狀態，必須在後方接上[[火之燃燒]]。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 3 |
| 進入領悟池 | 6枚整合印記 |
| 自動領悟 | 12枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級3 |

第一次取得整合印記時，以「你開始理解火焰、投射與區域之間的展開關係（1／6）」提示角色。達到最低門檻時，公開本精通名稱、展開結構與領悟檢定條件；正式領悟後，再公開全部里程碑與技法。

## 精通等級

> 火焰範圍投射精通等級＝火焰、投射與區域知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 定向展焰：建立作用區域時，可以指定區域內一個施術者可見的目標，使其不受本精通所傳遞的直接火焰內稟結果影響；不排除其他技能分支、環境火焰或後續燃燒。 |
| 5 | 焰心聚焦：可以指定一個占據區域中心點的目標，使其受到的本次直接火焰傷害增加2點。不增加燃燒週期傷害，中心沒有合法目標時不生效。 |
| 8 | 精準邊界：使用定向展焰時，可以指定至多兩個施術者可見的目標；總排除數量是兩個，不是額外增加兩個。 |

達到里程碑只會解鎖技法。技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入技能複雜度與迴路負載。
