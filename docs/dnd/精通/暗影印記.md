# 暗影印記

暗影印記把[[暗影]]核心與[[印記]]型態整合成一個精通節點，用於把暗影作用穩定依附在目標、物件或地點上。本精通缺少結果來源，不能單獨配置或施展。

## 取得方式

角色需要暗影1級與印記1級，並完成暗影依附與移除實驗，再透過訓練、研究、實戰領悟或特殊事件取得。二知識精通不需要前置精通。滿足知識條件不會自動取得。

## 展開結構

```text
暗影（核心）
└─印記（型態）
```

展開後尚未產生傷害、遮蔽或其他結果。放入技能時必須再接上適用效果，並由根節點記錄載體、可見程度與移除方式。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解暗影如何固定依附在指定載體（1／4）」提示。正式領悟後公開全部里程碑。

## 精通等級

> 暗影印記精通等級＝暗影與印記知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 隱晦印跡：觀察者辨識印記時，因低照度造成的有利條件降低1；不讓印記隱形。 |
| 5 | 穩定依附：載體受到非針對性擦碰或環境擾動時，印記維持不利修正降低1；不抵抗驅散。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入技能複雜度與迴路負載。
