# 生命鏈結

生命鏈結把[[生命]]核心與[[鏈結]]型態整合成向指定目標傳遞生命作用的固定操作。本精通本身不會恢復生命值。

## 取得方式

角色需要生命1級與鏈結1級，完成遠距生命訊號及修復作用傳遞練習後，透過訓練、研究、實戰領悟、導師傳授或特殊事件取得。二知識精通不需要前置精通。

## 展開結構

```text
生命（核心）
└─鏈結（型態）
```

技能仍須指定目標、距離、連線中斷與合法結果。恢復生命值必須另接[[治療]]。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得印記時，以「你開始理解生命作用與鏈結傳遞的穩定關係（1／4）」提示。

## 精通等級

> 生命鏈結精通等級＝生命與鏈結知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 生命校準：一般生命訊號雜訊直接干擾目標確認時，相關不利修正降低1；不繞過遮蔽或目標資格。 |
| 5 | 穩定連線：普通移動直接干擾既有鏈結時，相關不利修正降低1；不增加射程或阻止明確中斷。 |

技法必須附掛在本精通節點，並依[[精通#精通技法成本|精通技法成本]]計費。
