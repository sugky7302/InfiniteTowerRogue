# 持握武技

持握武技把[[持握中]]與[[武器技藝]]整合成穩定的戰具操作前置。本精通不是技能，必須放入具有技能根節點的設計稿。

## 取得方式

角色須使[[持握中]]與[[武器技藝]]都達1級，並以一件合法戰具完成持握、失去持握與重新控制的基礎練習，再透過訓練、實戰領悟或導師傳授取得。二知識精通不需要前置精通。

## 展開結構

```text
持握中（觸發）
└─武器技藝（核心）
```

本精通只確認戰具並啟用武器技藝核心。距離、型態、傷害、資源與結果仍須由技能其他節點及根節點記錄。

## 領悟條件

| 項目 | 條件 |
|---|---:|
| 展開節點數 | 2 |
| 進入領悟池 | 4枚整合印記 |
| 自動領悟 | 8枚整合印記 |
| 領悟檢定 | 智力或精神通用檢定，挑戰等級2 |

第一次取得整合印記時，以「你開始理解持握與戰具操作的穩定關係（1／4）」提示角色。

## 精通等級

> 持握武技精通等級＝持握中與武器技藝知識中的最低等級

## 精通里程碑與技法

| 精通等級 | 解鎖技法 |
|---:|---|
| 3 | 穩固握持：外力直接干擾持握時，抵抗該次繳械的不利修正降低1；不阻止已成功的繳械。 |
| 5 | 快速校正：更換為同類型且手數相同的戰具後，第一次相關技能檢定的器具不熟悉不利修正降低1。不免除更換時間。 |

技法必須附掛在本精通節點上，並依[[精通#精通技法成本|精通技法成本]]計入複雜度與迴路負載。
