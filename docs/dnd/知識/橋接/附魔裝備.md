# 附魔裝備

附魔裝備把物品的材料、合法裝備方式與可用事件結構連到魔法知識，使後續符文能由裝備保存、供能或觸發。

- 只負責連接裝備本體與魔法，不會免費提供屬性、傷害、持握、攻擊、格擋或技能。
- 技能必須另行加入[[符文刻印]]、觸發、效果與能量來源。
- 裝備載體不相容、結構損壞或刻印容量不足時，橋接失敗。
