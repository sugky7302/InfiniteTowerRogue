# 射線

讓核心力量沿直線瞬間或連續連接施術者與目標。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄射程、寬度、是否持續連接，以及被障礙物阻斷時的處理方式。
- 射線只決定直線傳遞方式，不會自行穿透、致盲或造成傷害。

## 知識修正值

本次實際執行路徑使用射線呈現、傳遞或接觸目標時，提供下列知識修正值：

| 知識等級 | 知識修正值 |
|---:|---:|
| 1～4 | +1 |
| 5～9 | +2 |
| 10以上 | +3 |
