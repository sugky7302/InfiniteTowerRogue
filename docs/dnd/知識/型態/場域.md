# 場域

讓核心力量充滿一個指定空間，使後續效果能以該空間為作用載體。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄形狀、大小、中心、邊界，以及場域是否跟隨目標移動。
- 場域不會自行持續、分辨敵我或附加環境效果。
