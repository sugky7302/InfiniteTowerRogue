# 覆體

讓核心力量貼合並包覆生物、物件或施術者的表面。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄覆蓋對象、覆蓋範圍、是否需要接觸，以及覆體脫離時的處理方式。
- 覆體不會自行提供防護、束縛、變形或持續效果。
