# 構造

讓核心力量呈現為具有明確幾何形狀的物體或地形。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄形狀、尺寸、位置、朝向與結構消失時的處理方式。
- 構造不會自行獲得硬度、承重、防護或傷害能力。
