# 軌跡

讓核心力量沿投射物經過的路線呈現，而不只作用於終點。

## 取得前置

[[投射]]1級。符合前置條件只代表可以開始理解。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄軌跡寬度、路線、有效區段與投射被攔截時的處理方式。
- 軌跡不會自行持續、造成傷害或免除路線上多目標的不利修正。

## 知識修正值

本次實際執行路徑使用軌跡呈現、傳遞或接觸目標時，提供下列知識修正值：

| 知識等級 | 知識修正值 |

| 5～9 | +2 |
| 10以上 | +3 |
