# 區域

讓力量不只作用於單一目標，而是覆蓋指定空間的型態知識。區域可以接在投射之後，使投射物抵達落點時向周圍展開。

## 基礎能力

- 建立技能時必須記錄區域的形狀、大小與中心點。
- 區域內所有符合條件的目標都會受到後續效果影響。
- 以區域為目標時，不因區域內的目標數量獲得額外目標的不利修正。
- 除非技能另有精通、修飾或選擇結構，區域效果不會自動分辨敵我。
