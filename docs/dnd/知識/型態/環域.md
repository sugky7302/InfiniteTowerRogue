# 環域

讓核心力量形成以生物、物件或位置為中心的環形作用空間。

## 取得前置

[[環繞]]1級、[[區域]]1級。符合前置條件只代表可以開始理解。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄中心、內外半徑、高度，以及環域是否跟隨中心移動。
- 環域不會自行持續、攔截或反覆影響同一目標。
