# 噴流

讓核心力量從一個起點朝指定方向連續噴出。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄起點、長度、寬度、方向與噴流中斷時的處理方式。
- 噴流不會自行推動、灼燒或覆蓋多個目標。這些結果由效果與其他節點決定。
