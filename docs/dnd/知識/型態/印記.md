# 印記

讓核心力量依附在生物、物件或地點上，成為後續節點可以指定的錨點。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄印記載體、可見程度、移除方式與載體失效時的處理方式。
- 印記不會自行持續或延遲發動。持續與發動條件仍須由修飾或觸發知識提供。
