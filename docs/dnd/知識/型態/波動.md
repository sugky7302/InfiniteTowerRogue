# 波動

讓核心力量從一個起點向外傳播，形成擴散中的波面。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄起點、傳播距離、方向、形狀與障礙物對波動的影響。
- 波動不會自行擊退、震盪或造成傷害。
