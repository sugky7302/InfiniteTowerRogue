# 環繞

讓核心力量沿生物、物件或位置周圍的軌道運行。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄環繞中心、軌道半徑、運行方向與軌道中斷時的處理方式。
- 環繞不會自行攔截、防護、追蹤或反覆命中。
