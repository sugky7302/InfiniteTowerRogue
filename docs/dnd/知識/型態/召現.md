# 召現

讓核心力量不經過中間路徑，直接在指定位置呈現。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄召現距離、合法位置、所需視線，以及位置被占用時的處理方式。
- 召現只建立呈現位置，不會自行傳送既有目標或延長力量的持續時間。
