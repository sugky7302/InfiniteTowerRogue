# 投影

讓核心力量在遠方位置呈現影像、輪廓或感知出口。

## 取得前置

[[射線]]1級。符合前置條件只代表可以開始理解。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄投影位置、方向、可呈現的資訊與投影受阻時的處理方式。
- 投影不會自行製造幻覺、共享感知或欺騙目標。
