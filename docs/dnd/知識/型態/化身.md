# 化身

讓核心力量形成具有完整外形、可以承載後續效果的身體或大型外殼。

## 取得前置

[[覆體]]1級、[[構造]]1級。符合前置條件只代表可以開始理解。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄外形、尺寸、依附對象、活動方式與結構破壞時的處理方式。
- 化身不會自行獲得生命、能力值、防護或自主行動。
