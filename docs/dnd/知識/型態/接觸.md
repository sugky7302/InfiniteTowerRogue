# 接觸

讓核心力量透過施術者或媒介與目標的直接接觸完成傳遞。

## 取得前置

無。這是一項基礎型態知識。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄接觸部位、可接觸的目標類型，以及接觸中斷時的處理方式。
- 接觸只負責建立傳遞關係，不會自行造成傷害、治療或其他效果。
