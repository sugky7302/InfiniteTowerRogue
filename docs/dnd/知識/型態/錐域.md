# 錐域

讓核心力量從起點向前展開為逐漸變寬的錐形空間。

## 取得前置

[[噴流]]1級、[[區域]]1級。符合前置條件只代表可以開始理解。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄起點、方向、長度、末端寬度與邊界判定。
- 錐域不會自行造成傷害、推動目標或分辨敵我。
