# 鏈射

讓投射抵達第一個目標後，依固定連接規則繼續傳往其他目標。

## 取得前置

[[投射]]1級、[[鏈結]]1級。符合前置條件只代表可以開始理解。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄跳躍次數、目標順序、每次跳躍距離與找不到下一目標時的處理方式。
- 鏈射不會自行選擇最有利目標，也不會免除多目標的不利修正。

## 知識修正值

本次實際執行路徑使用鏈射呈現、傳遞或接觸目標時，提供下列知識修正值：

| 知識等級 | 知識修正值 |
|---:|---:|
| 1～4 | +1 |
| 5～9 | +2 |
| 10以上 | +3 |
