# 投射

讓力量、物體或效果離開使用者，沿指定方向抵達遠方目標或落點的型態知識。

## 基準性能

- 基準射程：10碼。
- 基準投射速度：20碼／秒。
- 射程級距、飛行時間與命中時間依[[時間與距離]]計算。

## 基礎能力

- 可以把前方核心轉化為遠程投射物。
- 建立技能時必須記錄有效距離、射程級距、投射速度、飛行方式，以及投射物被阻擋時的處理方式。
- 投射只負責傳遞，不會自行造成傷害。
