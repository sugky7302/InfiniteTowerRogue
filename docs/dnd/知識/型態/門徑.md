# 門徑

讓核心力量在兩個位置之間形成可供後續效果通過的入口。

## 取得前置

[[召現]]1級、[[空間]]1級。符合前置條件只代表可以開始理解。角色仍須透過碎片、訓練、研究、觀察或實踐形成此知識。

## 基礎能力

- 可以接在核心知識之後，作為完整作用路徑的型態節點。
- 建立技能時必須記錄入口與出口的位置、方向、尺寸、通行限制及其中一端失效時的處理方式。
- 門徑不會自行傳送目標。是否移動、允許通行或造成其他結果仍由效果節點決定。
