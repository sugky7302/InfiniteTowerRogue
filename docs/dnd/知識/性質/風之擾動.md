# 風之擾動

風之擾動描述氣流因速度、方向、邊界或溫度差異產生不規則變化的特徵。

- 擾動可能形成渦流、亂流、抖動與不穩定壓力。
- 本性質不會自動干擾施法、命中或飛行。那些結果必須由效果與檢定規則提供。
- 開闊、平滑且穩定的流場可以降低擾動。
