# 暗影之延展

暗影之延展描述陰影尺寸與方向隨光源、遮光物和受光表面相對位置改變的特徵。

- 延展必須符合投影幾何，不代表陰影能自行擴大作用範圍。
- 主動改變暗影覆蓋區域仍需要光源、遮光物或空間效果。
