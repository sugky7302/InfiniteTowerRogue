# 火之蔓延

火之蔓延描述燃燒反應能沿相連燃料、熱傳路徑或可燃混合物擴張的條件。

- 蔓延速度取決於燃料排列、可燃性、供氧、熱量傳遞與環境流動。
- 本性質只說明蔓延是否可能，不會自行新增燃燒目標。
- 要讓技能主動擴散燃燒，仍須使用觸發、範圍或目標選取規則。
