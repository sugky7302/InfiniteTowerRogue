# 水之透光性

水之透光性描述光通過水時被傳遞、吸收、散射與改變方向的材料特徵。

- 透明度會受深度、懸浮物、波長、氣泡與表面狀態影響。
- 透光性不會自行照明、成像、隱形或使光聚焦。
- 折射、成像與光譜操作仍需要相應知識。
