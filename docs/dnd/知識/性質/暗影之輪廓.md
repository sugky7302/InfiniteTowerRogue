# 暗影之輪廓

暗影之輪廓描述遮光物外形如何在受光表面形成可辨識邊界。

- 輪廓清晰度取決於光源大小、距離、表面與遮光物形狀。
- 輪廓只能提供外形線索，不保證辨識身分或內部結構。
