# 地之承載

地之承載描述土石構造在不失穩或破壞的情況下支撐物體、力量或生物的能力。

- 承載上限取決於材料強度、結構、接觸面與受力方式。
- 本性質不會免費創造平台、提高防禦或固定承載物。
- 超過承載能力時，依實際結構產生下陷、斷裂、傾倒或其他後果。
