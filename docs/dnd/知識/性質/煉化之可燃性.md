# 煉化之可燃性

煉化之可燃性描述材料在取得足夠能量並接觸適當反應條件時，能否維持放熱氧化反應。

- 可燃性是材料性質，不代表目標已經燃燒。
- 點燃溫度、燃料、氧化條件與材料結構都會影響是否成立。
- 技能仍須使用[[火之燃燒]]等效果知識，才能讓目標進入燃燒狀態。
