# 地之顆粒性

地之顆粒性描述土、砂或碎石由許多可分離顆粒組成，能堆積、滑動與填入空隙的材料特徵。

- 顆粒尺寸、形狀、摩擦與含水量會改變其流動及堆積方式。
- 本性質不會自動粉碎完整岩石。把固體轉成顆粒仍需要效果知識。
- 顆粒也不等同液體，其流動會受到摩擦、壓實與崩落角限制。
