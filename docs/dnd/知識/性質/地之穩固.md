# 地之穩固

地之穩固描述土石構造在重力、震動與外力下維持位置及結構的能力。

- 穩固性來自材料結構、密度、支撐面與受力方向。
- 本性質只描述構造能否保持穩定，不會主動加固、固定或防護目標。
- 要提高既有構造的穩固程度，仍須使用適用的效果知識。
