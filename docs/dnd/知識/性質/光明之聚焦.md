# 光明之聚焦

光明之聚焦描述多條光路在特定位置或方向集中，使局部光強提高的條件。

- 焦點由光路、介質、曲率與相對位置決定。
- 聚焦只描述能量集中，不會自動造成傷害、點燃或命中。
