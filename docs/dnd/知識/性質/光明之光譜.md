# 光明之光譜

光明之光譜描述光由不同波長或頻率成分組成，以及各成分能被分辨、吸收或傳遞的特徵。

- 光譜成分會影響顏色、材料吸收、感知與能量作用。
- 本性質不會自行分光、改色、淨化或造成傷害。
