# 風之承載

風之承載描述氣流以動量與阻力攜帶微粒、氣味、聲波或物體移動的能力。

- 可承載的質量取決於氣體密度、流速、迎風面積與目標重量。
- 聲音與氣味是由介質傳遞，不代表氣流能精確保存或理解資訊。
- 本性質不會免費搬運目標。主動移動仍需要效果知識。
