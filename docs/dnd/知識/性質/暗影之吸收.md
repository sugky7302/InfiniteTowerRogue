# 暗影之吸收

暗影之吸收描述材料或魔法結構吸收抵達其上的光能，使反射與透射光減少的特徵。

- 吸收比例取決於波長、材料、厚度與入射角。
- 被吸收的能量必須轉成熱、儲能或其他形式，不會憑空消失。
- 本性質不會自行遮蔽、侵蝕或造成傷害。
