# 水之濕潤

水之濕潤描述液態水與材料表面接觸後附著、鋪展或進入表層孔隙的能力。

- 濕潤程度取決於表面結構、材料親水性、液體張力與接觸時間。
- 濕潤是接觸性質，不自動造成溶解、腐蝕、減速或其他狀態。
- 防水、疏水或封閉表面可以降低或阻止濕潤。
