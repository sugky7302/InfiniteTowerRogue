# 水之容形

水之容形描述液態水能配合容器、重力與邊界改變外形，同時維持連續介質的特徵。

- 水的外形由容器、自由表面、壓力與重力共同決定。
- 容形不代表水能自行懸浮或維持不受支撐的固定造型。
- 要讓水形成違反自然邊界的形狀，仍需持續施力或構造效果。
