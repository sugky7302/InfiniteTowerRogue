# 風之稀薄

風之稀薄描述單位空間內氣體質量與壓力偏低的狀態。

- 稀薄程度會影響呼吸、聲音傳播、浮力、阻力與燃燒供氧。
- 稀薄是氣體狀態，不會自行造成窒息、沉默或熄火。
- 主動降低氣體密度需要移除氣體、擴大容積或降低壓力的效果。
