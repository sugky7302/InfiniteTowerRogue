# 晶體

晶體是成分依規則排列形成固定結構的材料核心。

- 晶格、缺陷、成分與切面決定硬度、斷裂、透光與儲能表現。
- 不免費折射、儲能、防護或產生寶石。
- 晶體生長與改造仍需材料、能量及相應效果。
