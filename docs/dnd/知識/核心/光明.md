# 光明

光明是產生、引導或調整可見輻射的魔法核心，主要建立在能量與感知形成的[[光]]法則上。

## 基礎能力

- 提供照明、反射、折射、成像與光譜技能的核心來源。
- 不免費顯形、淨化、致盲、造成傷害或揭露真相。
- 觀察結果仍受感官閾值、遮蔽、距離與介質影響。

## 研究方式

角色須先理解能量放射與感知閾值，再透過光源、透鏡、色彩或成像實驗形成此核心。
