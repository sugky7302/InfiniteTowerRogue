# 武器技藝

武器技藝是使用持握戰具完成攻擊、格擋與操控動作的武技核心。

## 基礎能力

- 技能必須指定一件由[[持握中]]確認的戰具，並讀取其類型、所需手數、基礎傷害、傷害類型與適用屬性。
- 可以透過[[接觸]]、[[投射]]或其他相容型態，支持戰具明載的切割、穿刺或衝擊傷害。
- 技能根節點必須記錄武器係數、傷害事件、作用時點與性能代價。
- 盾牌只有在裝備資料明載可用於衝擊時，才能作為攻擊戰具。
- 多武器攻擊必須為每件戰具建立獨立路徑，分別命中與結算。
- 不免費提供命中、增傷、額外攻擊、位移、怒氣、連擊點或魔法效果。
