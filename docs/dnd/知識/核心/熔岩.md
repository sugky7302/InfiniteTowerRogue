# 熔岩

熔岩是岩石在高溫下熔融並流動的材料核心。

- 溫度、成分與黏度決定流速、冷卻與凝固結果。
- 不免費燃燒、造成傷害、封路或持續存在。
- 熱量不足時會冷卻並重新形成固體結構。
