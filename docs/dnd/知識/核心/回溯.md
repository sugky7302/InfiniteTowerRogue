# 回溯

回溯是根據先前留下的狀態記錄，重建過程或還原可逆狀態的認知核心。逆流只是比喻，並非讓時間倒轉。

## 可表達的現象

- 比較多份記錄，重演已發生的變化。
- 對可逆系統套用已知舊狀態。實際復原仍須相應效果與材料、能量。

## 自然限制

- 沒有可靠記錄便不能知道舊狀態。資訊缺口只能推測。
- 無法取消已發生事件、復活死者或改寫其他人的歷史。
