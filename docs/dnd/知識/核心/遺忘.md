# 遺忘

遺忘是記憶內容因衰退、干擾或提取失敗而變得難以取用的心智核心，並非暗影侵蝕時間。

## 可表達的現象

- 描述記憶痕跡衰退、內容互相干擾或線索失效。
- 為降低回想能力的效果提供心智機制。

## 自然限制

- 遺忘不會抹除外部紀錄或改寫已發生的歷史。
- 主動影響他人記憶必須有心智效果、抵抗與恢復條件，核心本身不會免費刪除記憶。
