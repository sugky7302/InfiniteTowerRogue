# 停滯

停滯是在有界區域內把指定過程的變化速率降到極低，藉此保存狀態的構域核心。

## 可表達的現象

- 降低移動、反應、代謝或材料變化的速率。
- 讓區域內外使用同一參照時鐘，比較實際延緩程度。

## 自然限制

- 必須逐項指定受影響過程，並承擔維持邊界與抑制變化的成本。
- 不會真正停止時間。外界作用、能量交換與因果事件仍需按技能規則處理。
