# 感官借用

感官借用把另一個心智載體實際收到的指定感官訊號，作為施術者可接收的心智來源。

## 基礎能力

- 技能必須指定訊號來源、接收者、感官種類及[[鏈結]]與[[投影]]路徑。
- 只轉送來源當下可取得的訊號；失明、遮蔽、幻覺與雜訊一併保留。
- 不讀取記憶、不控制來源身體，也不提供來源感官範圍外的資訊。
- 非自願來源必須連接[[同意或抵抗]]，持續連結必須連接[[連結中斷]]。
