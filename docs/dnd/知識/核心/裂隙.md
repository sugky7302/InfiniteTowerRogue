# 裂隙

裂隙是在既有空間邊界上建立狹窄且不穩定連接的核心。能量輸入用於建立與維持連接，不代表火焰真的把空間燒裂。

## 可表達的現象

- 建立短暫狹縫，讓另有指定的物質、能量或訊號穿過。
- 入口位置、出口位置、口徑、通過條件與崩解方式都必須明確定義。

## 自然限制

- 裂隙本身不造成切割或傷害。要傷害目標必須加入相應效果。
- 未建立可驗證出口時，裂隙不能作為任意放逐或刪除物質的手段。
