# 根鬚

根鬚是讓既有植物組織快速生長成可承力纖維、根系或藤蔓的生命核心。

## 基礎能力

- 可以透過[[生長]]增加既有植物組織，再以[[構造]]形成可纏繞或支撐的根鬚。
- 根鬚形成實體接觸後，可以支持擠壓、勒束或穿刺造成的物理傷害。技能根節點必須明確記錄傷害類型、數值、週期與材料強度。
- 可以連接[[定身]]限制目標位移，但不免費禁止攻擊、施法或其他行動。
- 必須有種子、根系、活體植物或技能明確支付的生物質來源。沒有物質、養分或能量時無法憑空形成。
- 不免費提供毒素、感知、追蹤、永久植物或無視地形的生長。
