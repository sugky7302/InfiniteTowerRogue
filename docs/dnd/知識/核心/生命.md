# 生命

生命是操控既有生命活動、代謝循環與可修復組織的魔法核心。它提供生命技能所需的作用來源，但不代表施術者能任意創造生命。

## 基礎能力

- 可以作為生長、組織修復與生命狀態調整技能的核心。
- 可以連接[[接觸]]、[[投射]]、[[鏈結]]、[[區域]]或其他相容型態，再由[[治療]]、[[生長]]等效果提供合法結果。
- 作用於活體時，目標必須具有生命活動及可修復結構。
- 作用於不死生物時，技能必須使用[[不死資格]]確認其維持生命值的結構能接受該效果。
- 不免費提供治療、生長、復活、解除疾病、創造生物或支配生命。

## 研究方式

角色須先理解代謝平衡、代謝速率與組織結構，再透過醫療、培育、生理觀察、師承或施法實踐形成此核心。
