# 預兆

預兆是從目前可觀測徵象與既有規律，推估後續事件機率的認知核心。

## 可表達的現象

- 辨認風險訊號、估計趨勢並提供示警。
- 根據模型與新證據持續修正預測。

## 自然限制

- 預兆是有誤差的推論，不是照見已確定的未來。
- 資訊不足、隨機事件與他人選擇都可能使結果改變。
