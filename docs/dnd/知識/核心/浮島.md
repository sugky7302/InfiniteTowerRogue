# 浮島

浮島是以持續力場或其他支撐機制維持大型土石離地的構造核心。

- 必須平衡質量、重力、支撐力、姿態與位置。
- 不免費懸浮、移動、造台或改變地形。
- 支撐中斷時，構造依質量、慣性與環境正常墜落。
