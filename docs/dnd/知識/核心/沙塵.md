# 沙塵

沙塵是氣流攜帶土砂或細碎顆粒移動的混合介質核心。

- 顆粒大小、風速與密度決定沉降、能見度與撞擊能力。
- 不免費遮蔽、侵蝕、干擾或造成傷害。
- 氣流不足時顆粒會依質量與環境逐步沉降。
