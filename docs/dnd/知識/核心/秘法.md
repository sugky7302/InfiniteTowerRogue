# 秘法

秘法是把可用魔力組織成可傳遞、可釋放之純魔法能量的核心。

- 可以透過能量衝擊或結構擾動支持直接秘法傷害。技能根節點必須記錄數值、作用時點與代價。
- 可以連接[[投射]]、[[射線]]、[[區域]]、[[印記]]或其他相容型態。
- 要建立週期秘法傷害，必須使用[[秘法灼蝕]]或其他明載持續機制。
- 不免費提供驅散、法力恢復、時間操作、必中或無視防護。
