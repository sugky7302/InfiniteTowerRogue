# 化石

化石是生物遺跡經沉積、礦物置換與長期環境作用保存形態或痕跡的材料核心。

- 形成需要原始遺跡、沉積條件、礦物來源與足夠變遷過程。
- 不免費回溯記憶、復活生命、強化結構或立即製造化石。
- 化石保存的是有限形態與材料資訊，不等同完整生命狀態。
