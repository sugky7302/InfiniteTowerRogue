# 霜奪

霜奪是冷酷凜冬建立的第二個低溫靈體來源，固定在施放者右側4碼並隨施放者移動。

- 只在對應冷酷凜冬實例存在時可用。來源與施放者失去同一空間連接時失效。
- 可以為[[冰凍之魂]]分支提供低溫能量與爆炸起點。
- 不自主選擇技能、支付資源或產生傷害。
