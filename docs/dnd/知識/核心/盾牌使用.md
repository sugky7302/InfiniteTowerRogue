# 盾牌使用

盾牌使用是讀取持握盾牌的覆蓋、格擋、重量與姿勢資料，並用於防禦行動的武技核心。

## 基礎能力

- 必須指定一面由[[裝備中]]與[[持握中]]確認的盾牌。
- 可以讀取盾牌的手數、覆蓋範圍、格擋能力、重量與裝備限制。
- 可以連接[[格擋時]]、[[接敵]]與[[傷害減免]]，建立主動防禦或護衛技能。
- 盾牌攻擊仍須使用[[武器技藝]]，並要求盾牌資料明載衝擊致傷機制。
- 不會自動格擋、免費增加護甲、保護相鄰同伴或免除持握需求。

## 研究方式

先形成[[武器技藝]]，再於軍營、守衛隊、武館或護衛教官處使用練習盾完成姿勢、受力與格擋訓練。

## 知識修正值

盾牌使用只在實際利用盾牌覆蓋、格擋、護衛位置或承受衝擊的路徑中提供知識修正值。
