# 環境偽裝

環境偽裝以背景觀測資料調整承受者的輪廓、色彩與可選訊號，使其較難被辨識。

## 基礎能力

- 技能必須指定取樣環境、更新頻率及實際改變的視覺、聲音或氣味訊號。
- 可以支撐[[潛行]]，但核心本身不建立潛行狀態。
- 背景改變、離開取樣環境或訊號來源中斷時，偽裝條件失效。
- 不提供隱形、穿透、消音、無味或免疫追蹤。未明列的感官仍正常偵測。
