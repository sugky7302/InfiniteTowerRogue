# 戰吼技藝

戰吼是以受控聲音、節奏與意志表達向可聽見對象傳遞士氣訊號的武技核心。

- 可以透過[[波動]]或[[區域]]傳播，並以[[可聽見]]檢查目標是否能接收。
- 可以連接[[增益]]、[[恐懼]]或其他明確效果，但本核心本身不免費鼓舞、恐嚇或修改數值。
- 真空、完全隔音、聲音未抵達或目標無法感知時，聲音路徑失敗。
- 技能必須記錄音量、距離、合法目標、持續時間及是否屬於魔法效果。
