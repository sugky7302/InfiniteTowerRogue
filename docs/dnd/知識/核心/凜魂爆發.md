# 凜魂爆發

凜魂爆發把低溫能量保存在成對靈體來源中，並在指定持續效果結束時釋放冰晶與熱量抽離爆發。

- 必須指定一個受監聽效果實例，以及兩個能提供低溫能量的合法[[外部施放來源]]。
- 可以透過急速降溫、冰晶切割與凍結介質衝擊支持冰霜傷害。
- 技能必須記錄每個來源的區域、傷害基礎值、屬性係數、結束原因及失效處理。
- 不免費建立命中紀錄、遠距來源、傷害倍率、冰凍狀態或來源復活。
