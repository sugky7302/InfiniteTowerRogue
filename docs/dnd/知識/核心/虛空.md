# 虛空

虛空是與周圍隔離、且可測內容密度很低的空間區域核心。它描述低內容環境，不等於抹除存在或失去方向。

## 可表達的現象

- 建立低物質、低訊號或低能量交換的封閉區域。
- 區域中缺少哪一類內容，必須由移除、隔離或轉移效果明確指出。

## 自然限制

- 內容不會無故消失，必須被排出、轉移、吸收或隔離，並遵守守恆與因果。
- 虛空本身不造成窒息、傷害、放逐或感知剝奪。
