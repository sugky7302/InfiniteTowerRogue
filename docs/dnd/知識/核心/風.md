# 風

風是操控氣體流動、壓力與動量傳遞的魔法核心，不是根本元素。

## 基礎能力

- 提供空氣或其他氣體作為介質的流動與施力來源。
- 不免費推動、切割、壓縮、傳聲或形成範圍。
- 真空、密閉空間與介質差異會影響技能是否成立。

## 研究方式

角色須先理解擴散、壓力與傳播，再透過氣流、風洞、呼吸或聲學實驗形成此核心。
