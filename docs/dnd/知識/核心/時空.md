# 時空

時空是以「位置加時刻」描述事件，並比較事件之間運動與因果關係的核心。

## 可表達的現象

- 記錄物體在不同時刻的位置，建立軌跡、速度與同步參照。
- 為延遲執行、狀態記錄或遠距協調提供事件座標。

## 自然限制

- 記錄過去不等於回到過去。預測軌跡也不等於確定未來。
- 跨時傳送、因果逆轉或區域保存都需要獨立效果與足夠資訊，不能由時空核心免費取得。
