# 瞬息

瞬息是把一個過程壓縮到極短可量測時間內完成的運動核心。

## 可表達的現象

- 定義短脈衝、快速反應或高頻變化的時間尺度。
- 比較執行時間、反應窗口與外界時鐘。

## 自然限制

- 時間縮短通常提高功率、精度與承載需求，不能跳過中間因果。
- 瞬息不等於瞬間移動、停止時間或無視冷卻。
