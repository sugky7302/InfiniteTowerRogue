# 時間

時間是研究狀態先後、延續、速率與歷史記錄的跨法則核心，不是第八項根本法則。

## 基礎能力

- 提供延遲、同步、加速、回溯與預見研究的共同核心。
- 不免費改變施法時間、取得未來資訊、回復過去狀態或改寫因果。
- 每次時間干涉都必須指定參照系、作用對象、幅度、持續時間與代價。
- 讓事件「從未發生」或轉移結果時，還涉及[[因果律]]。

## 研究方式

角色須理解連續變化、運動、位置與記憶，並透過週期觀測、歷史紀錄或相對運動實驗形成此核心。
