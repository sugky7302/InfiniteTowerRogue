# 結界

結界是以明確邊界與錨點維持一個受控區域的構域核心。地之穩固提供的是結構參照，不會讓區域免費獲得防護力。

## 可表達的現象

- 劃定內外、固定作用範圍，並讓後續效果只在邊界內執行。
- 邊界的強度、阻擋對象、持續時間與破壞條件，必須由效果、修飾或觸發節點另行定義。

## 自然限制

- 沒有錨點或邊界便不能形成結界。
- 結界不是護盾。若未加入阻擋或吸收效果，穿越邊界不會自動受阻。
