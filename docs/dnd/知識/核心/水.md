# 水

水是操控液態水及其流動行為的魔法核心，不是根本元素。

## 基礎能力

- 提供水作為介質時的凝聚、流動與滲透來源。
- 不免費創造水、減速、沖擊、溶解或治療。
- 相變、溫度與蒸發等現象還需要能量相關知識。

## 研究方式

角色須先理解連續、黏度與滲透，再透過水流、容器、壓力或混合實驗形成此核心。
