# 冰霜

冰霜是移除熱量、維持低溫並控制水分凝結或凍結的魔法核心。

- 可以透過低溫組織損傷、冰晶切割或冰塊衝擊支持冰霜傷害。技能根節點必須明載實際機制、數值與作用時點。
- 可以連接[[投射]]、[[覆體]]、[[區域]]或其他相容型態。
- 不免費提供[[移動減速]]、[[昏迷]]、[[癱瘓]]、凍結目標或傷害免疫。
- 直接作用於活體時，過度降溫仍可能造成自身或目標傷害；防護技能必須記錄安全機制及代價。
