# 魔法解析

魔法解析是辨識持續魔法效果的來源、受益方向、標籤、驅散類型、強度與特殊保護的魔法核心。

- 可以透過[[區域]]掃描候選，再以[[效果篩選]]建立有限且可排序的目標集合。
- 可以連接[[驅散]]嘗試終止相容效果。
- 特殊驅散必須由技能根節點明載權限並支付較高門檻。不可驅散效果仍不能處理。
- 不免費揭露未知施術者、讀取心智、解除效果或繞過遮蔽與感知限制。
