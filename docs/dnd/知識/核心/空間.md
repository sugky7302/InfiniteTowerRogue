# 空間

空間是操作位置、距離、容積、邊界與連接的魔法核心。

## 基礎能力

- 提供位移、收納、伸縮、隔離與通道技能的核心來源。
- 不免費傳送、無限延伸射程、擴大容積或穿過封閉邊界。
- 空間改變必須指定起點、終點、距離、邊界、目標與代價。

## 研究方式

角色須先理解位置、距離與邊界，再透過測量、容器、通道或位移實驗形成此核心。
