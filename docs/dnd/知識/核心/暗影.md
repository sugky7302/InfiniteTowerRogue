# 暗影

暗影是操控光能不足、吸收、遮蔽與低可見度現象的魔法核心，不是與光對立的根本元素。

## 基礎能力

- 提供遮光、消光、輪廓隱藏與暗影投射的核心來源。
- 不免費造成傷害、侵蝕心智、隱形或產生實體。
- 若暗影要形成可施力的實體，還需要形體或能量構造知識。

## 研究方式

角色須先掌握光的傳遞與感知閾值，再透過遮光材料、低照度觀測或能量吸收實驗形成此核心。
