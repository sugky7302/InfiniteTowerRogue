# 魔力注入

魔力注入是把外部可用魔力送入目標施法迴路，暫時承擔指定資源成本的魔法核心。

- 可以透過[[投射]]或[[鏈結]]傳遞，再由[[法力消耗豁免]]建立明確權限。
- 技能必須指定目標、持續時間、可豁免資源、適用技能與能量代價。
- 不免費恢復已消耗法力、不免除其他資源、施法時間、檢定或材料。
- 注入來源中斷或效果到期後，只影響之後開始支付的技能。
