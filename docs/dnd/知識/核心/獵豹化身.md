# 獵豹化身

獵豹化身提供四足獵豹身體的形態資料與機能來源。

## 基礎能力

- 目標形態為中型四足獵豹，具有四肢、尾部、獸口、正常獸類視聽嗅覺與相應碰撞範圍。
- 保留身分、意識、記憶、生命值比例與已支付資源。體積、肢體、感官、移動方式及可用技能依形態重算。
- 裝備預設收納停用。明列可隨形態調整的裝備才能保留作用。
- 本核心不免費提供速度增益、變形免疫、解除控制、墜落減傷或攻擊傷害。
