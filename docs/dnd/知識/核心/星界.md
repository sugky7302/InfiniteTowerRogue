# 星界

星界是以遠方光訊號建立天體位置、距離與方向模型的觀測核心，不預設存在另一個可進入的位面。

## 可表達的現象

- 依光線、週期與相對位置進行導航或遠距天文觀測。
- 把觀測結果轉成位置參照，供其他空間技能使用。

## 自然限制

- 只能取得實際抵達觀測者的訊號。遮蔽、延遲與解析度都會造成誤差。
- 星界不會免費提供即時遠距視野、傳送或跨位面能力。
