# 加速

加速是提高指定過程變化速率的核心。它必須指出被加速的過程以及驅動該過程所需的能量。

## 可表達的現象

- 提高移動、反應、燃燒、代謝或其他已定義過程的速率。
- 以共同時鐘比較加速前後的單位時間變化量。

## 自然限制

- 不會加快一切，也不會免費增加行動次數。每個受影響過程都要明列。
- 輸入能量、材料供給、散熱及生理承受能力仍限制最大速率。
