# 年輪

年輪是從材料逐期累積的實體差異，推定生長順序與環境變化的觀測核心。

## 可表達的現象

- 讀取層紋、沉積、磨耗或其他週期痕跡，估算相對年代。
- 將物理記錄整理成可比較的時間序列。

## 自然限制

- 只能讀取實際保存的痕跡。缺失、擾動與生長速率差異都會造成誤差。
- 年輪不保存完整歷史，也不會因年代久遠而免費累積力量。
