# 機動戰技

機動戰技是以身體協調、加速與路徑控制完成突進、衝鋒、躍擊或翻滾的武技核心。

## 基礎能力

- 技能必須記錄起點、終點、速度、路徑、距離限制與阻擋條件。
- 可以連接[[軌跡]]與[[接敵]]，把使用者移動到合法近戰位置。
- 路徑被阻擋、終點不可站立或使用者無法主動移動時，位移失敗。
- 本核心只提供主動身體移動，不免費穿越障礙、造成傷害、免疫控制或產生戰鬥資源。
- 若位移後還要攻擊，必須另外使用[[武器技藝]]或其他合法致傷核心。
