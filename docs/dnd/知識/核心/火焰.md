# 火焰

火焰是控制高溫能量、發光與持續氧化反應的魔法核心。它是能量法則的具體應用，不再視為根本元素。

## 基礎能力

- 可以作為火焰相關技能的核心。
- 可以透過高溫與能量傳遞支持直接火焰傷害。技能根節點必須明確啟用並記錄傷害數值、作用時點與性能代價。
- 只提供維持與操控火焰反應的技術來源，不會讓每項火焰技能自動造成傷害，也不免費提供燃燒、投射、範圍或持續時間。
- 要使目標燃燒，仍須使用[[火之燃燒]]效果，並檢查目標是否符合[[煉化之可燃性]]。
- 若技能要使用能量法則里程碑，[[能量法則]]節點必須實際出現在技能路徑中。

## 研究方式

角色須先理解能量的溫度、傳遞與放射，再透過燃燒觀察、熱力實驗、師承或施法實踐形成此核心。
