# 泥

泥是水進入土壤顆粒後形成的可塑混合介質核心。

- 含水量、顆粒尺寸與黏度決定流動、塑形及承載能力。
- 不免費提供困縛、減速、傷害或永久構造。
- 乾燥、排水、凍結或加入材料會改變泥的性質。
