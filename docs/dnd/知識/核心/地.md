# 地

地是操控土壤、岩石與礦物形體的魔法核心，不是根本元素。

## 基礎能力

- 提供土石材料的辨識與操控來源。
- 不免費創造土石、造成傷害、壓制、固結或改變地形。
- 實際結果仍須由型態、效果及材料性質完成。
- 使用法則權能時，對應法則節點必須實際進入技能路徑。

## 研究方式

角色須先理解質量、結構與密度，再透過土壤、岩石、礦物或建築實驗形成此核心。
