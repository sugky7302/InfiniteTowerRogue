# 陷阱裝置

陷阱裝置是把感應、啟動、載荷與失效條件封裝在可部署實體中的武技核心。

- 技能必須記錄部署完成時點、感應區、候選資格、啟動上限、存續時間、可否被破壞及失效方式。
- 可以透過[[投射]]部署，再以[[區域]]建立感應範圍，並由[[區域進入時]]啟動載荷。
- 單次陷阱在首次成功啟動後停止偵測並消耗。同時進入時依技能記錄的穩定排序選一名。
- 本核心不免費提供低溫、傷害、[[癱瘓]]、敵我辨識或無法拆除的隱藏。
