# 騎乘

騎乘是讓騎手在合格坐騎背上維持平衡、傳達方向並使用坐騎移動資料的武技核心。

## 基礎能力

- 必須指定一匹願意受控或已受訓的坐騎，以及合法的騎乘位置。
- 可以讀取坐騎的體型、負重、移動速度、可通行地形與轉向限制。
- 騎手與坐騎仍是兩個獨立個體，各自承受傷害、狀態與行動限制。
- 坐騎失去立足點、拒絕指令或騎手無法維持姿勢時，必須中止騎乘移動或進行相應檢定。
- 不會自動授予坐騎、馴服野獸、共享技能、免除墜落，也不讓坐騎免費攻擊。

## 研究方式

可在馬廄、牧場、驛站、軍隊騎兵營或旅行導師處直接研究。不要求其他完整知識，但需要合格坐騎與安全場地實習。

## 知識修正值

騎乘只在實際控制坐騎移動、轉向、越障、維持姿勢或處理坐騎失控的路徑中提供知識修正值。
