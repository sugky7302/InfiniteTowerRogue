# 腐土

腐土是有機物在水分、微生物與化學反應下分解並混入土壤的材料核心。

- 分解速度取決於溫度、水分、供氧、成分與生物活動。
- 暗影不是腐敗的必要原因。本核心不免費削弱生命、腐蝕或造成傷害。
- 產物與肥力必須依實際材料及反應判定。
