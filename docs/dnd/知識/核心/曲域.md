# 曲域

曲域是讓一段空間的距離或方向連續變化的核心。流體只是理解連續變形的模型，水本身不會彎曲空間。

## 可表達的現象

- 讓路徑逐步偏轉，或使同一路徑的有效距離伸長、縮短。
- 變形幅度、範圍與持續時間必須由修飾節點量化。

## 自然限制

- 曲域必須保持可追蹤的連續映射。若要直接連接兩地，應改用[[通道]]或[[空間之折疊]]。
- 不會免費使命中失敗、攻擊偏移或目標位移。
