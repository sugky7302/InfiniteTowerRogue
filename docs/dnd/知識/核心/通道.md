# 通道

通道是在兩個已知位置之間建立有邊界、可通行連接的構域核心。它描述空間拓撲，不以風作為必要成分。

## 可表達的現象

- 指定入口、出口及可通過內容，建立受控傳輸路徑。
- 可承載物質、能量或訊號，但每一類都須由技能明確授權。

## 自然限制

- 兩端必須能定位。距離、遮蔽與跨區域會提高建立及維持成本。
- 通道不會免費傳送、加速或建立遠距感知，必須加入對應效果。
