# 傷害減免

傷害減免修改承受者的一個或多個傷害事件，按技能記錄的倍率降低最終承受傷害。

- 技能必須指定傷害範圍、倍率、持續時間、疊加群組及套用順序。
- 「所有傷害降低30%」記為承受倍率0.7，對每個符合資格的傷害事件套用一次。
- 不會阻止傷害附帶的其他合法效果，除非那些效果以實際傷害為成立條件且傷害降為零。
- 本修飾不提供護盾、治療、免疫或狀態解除。
