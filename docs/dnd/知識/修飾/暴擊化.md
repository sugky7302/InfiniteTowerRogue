# 暴擊化

暴擊化是讓一次成功的傷害事件保證按照暴擊傷害結算的修飾知識。

## 基礎能力

- 相連的傷害事件成功時，不進行暴擊率判定，直接依對應分類的[[暴擊傷害]]結算。
- 暴擊化不提高命中或技能成功率。
- 保證暴擊屬於高性能。技能必須以施法時間、資源、其他性能降低或明確規則支付代價。

## 研究方式

角色須先理解至少一種合法致傷機制，並透過研究弱點、能量集中或破壞時機形成本知識。[[傷害]]是結算規則，不是研究前置知識。

## 知識修正值

暴擊化不提供知識修正值。它改變成功傷害的結算方式。

## 常見路徑

- 適用核心→適用型態→合法傷害事件→暴擊化
