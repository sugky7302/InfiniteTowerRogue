# 持續時間延長

持續時間延長把一項已存在且符合資格的持續效果之剩餘時間增加固定秒數。

- 技能必須指定效果名稱或標籤、增加秒數、每次施放上限及最大剩餘時間。
- 只能修改技能執行時仍存在的合格效果，不能建立不存在的效果。
- 不改變效果強度、週期、來源、承受者、驅散分類或已排定事件。
- 延長後的未來週期依原有效果規則繼續排程。已錯過的週期不補發。
