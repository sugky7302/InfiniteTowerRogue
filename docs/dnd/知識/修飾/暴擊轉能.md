# 暴擊轉能

暴擊轉能是在傷害已保證暴擊時，把角色對應分類的暴擊率轉換成額外暴擊傷害的修飾知識。

## 基礎能力

- 只能修飾已包含[[暴擊化]]的傷害事件。
- 最終傷害依「原始傷害×（暴擊傷害＋暴擊率）」計算。
- 不會再次觸發暴擊判定，也不能重複轉換同一份暴擊率。

## 研究方式

角色須先掌握[[暴擊化]]1級，理解保證暴擊後多餘機率的能量如何重新分配，才能形成本知識。

## 知識修正值

暴擊轉能不提供知識修正值。它把既有屬性轉成傷害倍率。

## 常見路徑

- 適用核心→適用型態→合法傷害事件→[[暴擊化]]→暴擊轉能
