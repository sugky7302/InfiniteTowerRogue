# 背襲增幅

背襲增幅在[[背後時]]成立時，提高一個明確相連的武器傷害事件。

- 技能必須記錄倍率、適用傷害事件與疊加群組。
- 只修改同一條路徑中相連的武器傷害，不影響命中、其他分支或後續週期傷害。
- 條件不成立時，基礎武器傷害仍正常結算。
- 本修飾不能單獨造成傷害，也不能把不合法武器變成可用戰具。
