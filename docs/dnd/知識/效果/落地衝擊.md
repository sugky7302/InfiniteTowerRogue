# 落地衝擊

落地衝擊把使用者著地時的動量經地面傳向鄰近目標，提供一次鈍擊物理傷害的致傷機制。

- 必須連在成功落地事件之後，並以[[區域]]或其他合法型態指定傳力範圍。
- 技能必須記錄傷害基礎值、力量係數、作用半徑、合法地面與目標關係。
- 每次落地只建立一次傷害事件。同一目標不因佔據多個區域位置而重複承受。
- 柔軟、破碎、懸空或無法傳力的落點會降低或取消衝擊。本效果不免費破壞地形或讓使用者免受自身墜落傷害。
