# 怒氣生成

怒氣生成在技能指定的成功條件成立時，增加固定數量的怒氣。

- 技能必須記錄生成量、成功條件與每次施放上限。
- 攻擊技能預設要求至少一個相連傷害事件造成實際傷害。移動技能可以明確改用成功抵達作條件。
- 多段或多武器技能不會因多次命中重複生成，除非技能明載逐段生成。
- 怒氣不能超過最大值。超出部分預設溢失。
