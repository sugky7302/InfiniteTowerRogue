# 強制逃離

強制逃離使受恐懼目標在仍能主動移動時，優先沿可通行路徑遠離指定來源。

- 技能必須指定逃離來源、移動速度、路徑選擇、無路可走時的行為與終止條件。
- 不會讓目標穿越障礙、危險地形或取得額外移動能力。
- 目標被定身、昏迷或癱瘓時不能移動，但恐懼狀態是否繼續由技能決定。
- 減少移動速度必須另外使用[[移動減速]]。
