# 暗影之蔓延

暗影之蔓延是改變光路、遮光結構或吸收區域，使遮蔽向相鄰位置擴張的效果知識。

- 蔓延必須有連續區域與可說明的遮光或吸收來源。
- 技能必須支付新增範圍、持續時間與目標選取成本。
