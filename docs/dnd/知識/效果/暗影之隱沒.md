# 暗影之隱沒

暗影之隱沒是調整目標輪廓、亮度與背景對比，使其更難被光學辨認的效果知識。

- 目標移動、背景改變或受到強光時可能破壞隱沒。
- 本效果不等同不存在，仍可能被其他感官、接觸或推理發現。
