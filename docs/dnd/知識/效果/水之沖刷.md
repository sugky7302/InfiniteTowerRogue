# 水之沖刷

水之沖刷是以持續水流、壓力與顆粒搬運帶走表層物質或削弱結構的效果知識。

- 必須有足夠水量、流速及作用時間。
- 材料硬度、結構、表面保護與水流方向會影響結果。
- 沖刷可以在水流壓力與搬運物足以破壞目標時支持直接傷害。技能根節點須依[[傷害]]記錄數值與代價。低壓清洗或搬運用途不會自動造成傷害。
