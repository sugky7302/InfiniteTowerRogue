# 躍擊

躍擊讓使用者沿已檢查的拋物[[軌跡]]主動離地，並在合法落點恢復站立或指定著地姿態。

- 技能必須記錄最短與最長距離、起跳速度、最高點、落點、路徑及移動時間。
- 起跳前要確認使用者能主動移動，且路徑容積與落點可供其通過及站立。
- 路徑撞上障礙、落點失效或移動能力中斷時，依技能指定提前落地或失敗，不會穿越障礙。
- 成功只代表完成位移，不免費造成傷害、免疫墜落、跨越空間隔離或命中目標。
