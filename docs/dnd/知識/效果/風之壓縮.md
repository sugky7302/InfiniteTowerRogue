# 風之壓縮

風之壓縮是把一定量氣體限制在較小容積內，提高其密度與壓力的效果知識。

- 壓縮必須有邊界或持續施力，解除限制後氣體會膨脹。
- 壓縮通常提高溫度。若要控制熱量，還需要能量相關知識。
- 本效果不免費造成傷害、爆炸或永久儲存氣體。
