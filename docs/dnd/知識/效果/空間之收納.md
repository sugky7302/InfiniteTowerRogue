# 空間之收納

空間之收納是建立或指定具有邊界與入口的容納空間，讓合格目標進出及保存的效果知識。

- 必須記錄容量、入口、存取條件、環境交換與失效後內容去向。
- 目標不會失去質量、時間需求或生命維持條件。
- 活物、危險物與超量內容依技能限制處理。
