# 空間之隔離

空間之隔離是以明確邊界限制內外之間的移動、能量或資訊傳遞的效果知識。

- 技能必須逐項指定被阻斷的內容。阻擋移動不代表同時阻擋光、聲、熱或心智連結。
- 邊界必須有範圍、強度、持續時間、通過條件與解除方式。
- 未被列入的作用仍可正常穿過。
