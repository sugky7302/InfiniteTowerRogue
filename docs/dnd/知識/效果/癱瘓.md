# 癱瘓

癱瘓是使目標不能主動移動、攻擊、施法、使用技能或操作物品的控制狀態。

- 與昏迷不同，癱瘓可以由僵直、冰封、麻痺或封鎖動作造成，不必代表意識中斷。
- 技能必須記錄持續時間、可否感知或說話、抵抗方式、解除條件及驅散分類。
- 癱瘓不會免費提高承受傷害或保證攻擊命中。
- 標示[[受傷解除]]時，每次實際生命值損失後依相連觸發的解除率判定。
