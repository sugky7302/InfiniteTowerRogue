# 光明之裁擊

光明之裁擊把受控光能與施術者意志集中於目標，使相容形體承受神聖類型的直接能量傷害。

## 基礎能力

- 必須由[[光明]]或其他明載相容核心供能，並以[[接觸]]、[[投射]]或其他合法型態抵達目標。
- 技能必須記錄神聖傷害基礎值、法術強度係數、命中時點與能量消耗。
- 「神聖」是此效果的傷害分類，不代表自動克制邪惡、不死或特定陣營。額外相剋必須另有資格與修飾節點。
- 不免費淨化、治療、顯形、昏迷或驅散。

## 研究方式

角色須先理解能量放射、光強控制與意志維持，才能把光明穩定集中成一次致傷事件。

## 知識修正值

本次實際執行路徑使用光明之裁擊建立直接神聖傷害時，依一般效果知識提供知識修正值。
