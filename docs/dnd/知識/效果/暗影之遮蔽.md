# 暗影之遮蔽

暗影之遮蔽是降低目標與背景之間可見差異，使光學觀測更困難的效果知識。

- 遮蔽程度取決於照明、對比、距離、觀察者感官與替代感知。
- 本效果不等同隱形，也不免費影響聽覺、嗅覺或魔法感知。
