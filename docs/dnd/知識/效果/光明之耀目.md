# 光明之耀目

光明之耀目是讓入眼光強超過視覺適應能力，暫時降低目標視覺的效果知識。

- 只對能以視覺接收該光譜的目標有效。
- 效果取決於亮度、距離、暴露時間、防護與感知閾值。
- 技能必須指定持續時間、恢復方式與抵抗判定。
