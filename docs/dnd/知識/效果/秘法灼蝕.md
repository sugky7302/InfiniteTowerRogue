# 秘法灼蝕

秘法灼蝕讓秘法能量依附目標並週期性擾動其結構，支持週期秘法傷害。

- 技能必須記錄總持續時間、首次觸發延遲、週期、每次傷害、驅散分類與終止條件。
- 每次週期分別結算傷害、抵抗與觸發，不把總量預先扣除。
- 到期、成功驅散或依附來源失效後，不再產生未來傷害事件。
- 本效果不提供命中時直接傷害。直接秘法傷害由相容核心另行支持。
