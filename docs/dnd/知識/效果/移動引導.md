# 移動引導

移動引導允許角色在指定引導技能持續期間移動，並以當下位置與朝向更新後續作用來源。

- 技能必須指定允許的移動方式、速度上限、可否改變朝向及每次更新時點。
- 不免除引導時間、資源、視線、射程、路徑、控制或其他中斷條件。
- 移動不補發已錯過事件，也不把先前事件改到新位置。
- 未明列的瞬移、強制位移、跌倒或失去意識仍按技能中斷規則處理。
