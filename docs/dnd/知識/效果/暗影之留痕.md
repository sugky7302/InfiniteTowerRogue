# 暗影之留痕

暗影之留痕是把目標的光學輪廓記錄在介質或能量結構中，使目標離開後仍可觀察的效果知識。

- 留痕必須有記錄介質、儲能或記憶機制，不是自然陰影的固有能力。
- 技能必須指定保存時間、解析度與可被清除的方式。
