# 火之消耗

火之消耗是讓燃料在持續燃燒中逐步轉成氣體、灰燼與其他產物的效果知識。

- 消耗速度取決於燃料量、反應面積、供氧、溫度與燃燒時間。
- 物質不會消失，只會轉成其他產物並釋放或吸收能量。
- 本效果不自動造成傷害，也不能消耗不符合反應條件的材料。
