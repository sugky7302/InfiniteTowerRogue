# 空間之位移

空間之位移是把目標由起點移到合法終點的效果知識。

- 必須指定距離、方向或終點，以及目標與目的地是否可重疊。
- 位移不會免費穿越封閉邊界。傳送還需處理空間連接。
- 強制位移必須提供抵抗方式，目的地無效時不得默認成功。
