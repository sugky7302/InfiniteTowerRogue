# 連擊點生成

連擊點生成在相連攻擊成功命中後，對本次目標增加固定數量的連擊點。

- 角色的連擊點綁定一名目標，預設範圍為0至5。
- 改換綁定目標時，舊目標的連擊點清除；保留或轉移需要額外知識。
- 未命中、攻擊失敗或目標在結算前失去資格時不生成。
- 超過上限的部分溢失。生成本身不造成傷害或支付終結技成本。
