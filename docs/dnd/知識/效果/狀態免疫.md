# 狀態免疫

狀態免疫在限定持續時間內，拒絕新施加的一種明確狀態分類。

- 技能必須指定免疫分類、持續時間、來源、驅散分類及是否處理已存在狀態。
- 預設只阻止新狀態，不移除已存在狀態。若要解除既有狀態，必須另有解除效果。
- 免疫昏迷不會免疫癱瘓、定身或恐懼。免疫移動減速也不會免疫定身。
- 免疫只改變狀態是否成立，不減少造成該狀態之技能的其他傷害或效果。
