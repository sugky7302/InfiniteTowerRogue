# 火之燃燒

火之燃燒是把足夠熱量傳給可燃目標，使其進入持續氧化反應的效果知識。

## 基礎能力

- 目標必須具有可燃材料或被其他知識暫時賦予可燃條件。
- 成功建立燃燒狀態時，必須同時建立至少一個大於0的週期火焰傷害值；此內稟結果不需要額外傷害節點。
- 技能根節點必須記錄每次週期傷害、週期間隔、持續條件與終止條件。
- 只有加熱、照明或短暫接觸而沒有持續氧化時，不建立燃燒狀態。
- 缺氧、隔絕、降溫或移除燃料可以終止燃燒，依技能記載判定。
- 本頁不再是自動取得的元素性質，也不能同時替代法則性質節點。

## 常見路徑

> [[能量法則]]→[[火焰]]→適用型態→[[火之燃燒]]
