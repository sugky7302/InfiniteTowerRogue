# 暗影之侵蝕

暗影之侵蝕是把吸收的能量轉為能破壞材料或生命結構的持續作用。

- 暗影只提供吸收與承載方式。真正破壞必須說明能量轉化及作用機制。
- 本效果支持週期暗影傷害。技能根節點仍須依[[傷害]]與[[持續與週期]]記錄數值、週期、持續時間及終止條件。
