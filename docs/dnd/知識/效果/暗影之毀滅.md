# 暗影之毀滅

暗影之毀滅是把暗影結構中儲存的破壞性能量集中釋放到目標的效果知識。

- 暗影本身不提供破壞力。技能必須記錄能量來源、儲存方式與釋放機制。
- 本頁以集中釋放的破壞性能量支持即時暗影傷害。數值、作用時點與代價仍由[[傷害]]規則及技能根節點決定。

常見路徑：[[暗影]]→[[投射]]→暗影之毀滅→啟用即時暗影傷害
