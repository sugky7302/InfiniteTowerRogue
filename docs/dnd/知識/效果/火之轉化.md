# 火之轉化

火之轉化是以熱量使材料發生相變、乾燥、熔融、燒結或其他熱致變化的效果知識。

- 目標材料必須達到對應溫度並維持足夠時間。
- 轉化內容取決於材料本身，不能用同一效果任意指定產物。
- 本效果不免費燃燒、造成傷害或讓改變永久維持。
