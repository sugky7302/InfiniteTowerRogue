# 接敵

接敵讓使用者沿已檢查的[[軌跡]]移動到目標旁的合法近戰位置。

- 技能必須記錄最短與最長啟動距離、移動速度及允許的終點範圍。
- 目標移動時，技能依根節點指定追蹤、修正終點或失敗，不會自動傳送到目標身邊。
- 路徑被障礙阻擋、終點不可站立或距離不符時失敗。
- 成功只代表抵達合法位置，不免費命中、造成傷害或限制目標。
