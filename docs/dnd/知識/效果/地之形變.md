# 地之形變

地之形變是改變土壤、岩石或礦物既有輪廓與排列的效果知識。

- 材料必須能被塑形，或技能另行支付破碎、軟化等前置效果。
- 形變的體積、精度與幅度由技能性能與施展時間決定。
- 本效果不免費創造或移除材料，也不保證變形後的構造穩固。
