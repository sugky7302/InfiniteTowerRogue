# 空間之錨定

空間之錨定是把目標位置綁定到指定參照系，以抵抗位移、傳送或空間重連的效果知識。

- 錨定必須指出參照物、強度、持續時間及可抵抗的位移類型。
- 它不等同定身。目標仍可在錨定允許的範圍內正常移動。
- 超過錨定強度時依對抗結果解除或失效。
