# 光明之顯現

光明之顯現是以足夠照明與觀測條件提高目標可見度的效果知識。

- 只能削弱缺光、普通陰影與相容的光學遮蔽。
- 不會免費揭露偽裝、心智幻覺、不可見物或被實體阻隔的目標。
- 是否看清仍取決於距離、解析度與觀察者感官。
