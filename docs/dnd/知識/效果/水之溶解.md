# 水之溶解

水之溶解是使可溶物質從原有結構分散並混入水中的效果知識。

- 只有與水相容且可溶的材料才能被溶解。
- 溶解速度受接觸面積、溫度、攪動、濃度與材料結構影響。
- 本效果不免費腐蝕不可溶材料，也不會使溶質消失。
