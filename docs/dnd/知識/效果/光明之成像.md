# 光明之成像

光明之成像是控制光路形成可辨識影像的效果知識。

- 影像內容必須來自光學資訊、記錄或另行提供的心智內容。
- 解析度、視角、亮度與遮蔽由光路和感知條件限制。
- 成像不會自動欺騙心智。幻覺還需要心智相關效果。
