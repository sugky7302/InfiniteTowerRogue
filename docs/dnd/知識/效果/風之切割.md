# 風之切割

風之切割是以集中高速氣流或氣流攜帶的微粒對目標表面施加剪切的效果知識。

- 能否切開目標取決於壓力差、速度、作用面積、介質與材料結構。
- 純氣流難以切割高強度材料。需要更高能量或攜帶顆粒時必須明確記錄。
- 集中高速氣流形成足夠剪切時，本效果支持直接風屬性傷害；技能根節點須依[[傷害]]記錄數值與代價。低速氣流不會自動造成傷害。
