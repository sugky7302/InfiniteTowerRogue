# 空間之伸縮

空間之伸縮是改變限定區域內有效距離或容積的效果知識。

- 必須指定固定參照點、倍率、邊界、持續時間及內部物質如何適應改變。
- 伸縮空間不等同改變物體本身尺寸。
- 結束時若內容超出可容納範圍，必須有明確的排出或失敗規則。
