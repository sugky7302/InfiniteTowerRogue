# 暗影之消光

暗影之消光是吸收、偏轉或阻隔局部光能，使光源或受照區域變暗的效果知識。

- 被移除的光能必須轉化、儲存或離開作用區域。
- 消光不會自動隱藏目標，也不影響不依賴光的感知。
