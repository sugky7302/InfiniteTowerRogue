# 空間之折疊

空間之折疊是暫時改變兩個位置間的連接與有效距離，使作用能以較短路徑通過的效果知識。

- 必須指定兩端位置、可通過內容、有效距離、持續時間與邊界。
- 折疊不會自動移動目標，也不會取消原本空間。
- 路徑中斷時，正在通過的目標依技能的失敗條件處理。
