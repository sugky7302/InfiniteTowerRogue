# 光明之淨化

光明之淨化是以特定光譜或輻射能量破壞已辨識且對該能量敏感之污染、遮蔽或魔法結構的效果知識。

- 使用前必須辨識目標結構及其可被光能干涉的原因。
- 只對相容目標有效，不是通用驅散，也不能因「邪惡」或「污穢」標籤自動成立。
- 能量強度、暴露時間與副作用必須由技能記錄。
