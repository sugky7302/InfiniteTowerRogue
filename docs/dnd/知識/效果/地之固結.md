# 地之固結

地之固結是使鬆散土砂或碎石重新形成較穩定結構的效果知識。

- 必須有足夠顆粒材料與可形成連結的條件。
- 固結程度決定材料抵抗鬆散、沖刷與外力破壞的能力。
- 本效果不免費提供永久性、金屬硬度或建築級承載力。
