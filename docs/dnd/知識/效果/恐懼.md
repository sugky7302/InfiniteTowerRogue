# 恐懼

恐懼是使目標進入強烈威脅反應的心智控制狀態。

- 技能必須指定恐懼來源、限制行為、持續時間、抵抗方式、解除條件及是否強制移動。
- 恐懼本身可以使目標畏縮或不能主動接近來源。要強迫移動仍須連接[[強制逃離]]。
- 不具有相容心智、無法感知威脅或明載免疫恐懼的目標不受影響。
- 標示[[受傷解除]]時，每名目標分別監聽實際傷害。
