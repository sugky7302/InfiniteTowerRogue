# 風之推動

風之推動是以氣流壓力對目標施力，使其開始移動或改變方向的效果知識。

- 位移量取決於氣流施力、作用時間、目標質量與阻力。
- 推動不自動造成傷害、擊倒或無視固定裝置。
- 技能必須指定方向、最大位移與目標抵抗方式。
