# 水之遲滯

水之遲滯是利用流體阻力、黏度與壓力降低目標移動或動作速度的效果知識。

- 目標必須接觸足夠水量，且水能對其運動形成阻力。
- 遲滯只影響技能指定的移動或動作，不等同定身。
- 技能必須指定減速幅度、持續時間、離開水體後的終止條件與抵抗方式。
