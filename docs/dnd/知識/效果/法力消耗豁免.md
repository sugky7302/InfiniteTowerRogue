# 法力消耗豁免

法力消耗豁免在限定時間內，把承受者開始支付之合格技能的法力消耗改為0。

- 技能必須指定持續時間、合法承受者及適用技能範圍。
- 只免除法力，不免除其他資源、材料、施法時間、檢定、冷卻或維持條件。
- 只影響效果持續期間開始支付的技能。不返還先前法力，也不追溯修改已開始技能。
- 同一筆法力消耗最多套用一次豁免。
