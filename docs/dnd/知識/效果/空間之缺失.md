# 空間之缺失

空間之缺失是把限定區域或內容暫時移出目前可接觸的空間連接，而非使其憑空消滅。

- 必須指定內容被轉移至何處、如何保存，以及何時返回。
- 不能用「缺失」規避質量、能量、生命維持或因果後果。
- 對生物或他人持有物使用時必須提供抵抗與失敗條件。
