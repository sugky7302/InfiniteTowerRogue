# 移動施法

移動施法在限定持續時間內，允許角色移動時繼續施放技能根節點明列的技能類型。

- 技能必須指定允許範圍，例如特定技能、職業技能或具有指定標籤的法術。
- 不會免除施法時間、資源、檢定、距離、視線或其他中斷條件。
- 未列入允許範圍的技能仍按原規則受移動中斷。
- 本效果不提高移動速度，也不提供減速或其他控制免疫。
