# 昏迷

昏迷是使目標暫時不能主動移動、攻擊、施法、使用技能或做出需要主動反應之行為的控制狀態。

- 目標仍能承受傷害、被移動及受到其他效果。
- 技能必須記錄持續時間、抵抗方式、解除條件及驅散分類。
- 昏迷不等於死亡、睡眠、定身或失去所有感知。敘事反應由場景規則處理。
- 已存在的昏迷是否刷新或取較強者，依[[持續與週期]]處理。
