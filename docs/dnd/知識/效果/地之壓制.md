# 地之壓制

地之壓制是利用土石質量、接觸阻力與持續施力限制目標移動的效果知識。

- 必須有足夠土石能接觸並阻擋目標。
- 壓制只限制技能指定的移動或動作，不自動造成傷害、昏迷或完全失去行動。
- 技能必須記錄持續時間、解除方式與目標抵抗方式。
