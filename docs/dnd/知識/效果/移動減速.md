# 移動減速

移動減速是在指定持續時間內降低目標移動速度的狀態效果。

- 技能必須記錄速度倍率、持續時間、疊加群組、抵抗方式與解除條件。
- 最終移動速度依相容規則計算，不得低於技能或遊戲模式設定的下限。
- 移動減速不等於[[定身]]，不會禁止目標移動、攻擊或施法。
- [[狀態免疫]]可以只拒絕移動減速，而不影響定身、昏迷或其他控制。
