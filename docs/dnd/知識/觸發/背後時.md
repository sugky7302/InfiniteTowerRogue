# 背後時

背後時在命中時依攻擊者位置、目標朝向與場景方位規則，判斷攻擊者是否位於目標背後。

- 判定使用命中時位置，不使用技能開始時的位置。
- 沒有可辨識朝向、免疫方位判定或全向感知的目標，依目標規則決定是否成立。
- 條件不成立時只略過相連分支，不會使基礎攻擊失敗。
- 本觸發只判斷方位，不提供增傷或命中加成。
