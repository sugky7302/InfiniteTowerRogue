# 不死資格

不死資格在效果執行前，檢查目標是否具有「不死」類型，以及能承受該效果的維持結構。

- 只有生物類型與結構檢查都成立時，後續的不死專用分支才會執行。
- 不死生物具有生命值，不代表它具有一般代謝。治療、修復、驅散或傷害仍須分別聲明是否相容。
- 目標在技能結算前失去資格時，該分支失敗，不會自動改選其他目標或結果。
- 本觸發只判斷資格，不會把活體轉成不死生物，也不提供治療或傷害。
