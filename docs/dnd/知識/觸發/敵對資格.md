# 敵對資格

敵對資格在相連效果執行前，確認候選者於該時點是施放者的敵人且不是施放者本人。

- 技能必須先以位置、區域、射線或其他條件建立有限候選，再套用本觸發。
- 施放者、友軍與中立目標不合格。關係依[[增益與目標選取]]於每次觸發時重算。
- 本觸發不忽略遮蔽、感知、射程、無敵或其他目標限制。
- 只負責資格判斷，不造成傷害或建立仇恨。
