# 符文熔爐前置

符文熔爐前置在刻印開始及完成時，檢查工作站、工具、材料與目標裝備是否符合配方。

- 工作站必須提供配方指定的穩定能量、刻印平面、固定裝備機構及安全散熱能力。只有名稱相同但缺少功能的場景物件不合格。
- 技能必須指定裝備類型、刻印負載、相容標籤、鑲嵌順序、材料、工具、改造時間與拆除方式。
- 改造期間離開工作站、移走目標裝備、失去工具或中斷操作時失敗。已消耗材料是否保留由配方明列。
- 本觸發只確認改造資格，不提供刻印容量、供能或執行刻印。
