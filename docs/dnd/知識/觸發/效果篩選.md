# 效果篩選

效果篩選依目標關係、受益方向、效果標籤、驅散類型與特殊保護，建立有限且可排序的持續效果候選。

- 每次使用必須指定友軍／敵軍／中立、增益／有害／中性、驅散類型、目標上限、每名效果上限與排序。
- 不符合條件的效果不進入候選，不會因檢定較高而被強行選取。
- 特殊保護只在技能具有特殊驅散權限時列入。不可驅散效果永不列入。
- 本觸發只篩選候選，實際終止仍須使用[[驅散]]。
