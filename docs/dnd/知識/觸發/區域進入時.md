# 區域進入時

區域進入時在符合資格的目標由區域外進入感應區後，執行一次相連效果。

- 技能必須指定區域、候選資格、部署完成時點、同時進入排序、啟動上限與內部冷卻。
- 部署前已在區域內的目標是否算進入，必須由技能明載。未記載時不觸發。
- 單次裝置在首次成功觸發後停止偵測並消耗。
- 本觸發只偵測事件，不提供敵我辨識、傷害、控制或隱藏。
