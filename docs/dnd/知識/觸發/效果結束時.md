# 效果結束時

效果結束時在指定持續效果實例終止後，依結束原因白名單決定是否執行相連分支。

- 技能必須指定效果名稱、實例關係及接受的結束原因。
- 自然到期、驅散、主動取消、來源死亡、條件失效與替換刷新分開判定。
- 每個效果實例最多觸發一次。刷新未建立新實例時不視為結束。
- 本觸發不建立外部來源、區域、傷害或新持續效果。
