# 外部施放來源

外部施放來源在分支執行前，確認技能指定的其他實體、召現物或裝備仍可作為作用起點。

- 必須指定來源身分、位置、控制者、可用期間、相容核心與失效條件。
- 只把相連分支的起點改為該來源，不替代核心、型態、資源或結果。
- 多個來源必須各自建立完整分支並分別計算節點。
- 來源失效只使自身分支失敗，不會把作用改回施放者位置。
