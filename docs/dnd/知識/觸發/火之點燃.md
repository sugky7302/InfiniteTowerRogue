# 火之點燃

火之點燃是在可燃材料達到點燃條件時，執行[[火之燃燒]]效果的觸發知識。

- 觸發條件至少包含足夠溫度、可燃材料與可維持反應的環境。
- 本觸發只決定何時執行，不會取代燃燒效果或免費提供熱量。
- 若材料降溫、缺氧或失去燃料，觸發不成立。
