# 時間之週期

時間之週期是依固定或可計算間隔重複執行相連效果的觸發知識。

- 技能必須指定間隔、總持續時間、最大觸發次數與中斷條件。
- 每次觸發只執行已連接效果，不會免費產生傷害或恢復。
- 即時與回合模式都使用實際秒數，再由模式轉譯規則顯示。
