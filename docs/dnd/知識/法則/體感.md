# 體感

體感研究感官如何接收身體位置、受力與運動狀態。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：平衡、本體感覺、觸覺、疼痛與姿勢控制。
- 邊界：不免費提供閃避、免疫失衡或預判攻擊。
