# 自我

自我研究心智如何整合身體感受並維持自身身分。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：自我認同、身體圖式、自我感、人格界線與意識定位。
- 邊界：不免費抵抗心控、修復人格或轉移意識。
