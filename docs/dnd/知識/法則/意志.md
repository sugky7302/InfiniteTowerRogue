# 意志

意志研究心智如何產生、集中與維持可用力量，是能量與心智的二級複合法則。

- 常見方向：專注、精神負荷、意念強度與心靈能量。
- 邊界：不免費恢復資源、抵抗控制或把意念轉成傷害。
- 悟證方式：掌握兩項來源法則後，透過冥想、壓力訓練或心智能量實驗形成。
