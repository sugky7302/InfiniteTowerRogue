# 刺激

刺激研究能量變化與動態訊號如何觸發感知反應。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：閃光、巨響、電刺激、疼痛與感官過載。
- 邊界：不免費致盲、暈眩、麻痺或強迫反應。
