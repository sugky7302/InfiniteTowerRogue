# 場力

場力研究空間中的能量分布如何對物體施加方向性力量。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：引力、電磁力、排斥、牽引與場加速。
- 邊界：不免費吸引、推開、束縛或造成傷害。
