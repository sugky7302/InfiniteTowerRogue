# 流動法則

流動法則研究事物如何凝聚、流轉、滲透與循環，是七大法則之一。

## 本體定位與象徵

流動法則源自水大，代表滋潤與凝聚。標準種子字是尾（Va），圖案是圓形。在人體以血液為典型對應，在萬物以山川河流為典型對應。這些象徵用於表達與教學，不限縮流動法則的其他表現。

## 主要性質

- 凝聚：分散內容維持為連續整體。
- 流動：內容沿可行路徑改變位置。
- 溶解與混合：不同內容進入同一流體系統。
- 滲透：流體穿過孔隙或介面。
- 循環：流動沿路徑反覆返回。

## 使用邊界

流動法則不等同於水元素，也不免費產生液體、減速、治療或沖擊。技能必須指定實際介質及相應效果。
