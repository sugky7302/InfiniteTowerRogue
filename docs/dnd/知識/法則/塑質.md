# 塑質

塑質研究能夠流動、變形，同時維持物質連續性的形體，是形體與流動的二級複合法則。

- 常見方向：泥、膠體、凝膠、軟組織與可塑材料。
- 邊界：不免費提供塑形、束縛或減速效果。
- 悟證方式：掌握兩項來源法則後，透過材料觀察、流變實驗或實踐形成。
