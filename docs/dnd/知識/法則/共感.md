# 共感

共感研究感知到的情緒訊息如何被心智理解並形成同步感受。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：同理、情緒辨識、群體共鳴與感受分享。
- 邊界：不免費讀心、操縱情緒或取得目標完整記憶。
