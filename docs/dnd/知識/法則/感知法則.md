# 感知法則

感知法則研究生命或裝置如何接收外界訊息，是七大法則之一。

## 見大與根塵接觸

感知法則以見大為理論原型，負責使既有現象成為可接觸的訊號。六根是接收介面，六塵是既有現象的可感知面。兩者接觸仍只建立訊號條件，不保證形成理解。前五根的具體載體通常由[[感官]]承擔，意根則與心智條件相連。

## 主要性質

- 感受：接收光、聲、氣味、味道、觸碰或其他刺激。
- 閾值：刺激必須達到可被察覺的程度。
- 方向：判斷訊息來自何處。
- 分辨：區隔同時或相近的刺激。
- 回饋：感知結果影響後續行動。

## 使用邊界

感知法則只負責取得訊息，不保證理解內容。它不免費提供遠視、預知、識破幻象或必中能力。根塵接觸後的六識是辨識事件，通常必須透過[[認知]]結合心智法則才能成立。
