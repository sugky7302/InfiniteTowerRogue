# 流場

流場研究流體在空間中各位置的速度、方向與壓力分布。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：風場、水流場、渦旋區、壓力圖與流線。
- 邊界：不免費產生風水、控制區域或移動目標。
