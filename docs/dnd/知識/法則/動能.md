# 動能

動能研究能量如何轉化為運動、衝擊與加速，是能量與動力的二級複合法則。

- 常見方向：衝擊、加速、反衝、爆發與能量傳遞。
- 邊界：不免費造成傷害、推動目標或增加速度。
- 悟證方式：掌握兩項來源法則後，透過碰撞、加速或能量轉換實驗形成。
