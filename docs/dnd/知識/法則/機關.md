# 機關

機關研究有形零件如何在限定空間內依序運動並完成工作。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：陷阱、鎖具、連桿、機械門與自動裝置。
- 邊界：不免費製造設備、偵測觸發或造成傷害。
