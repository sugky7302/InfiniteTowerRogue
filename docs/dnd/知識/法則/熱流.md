# 熱流

熱流研究能量如何隨流體遷移、交換與擴散，是流動與能量的二級複合法則。

- 常見方向：對流、蒸氣、冷媒、熱液與溫度循環。
- 邊界：不免費造成燃燒、凍結、推進或範圍傷害。
- 悟證方式：掌握兩項來源法則後，透過溫差、流體與熱交換實驗形成。
