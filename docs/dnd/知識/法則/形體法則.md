# 形體法則

形體法則研究事物如何具有可辨識的形體、質量與結構，是七大法則之一。

## 本體定位與象徵

形體法則源自地大，代表堅固與定著。標準種子字是阿（A），圖案是方形。在人體以骨骼為典型對應，在萬物以大地為典型對應。這些象徵用於表達與教學，不是施展技能的強制材料或免費效果。

## 主要性質

- 形體：事物占有範圍並具有外形。
- 質量：事物具有重量與慣性。
- 結構：組成部分按照固定關係排列。
- 硬度與密度：形體抵抗變形及內容集中的程度。
- 承載：形體支撐、容納或固定其他事物。

## 使用邊界

形體法則只提供研究形體現象的根本依據，不免費創造物質、改變材質、造成傷害或提供防護。具體能力必須由核心、型態、效果與性質知識完成。
