# 認知

認知研究感官訊息如何被辨識、理解、記憶與判斷，是感知與心智的二級複合法則。

- 常見方向：辨識、注意、學習、記憶、推理與錯覺。
- 邊界：不免費讀心、識破幻覺、取得知識或改寫記憶。
- 悟證方式：掌握兩項來源法則後，透過觀察、推理、記憶或心理實驗形成。
