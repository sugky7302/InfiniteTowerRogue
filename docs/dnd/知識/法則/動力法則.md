# 動力法則

動力法則研究事物如何開始、維持與改變運動，是七大法則之一。

## 本體定位與象徵

動力法則源自風大，代表流通與交互作用。標準種子字是吽（Hūṃ），圖案是半圓形。在人體以呼吸為典型對應，在萬物以空氣、吸力與斥力為典型對應。風大不限於空氣，任何力量傳遞仍須具備合法來源與作用路徑。

## 主要性質

- 施力：使目標的運動狀態改變。
- 動量：運動中的事物維持方向與速度。
- 壓力：力量分布在接觸面或介質中。
- 震動：狀態在平衡位置附近反覆變化。
- 傳播：運動或擾動沿介質向外傳遞。

## 使用邊界

動力法則不等同於風，也不免費移動、推拉、切割或加速目標。技能必須指定力量來源、作用方向與效果。
