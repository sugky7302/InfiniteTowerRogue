# 傳情

傳情研究心智狀態如何透過動態訊號在人與人之間傳播。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：語調、姿態、群體情緒、鼓舞與恐慌傳播。
- 邊界：不免費魅惑、恐懼、鼓舞或強迫他人接受情緒。
