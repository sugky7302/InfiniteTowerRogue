# 心靈投射

心靈投射研究感知與心智如何跨越空間建立可理解的資訊出口。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：共享視野、遠距意識、心靈通訊與感知化身。
- 邊界：不免費跨越隔絕區域、讀取思想、控制目標或無限延伸距離。
