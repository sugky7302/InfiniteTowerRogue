# 驅使

驅使研究心智如何把意圖轉換成行動、操控與命令，是動力與心智的二級複合法則。

- 常見方向：自主動作、念動、操偶、命令與意圖執行。
- 邊界：不免費控制目標、移動物體或強迫他人服從。
- 悟證方式：掌握兩項來源法則後，透過動作控制、操偶、念動或意圖訓練形成。
