# 煉化

煉化研究能量如何改變形體的狀態與材質，是形體與能量的二級複合法則。

- 常見方向：熔融、凝固、鍛造、燒結與相變。
- 邊界：不免費產生火焰、改變材料或提供傷害。
- 悟證方式：掌握兩項來源法則後，透過加熱、冷卻、鍛造或材料實驗形成。
