# 流力

流力研究流體的速度、壓力、渦流與推進，是流動與動力的二級複合法則。

- 常見方向：水流、氣流、液壓、渦旋與流體阻力。
- 邊界：不免費推動、切割、壓制或改變目標速度。
- 悟證方式：掌握兩項來源法則後，透過流速、壓力與渦流觀察形成。
