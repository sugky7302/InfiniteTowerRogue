# 機械

機械研究形體如何承受、傳遞與轉換力量，是形體與動力的二級複合法則。

- 常見方向：槓桿、齒輪、關節、彈性與結構受力。
- 邊界：不免費製造機械、移動物體或增加力量。
- 悟證方式：掌握兩項來源法則後，透過器械拆解、受力觀察或製作實驗形成。
