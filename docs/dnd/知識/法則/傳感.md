# 傳感

傳感研究訊息如何透過流動介質抵達感官，是流動與感知的二級複合法則。

- 常見方向：氣味、水中訊號、化學感受與介質取樣。
- 邊界：不免費辨識訊息、追蹤來源或跨越無介質區域。
- 悟證方式：掌握兩項來源法則後，透過氣味、水質、化學或介質傳遞實驗形成。
