# 循動

循動研究流體如何在有形結構中受力並持續循環。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：心搏、泵浦、液壓循環、呼吸運動與脈動。
- 邊界：不免費推進流體、驅動器官或維持生命。
