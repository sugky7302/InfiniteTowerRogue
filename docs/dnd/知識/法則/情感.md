# 情感

情感研究心智狀態的流轉、累積、感染與平復，是流動與心智的二級複合法則。

- 常見方向：情緒變化、共情、情緒感染、壓抑與宣洩。
- 邊界：不免費鼓舞、恐懼、魅惑或控制心智。
- 悟證方式：掌握兩項來源法則後，透過自省、觀察、交流或心理實驗形成。
