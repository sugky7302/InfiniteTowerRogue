# 力場

力場研究能量在空間中的分布、梯度與作用區域，是能量與空間的二級複合法則。

- 常見方向：引力場、電磁場、能量障壁與區域梯度。
- 邊界：不免費建立護盾、吸引、排斥或造成區域傷害。
- 悟證方式：掌握兩項來源法則後，透過場域測量、能量分布或邊界實驗形成。
