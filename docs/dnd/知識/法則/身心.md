# 身心

身心研究形體與內部流動如何共同影響心智狀態。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：壓力反應、荷爾蒙、情緒體感、身心症與內在平衡。
- 邊界：不免費治療精神、控制情緒或支配身體。
