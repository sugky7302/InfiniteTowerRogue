# 感知網

感知網研究訊息如何沿空間中的流動網路抵達多個感知端點。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：菌絲感應、水網監測、氣味網路與分散式感測。
- 邊界：不免費共享視野、全域探測或無視通道中斷。
