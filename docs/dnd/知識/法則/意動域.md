# 意動域

意動域研究心智如何在限定空間內指定並驅使運動。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：區域念控、路徑命令、遠端操控與自主移動區。
- 邊界：不免費操縱多個目標、傳送或無視抵抗。
