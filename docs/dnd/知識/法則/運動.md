# 運動

運動研究位置改變形成的軌跡、速度與方向，是動力與空間的二級複合法則。

- 常見方向：位移、速度、加速度、軌跡與相對運動。
- 邊界：不免費移動、傳送、追蹤或縮短距離。
- 悟證方式：掌握兩項來源法則後，透過測量、追跡、投射或移動實驗形成。
