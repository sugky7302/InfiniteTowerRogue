# 心脈

心脈研究心智內容如何沿固定連結在不同內在空間之間流動。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：心靈通道、記憶路徑、群體心智與情緒網路。
- 邊界：不免費讀心、共享記憶或跨距離傳遞思想。
