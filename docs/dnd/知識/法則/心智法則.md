# 心智法則

心智法則研究意識如何理解資訊、形成意圖並維持自我，是七大法則之一。

## 識大與六識事件

心智法則以識大為理論原型，提供注意、記憶、分別、判斷與意圖，使感知取得的訊號成為可理解資訊。六識是六根與相應六塵接觸後產生的事件，主要歸屬感知與心智組成的[[認知]]，不是六項永久知識。

## 主要性質

- 意識：對自身與外界狀態保持覺察。
- 記憶：保存並重新取得經驗資訊。
- 判斷：比較資訊並形成結論。
- 意圖：選擇目標並準備行動。
- 自我：維持心智身分與內外界線。

## 使用邊界

心智法則不能在沒有根、塵或其他合法資訊來源時免費取得外界內容，也不免費提供讀心、控制、幻覺、記憶改寫或精神傷害。技能必須指定資訊來源、目標資格、作用內容與抵抗方式。
