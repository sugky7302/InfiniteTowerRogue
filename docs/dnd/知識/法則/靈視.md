# 靈視

靈視研究心智如何感知、辨識與理解能量訊號。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：魔力視覺、氣場辨識、精神訊號與能量痕跡。
- 邊界：不免費看穿偽裝、解析法術或知道目標能力。
