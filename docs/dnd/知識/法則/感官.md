# 感官

感官研究具體器官或載體如何接收外界訊息，是形體與感知的二級複合法則。

- 常見方向：眼、耳、皮膚、感測器與感官損傷。
- 邊界：不免費提供特殊視覺、遠距感知或資訊理解。
- 悟證方式：掌握兩項來源法則後，透過解剖、觀察、感測實驗或醫療研究形成。
