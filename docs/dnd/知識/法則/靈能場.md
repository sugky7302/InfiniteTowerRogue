# 靈能場

靈能場研究心智能量如何在空間中分布並影響一個區域。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：精神領域、意志壓力、心智屏障與群體心靈環境。
