# 機能

機能研究有形結構如何取得能量並轉化為穩定運作。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：引擎、肌肉、機關動力、功率與效率。
- 邊界：不免費驅動設備、增加力量或產生額外行動。
