# 空間法則

空間法則研究事物存在的位置、距離、容積、邊界與連接，是七大法則之一。

## 本體定位與象徵

空間法則源自空大，代表無礙與包容，是地、水、火、風得以建立的本體基底。標準種子字是欠（Kha），圖案是蓮花或寶珠。在人體以包容為典型對應，在萬物以虛空為典型對應。

正常世界預設已有空間基底，因此普通技能不必顯式加入空間節點。只有技能主動改變位置、距離、容積、邊界或連接時，才需要以空間知識建立作用路徑。

## 主要性質

- 位置：事物相對於參照物所在之處。
- 距離：兩個位置之間的間隔。
- 容積：區域能夠容納內容的大小。
- 邊界：區分區域內外及通過條件。
- 連接：分離位置之間可供作用通過的關係。

## 使用邊界

空間法則不免費提供位移、傳送、收納、結界或無限射程。任何空間改變都必須記錄距離、目標、邊界與代價。
