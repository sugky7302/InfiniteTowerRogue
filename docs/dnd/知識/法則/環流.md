# 環流

環流研究能量與流體如何在空間中形成大尺度循環。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：洋流、氣候環流、熱循環、冷卻網與區域交換。
- 邊界：不免費改變天氣、溫度、地形或建立持續場域。
