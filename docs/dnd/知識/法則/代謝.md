# 代謝

代謝研究形體如何透過物質流動取得、轉化與消耗能量。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：營養、呼吸、體溫、能量循環與廢物排除。
- 邊界：不免費提供生命、治療、成長或資源恢復。
