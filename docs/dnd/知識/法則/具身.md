# 具身

具身研究心智如何依附、控制並透過形體表現，是形體與心智的二級複合法則。

- 常見方向：身體圖式、意識附著、化身、軀體記憶與身心協調。
- 邊界：不免費提供附身、控制、創造生命或轉移意識。
- 悟證方式：掌握兩項來源法則後，透過身心訓練、神經研究或意識實驗形成。
