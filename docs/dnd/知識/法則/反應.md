# 反應

反應研究感知變化後形成的即時回應與動作調整，是動力與感知的二級複合法則。

- 常見方向：反射、閃避、攔截、平衡與手眼協調。
- 邊界：不免費獲得額外行動、必中、閃避或預知。
- 悟證方式：掌握兩項來源法則後，透過反射訓練、對抗或感覺動作實驗形成。
