# 心域

心域研究心智如何建立、投射或共享內在空間，是空間與心智的二級複合法則。

- 常見方向：夢境、記憶宮殿、共享心境與精神領域。
- 邊界：不免費進入他人心智、建立真實空間或囚禁意識。
- 悟證方式：掌握兩項來源法則後，透過冥想、夢境、記憶結構或心靈連結形成。
