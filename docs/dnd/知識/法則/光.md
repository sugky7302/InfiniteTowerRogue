# 光

光研究可被感知的輻射、亮度、色彩與成像條件，是能量與感知的二級複合法則。

- 常見方向：照明、光譜、反射、折射與視覺成像。
- 邊界：不免費照明、致盲、顯形、幻象或造成輻射傷害。
- 悟證方式：掌握兩項來源法則後，透過光源、光譜、成像或視覺實驗形成。
