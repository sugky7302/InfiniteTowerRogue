# 追跡

追跡研究感知如何持續判斷移動目標的位置、方向與軌跡。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：追蹤、預判軌跡、鎖定、導航與移動偵測。
- 邊界：不免費必中、無視遮蔽、預知未來或跨區域追蹤。
