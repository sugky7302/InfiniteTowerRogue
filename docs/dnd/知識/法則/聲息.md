# 聲息

聲息研究介質中的振動與流動如何形成可被感知的訊號。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：聲音、回音、呼吸聲、水下聽覺與振動定位。
- 邊界：不免費造成音波傷害、沉默、定位或語意理解。
