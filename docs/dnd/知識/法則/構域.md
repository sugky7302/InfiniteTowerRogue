# 構域

構域研究形體如何界定、分隔與支撐空間，是形體與空間的二級複合法則。

- 常見方向：容器、建築、壁障、封閉區域與幾何構造。
- 邊界：不免費建立結界、擴張容積或提供防護。
- 悟證方式：掌握兩項來源法則後，透過建築、容器、邊界或空間測量研究形成。
