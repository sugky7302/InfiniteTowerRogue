# 身域

身域研究心智如何界定自身形體、控制範圍與內外邊界。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：身體邊界、化身控制、意識容器與領域化軀體。
- 邊界：不免費擴張身體、奪取軀殼或建立領域。
