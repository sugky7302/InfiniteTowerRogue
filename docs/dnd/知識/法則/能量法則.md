# 能量法則

能量法則研究事物發生作用與轉化所需的能量，是七大法則之一。

## 本體定位與象徵

能量法則源自火大，代表能量與變化。標準種子字是羅（Ra），圖案是三角形。在人體以溫度為典型對應，在萬物以陽光為典型對應。這些象徵不等同於火焰，也不會自行提供燃燒或傷害。

## 主要性質

- 溫度：能量在物質中的熱狀態。
- 傳遞：能量由一處移向另一處。
- 儲存與釋放：能量被保留後重新輸出。
- 轉化：能量在熱、光、動力等形式之間變換。
- 消耗：可用能量轉為難以利用的狀態。

## 使用邊界

能量法則不等同於火焰，也不免費造成燃燒、爆炸、照明、傷害或資源恢復。技能必須說明能量來源、轉化方式與代價。
