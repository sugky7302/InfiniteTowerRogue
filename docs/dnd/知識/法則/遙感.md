# 遙感

遙感研究感知如何跨越距離、邊界或媒介取得訊息，是空間與感知的二級複合法則。

- 常見方向：遠視、遠聽、感官出口、定位與區域探測。
- 邊界：不免費提供無限距離、跨區域觀察、穿透遮蔽或資訊理解。
- 悟證方式：掌握兩項來源法則後，透過遠距觀測、定位或感官連結實驗形成。
