# 念動

念動研究心智能量如何轉換為可施加於外界的力量。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：念力、精神衝擊、遠端推拉與意念驅動。
- 邊界：不免費移動物體、造成傷害或無視重量與距離。
