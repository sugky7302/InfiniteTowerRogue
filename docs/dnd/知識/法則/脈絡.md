# 脈絡

脈絡研究流體如何沿管道、循環與網路分配，是流動與空間的二級複合法則。

- 常見方向：血管、水路、輸送網、分流與循環路徑。
- 邊界：不免費建立通道、傳送物質或治療循環。
- 悟證方式：掌握兩項來源法則後，透過管路、循環系統或路徑追蹤形成。
