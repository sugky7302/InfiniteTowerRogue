# 氣息

氣息研究感官如何從流動介質中的能量與物質變化取得訊息。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：熱感、呼吸、氣味強度、生命徵兆與能量氣息。
- 邊界：不免費偵測生命、看穿隱藏或辨識身分。
