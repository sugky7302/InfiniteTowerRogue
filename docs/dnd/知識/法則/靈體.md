# 靈體

靈體研究心智如何透過能量維持可辨識的形體或載體。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：精神載體、能量軀殼、靈魂依附與意識形象。
- 邊界：不免費創造靈魂、復活、附身或形成戰鬥化身。
