# 生境

生境研究形體、流體與空間如何共同形成可維持物質循環的環境。

- 悟證前置：完成本頁18項知識網、相關統合精通與五階公開考核。
- 常見方向：土壤水系、棲地、器官腔室、微環境與物質交換。
- 邊界：不免費創造生命、植物、地形或安全區域。
