# 知識面板

## 目的

知識體系取代天賦（物品欄設計稿的決策）。本設計加入一個獨立視窗，讓玩家查看英雄的知識：名稱、分類、等級與解析進度。

## 使用者決策（2026-11-05）

| 問題 | 決策 |
|---|---|
| 顯示內容 | 名稱、分類、等級、解析進度 |
| 版面 | 像物品欄一樣一格一格排列；全螢幕；可以捲動 |
| 功能 | 篩選與排序 |
| 位置 | 獨立視窗 |
| 操作 | 只能查看。研究與學習另立設計稿 |
| 每格內容 | 圖示與名稱。等級、經驗與其他資料放在說明框 |
| 顯示哪些知識 | 只顯示英雄接觸過的知識（經驗大於 0，包含解析中）。沒有接觸過的不顯示 |
| 經驗 | 上限 4000。經驗曲線與取得量之後可以調整，經驗可以有小數 |

## 規則來源

`docs/dnd/規則/知識體系.md`：

- 經驗未達第一個門檻時稱為「解析進度」，尚未形成知識。達到門檻後為 1 級。
- 升至目標等級所需經驗＝100×目標等級。超出的經驗保留。所以累積經驗與等級的關係：
  - 1 級需要累積 100，2 級需要 300，3 級需要 600，n 級需要 50×n×(n+1)。
  - 上限 4000 時最高 8 級（累積 3600）。
- 這是暫定公式。曲線放在 `config/`，之後可以調整，不改其他程式。
- 每項知識有固定的主要節點類型（核心、型態、效果、修飾、觸發、橋接）、主要歸屬法則（七大法則之一）與知識深度（基礎、專業、高等、統合）。

## 現況

- `Hero.knowledge` 是知識名稱的清單（符文學者有 7 項）。沒有等級與經驗。
- 存檔 `hero` 區段的 `knowledge` 是 32 個 0／1 旗標，對應 `src/app/hero-save.ts` 的知識目錄。
- 技能定義中的 `knowledge` 是檢定用的數字，與本設計無關。

## 做法

### 資料（entities）

1. 新增 `src/entities/knowledge/`：
   - `config/`：知識目錄。每項有名稱、主要節點類型、主要歸屬法則、知識深度、一句說明。資料從 `docs/dnd/知識/` 的頁首與第一段手動整理。首版只有存檔目錄的 32 個位置（目前 7 項，其他保留）。
   - `model/`：
     - 經驗的單位：程式中以 **0.1 經驗** 為一個整數單位保存（例如 `350` 表示 35.0 經驗），顯示時才除以 10。原因：WC3 Lua 的浮點數只有約 7 位有效數字，不得用浮點數累加（AGENTS.md）。上限 4000 經驗＝40000 單位。
     - 經驗轉等級：`levelOf(units)`、本級門檻、下一級門檻。門檻來自 `config/` 的曲線。只用整數運算，結果不得超過 2147483647。超過上限時以上限計算。
     - 英雄的知識狀態：知識編號 → 累積經驗單位。0 表示沒有接觸過，大於 0 且未達 1 級門檻表示解析中，達到門檻表示已形成。
2. `Hero.knowledge` 的用途（技能使用的已形成知識）保持不變，由知識狀態中已形成的項目產生。

### 存檔

- `hero` 區段的 `knowledge` 由 32 個旗標改為 32 個經驗單位。範圍 0～40000（16 位元）。
- 存檔格式升版。舊版旗標 1 轉換為 1000 單位（100 經驗，1 級），0 轉換為 0。
- 預估增加 480 位元。需要確認存檔碼的長度仍可接受。

### 介面（features）

新增 `src/features/knowledge/`，`ui/` 放框架，`model/` 放篩選、排序與捲動的純函式。

- 開關：
  - 物品欄按鈕旁加入「知識」按鈕。
  - 知識視窗與物品欄互斥：打開一個時關閉另一個。
  - 聊天指令 `-know` 開關視窗（測試用）。
- 版面（4:3 區域 0.8×0.6）：
  - 上方：標題、篩選按鈕、排序按鈕、關閉按鈕。
  - 中間：格子區。每格有節點類型圖示與名稱。暫定每列 6 格、顯示 5 列，共 30 格（與背包一頁相同）。
  - 右側：捲軸（上、下按鈕與目前位置）。
  - 下方：說明框。移到格子上時，顯示名稱、節點類型、法則、深度、等級、經驗（例如 `35.0／100`、解析中或已形成）與說明。
- 捲動：
  - 只建立固定數量的格子（30 格），捲動時改變內容，不建立新框架（物品欄 I5 的經驗：反覆建立框架會讓關閉遊戲時卡住）。
  - 滑鼠滾輪（`FRAMEEVENT_MOUSE_WHEEL`）與上、下按鈕每次移動一列。
- 篩選（按鈕循環切換）：
  - 節點類型：全部、核心、型態、效果、修飾、觸發、橋接。
  - 法則：全部、七大法則。
  - 狀態：全部、已形成、解析中。
- 排序（按鈕循環切換）：名稱、等級（高到低）、節點類型、法則。同值時以目錄順序排列，結果穩定。
- 只顯示經驗大於 0 的知識。
- 測試指令 `-know-exp <目錄編號> <經驗>` 設定經驗（可以有一位小數），用於檢查說明框與捲動。

### 圖示

每種節點類型使用一個遊戲內建圖示（`ReplaceableTextures\CommandButtons\` 中的 BTN 圖示）。圖示路徑放在 `config/`，之後可以替換。

## 不包含

- 研究、學習、碎片、聯想線索。
- 知識圖譜（研究前置的連線）。
- 精通與法則。
- 從 `docs/dnd/知識/` 自動產生全部知識頁的目錄。
